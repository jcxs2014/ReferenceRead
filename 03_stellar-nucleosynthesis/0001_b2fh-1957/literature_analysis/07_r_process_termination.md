# 7. Termination of r & s Processes; Radioactive Elements; U/Th (第 VIII 章，P59–P65)

## 7.1 本节核心内容

第 VIII 章讨论：(A) 天然放射性元素的合成（U、Th、Pu）；(B) r 过程的延伸与终止（裂变、超铀合成）；(C) 元素年龄与银河系年龄（U$^{235}$/U$^{238}$ 双衰变定年）；(D) s 过程的终止（Pb/Bi/Th/U 丰度）。

## 7.2 天然放射性元素的合成（VIII.A，P59）[FACT]

### 7.2.1 三大天然放射性系列 [FACT]

| 系列 | 起始核素 | 半衰期 | 衰变类型 |
|---|---|---|---|
| 4n（Th 系） | Th$^{232}$ | $1.39\times10^{10}$ yr | $\alpha$ |
| 4n+2（U 系） | U$^{238}$ | $4.51\times10^{9}$ yr | $\alpha$ |
| 4n+3（Actinium 系） | U$^{235}$ | $7.04\times10^{8}$ yr | $\alpha$ |

[FACT] 4n+1 系列（Np$^{237}$）在自然界已**消失**（半衰期太短，$~2\times10^{6}$ yr）。

### 7.2.2 合成机制 [FACT]

[FACT] 论文明确指出：
- **U 和 Th 的合成**——r 过程**唯一**可能的来源（s 过程无法达到如此高的 A）。
- **Pu$^{244}$**（半衰期 $~8\times10^{7}$ yr）——r 过程合成，但在太阳系形成时已大部分衰变。

### 7.2.3 Table VIII.1 — r 过程放射性能量释放 [FACT]

论文列出 A=94 至 A=254 的所有质量链的放射性数据：
- 最长半衰期
- 衰变类型（$\beta$, $\alpha$, fission）
- 衰变能 Q (MeV)
- 初始丰度（相对）
- 总释放能

**关键数值 [FACT]**：
- A<78 的 $\beta$ 衰变：$~2\times10^{2}$ 质量单位释放，~5 天
- A=78–150：$\alpha$+$\beta$ 衰变：$~2\times10^{2}$ 质量单位
- A=150–254：自发裂变（Cf$^{254}$）：120–3000 质量单位

## 7.3 r 过程的延伸与终止（VIII.B，P62–P65）[FACT]

### 7.3.1 裂变终止 [FACT]

**中子诱发裂变 [FACT]**：
- 在 N≈152 附近（形变壳稳定），裂变势垒降低。
- 中子诱发裂变截面增大 → r 过程路径被**截断**。

**自发裂变 [FACT]**：
- Fm$^{258}$（半衰期 ~370 µs）——自发裂变"截止"。
- 裂变产生的碎片在 A≈110–140 区间。

### 7.3.2 Cf$^{254}$ 与超新星 [FACT]

[FACT] Burbidge (1956) 提出：Cf$^{254}$ 的自发裂变是 **I 型超新星光变曲线**后期指数衰减的能量来源：
- 半衰期 **~55 天**（今日实际值 60.5 天，接近）
- 能量释放 **~220 MeV/Cf$^{254}$ 核**

[FACT] 论文给出：
```
总能量 = g · f · m · $1.6\times10^{45}$ erg
其中 m = Cf$^{254}$ 质量，f = Cf 质量分数，g = 衰变分支比
```

**[CRITIQUE]** 论文对超新星供能的判断后来被证实**基本错误**——I 型超新星（今日 Ia 型）的能量主要来自 $^{56}{\rm Ni}$ → $^{56}{\rm Co}$ → $^{56}{\rm Fe}$ 衰变链（63 天与 111 天半衰期）；Cf$^{254}$ 不是主要供能者。

## 7.4 元素年龄与银河系年龄（VIII.C，P62–P64）[FACT]

### 7.4.1 U$^{235}$/U$^{238}$ 定年法 [FACT]

**核心思想 [FACT]**：
- U$^{235}$ 半衰期 = $7.04\times10^{8}$ yr
- U$^{238}$ 半衰期 = $4.51\times10^{9}$ yr
- r 过程同时合成 U$^{235}$ 与 U$^{238}$
- 观测到的 **U$^{235}$/U$^{238}$ 比值** → 可推算合成时间与银河系年龄

### 7.4.2 衰变方程 [FACT]

```
dU$^{235}$(t)/dt = -$\lambda_{235}$·U$^{235}$(t) + $P_{235}$（连续合成项）
dU$^{238}$(t)/dt = -$\lambda_{238}$·U$^{238}$(t) + $P_{238}$
```

其中 $P_{235}$/$P_{238}$ = r 过程合成时的初始比值。

### 7.4.3 三种极限情形 [FACT]

**情形 1：稳态合成（continuous synthesis）** [FACT]
如果元素持续合成：
```
U$^{235}$/U$^{238}$ = $P_{235}$ / $P_{238}$
```
比值不变。

**情形 2：突然合成（sudden synthesis）** [FACT]
如果元素在某时刻 $t_{0}$ 突然合成：
```
U$^{235}$(t)/U$^{238}$(t) = 0.713 · 2^(12.3·($t_{0}$ - t)/$10^{9}$)
```
（用 $\lambda_{235}$/$\lambda_{238}$ = 0.693·4.51/0.713·7.04 = 0.640）

**情形 3：观测值 [FACT]**
```
U$^{235}$/U$^{238}$（太阳系）= 0.0072
U$^{235}$/U$^{238}$（初始，46 亿年前）= 0.0072 × 2^(12.3×4.6/10)
```

### 7.4.4 论文推断 [FACT]

[FACT] 论文明确得出：
- 太阳系中初始 **U$^{235}$/U$^{238}$ ≈ 0.72**
- 由此推出**银河系年龄 ~ $1.5\times10^{10}$ 年**（在"突然合成"极限下）
- 或者 ~ **$6\times10^{9}$ 年**（在"连续合成"极限下）

[FACT] 论文明确结论："The age of the elements and of the Galaxy is probably of the order of $10^{10}$ years."

**[CRITIQUE]** 1957 年的估计 ~$10^{10}$ yr 与今日已接受的 **$~13.8\times10^{9}$ yr** 宇宙年龄相当接近——考虑到论文发表时宇宙年龄争议巨大（从 $10^{8}$ 到 $10^{10}$ yr），这是令人印象深刻的估计。

## 7.5 s 过程的终止（VIII.D，P64–P65）[FACT]

### 7.5.1 Pb$^{208}$ 的丰度 [FACT]

- s 过程在 Pb$^{208}$（Z=82, N=126）处**终止**。
- 论文给出 Pb$^{204}$, Pb$^{206}$, Pb$^{207}$, Pb$^{208}$ 的丰度比例：
  - Pb$^{204}$（非 s/r 过程）：0.014%
  - Pb$^{206}$（4n 系产物）：24%
  - Pb$^{207}$（4n+3 系产物）：22%
  - Pb$^{208}$（4n+2 系产物，**s 过程终点**）：52%

### 7.5.2 陨石铅比 [FACT]

[FACT] Patterson et al. (1953, 1955) 陨石铅同位素比：
```
Pb$^{206}$/Pb$^{204}$ = 18.14
Pb$^{207}$/Pb$^{204}$ = 15.33
Pb$^{208}$/Pb$^{204}$ = 36.74
```
（这些数值随陨石类型略有变化）

### 7.5.3 Bismuth 与 Th/U [FACT]

- Bi$^{209}$：半衰期 $~1.9\times10^{19}$ yr，实际上是 s 过程的**最终稳定终点**（因 $\alpha$ 衰变极慢）。
- Th$^{232}$ 与 U$^{238}$ 的丰度比：r 过程合成时的初始比 ~ 1.6。

## 7.6 作者论证链

```
r 过程在裂变处终止 
→ 最终产物为 U、Th
→ U$^{235}$/U$^{238}$ 双衰变定年 
→ 推出银河系年龄 ~$10^{10}$ yr
```

## 7.8 [INTERPRETATION]

1. U$^{235}$/U$^{238}$ 定年法是**核天体物理学中第一个**系统性的"时钟"——今日仍是恒星考古学（stellar archaeology）的核心工具。
2. 论文对银河系年龄的估计（~$10^{10}$ yr）在**当时是革命性的**——首次将核衰变时钟系统引入天体物理学。

## 7.9 [CRITIQUE]

1. Cf$^{254}$ 作为 I 型超新星供能者的主张被**后来修正**——Ia 型超新星的真实供能是 $^{56}{\rm Ni}$/$^{56}{\rm Co}$ 衰变链。
2. U$^{235}$/U$^{238}$ 定年的**初始比值**（$P_{235}$/$P_{238}$）在不同 r 过程模型中有争议——论文的"突然合成"与"连续合成"两种极限是合理的但简化。
3. 论文使用 $4.51\times10^{9}$ yr 作为 U$^{238}$ 半衰期——今日已精确为 $4.468\times10^{9}$ yr。
