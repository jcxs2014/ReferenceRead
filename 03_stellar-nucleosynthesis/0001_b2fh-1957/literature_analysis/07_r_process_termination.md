# 7. Termination of r & s Processes; Radioactive Elements; U/Th (第 VIII 章，P59–P65)

## 7.1 本节核心内容

第 VIII 章讨论：(A) 天然放射性元素的合成（U、Th、Pu）；(B) r 过程的延伸与终止（裂变、超铀合成）；(C) 元素年龄与银河系年龄（U²³⁵/U²³⁸ 双衰变定年）；(D) s 过程的终止（Pb/Bi/Th/U 丰度）。

## 7.2 天然放射性元素的合成（VIII.A，P59）[FACT]

### 7.2.1 三大天然放射性系列 [FACT]

| 系列 | 起始核素 | 半衰期 | 衰变类型 |
|---|---|---|---|
| 4n（Th 系） | Th²³² | 1.39×10¹⁰ yr | α |
| 4n+2（U 系） | U²³⁸ | 4.51×10⁹ yr | α |
| 4n+3（Actinium 系） | U²³⁵ | 7.04×10⁸ yr | α |

[FACT] 4n+1 系列（Np²³⁷）在自然界已**消失**（半衰期太短，~2×10⁶ yr）。

### 7.2.2 合成机制 [FACT]

[FACT] 论文明确指出：
- **U 和 Th 的合成**——r 过程**唯一**可能的来源（s 过程无法达到如此高的 A）。
- **Pu²⁴⁴**（半衰期 ~8×10⁷ yr）——r 过程合成，但在太阳系形成时已大部分衰变。

### 7.2.3 Table VIII.1 — r 过程放射性能量释放 [FACT]

论文列出 A=94 至 A=254 的所有质量链的放射性数据：
- 最长半衰期
- 衰变类型（β, α, fission）
- 衰变能 Q (MeV)
- 初始丰度（相对）
- 总释放能

**关键数值 [FACT]**：
- A<78 的 β 衰变：~2×10² 质量单位释放，~5 天
- A=78–150：α+β 衰变：~2×10² 质量单位
- A=150–254：自发裂变（Cf²⁵⁴）：120–3000 质量单位

## 7.3 r 过程的延伸与终止（VIII.B，P62–P65）[FACT]

### 7.3.1 裂变终止 [FACT]

**中子诱发裂变 [FACT]**：
- 在 N≈152 附近（形变壳稳定），裂变势垒降低。
- 中子诱发裂变截面增大 → r 过程路径被**截断**。

**自发裂变 [FACT]**：
- Fm²⁵⁸（半衰期 ~370 µs）——自发裂变"截止"。
- 裂变产生的碎片在 A≈110–140 区间。

### 7.3.2 Cf²⁵⁴ 与超新星 [FACT]

[FACT] Burbidge (1956) 提出：Cf²⁵⁴ 的自发裂变是 **I 型超新星光变曲线**后期指数衰减的能量来源：
- 半衰期 **~55 天**（今日实际值 60.5 天，接近）
- 能量释放 **~220 MeV/Cf²⁵⁴ 核**

[FACT] 论文给出：
```
总能量 = g · f · m · 1.6×10⁴⁵ erg
其中 m = Cf²⁵⁴ 质量，f = Cf 质量分数，g = 衰变分支比
```

**[CRITIQUE]** 论文对超新星供能的判断后来被证实**基本错误**——I 型超新星（今日 Ia 型）的能量主要来自 ⁵⁶Ni → ⁵⁶Co → ⁵⁶Fe 衰变链（63 天与 111 天半衰期）；Cf²⁵⁴ 不是主要供能者。

## 7.4 元素年龄与银河系年龄（VIII.C，P62–P64）[FACT]

### 7.4.1 U²³⁵/U²³⁸ 定年法 [FACT]

**核心思想 [FACT]**：
- U²³⁵ 半衰期 = 7.04×10⁸ yr
- U²³⁸ 半衰期 = 4.51×10⁹ yr
- r 过程同时合成 U²³⁵ 与 U²³⁸
- 观测到的 **U²³⁵/U²³⁸ 比值** → 可推算合成时间与银河系年龄

### 7.4.2 衰变方程 [FACT]

```
dU²³⁵(t)/dt = -λ₂₃₅·U²³⁵(t) + P₂₃₅（连续合成项）
dU²³⁸(t)/dt = -λ₂₃₈·U²³⁸(t) + P₂₃₈
```

其中 P₂₃₅/P₂₃₈ = r 过程合成时的初始比值。

### 7.4.3 三种极限情形 [FACT]

**情形 1：稳态合成（continuous synthesis）** [FACT]
如果元素持续合成：
```
U²³⁵/U²³⁸ = P₂₃₅ / P₂₃₈
```
比值不变。

**情形 2：突然合成（sudden synthesis）** [FACT]
如果元素在某时刻 t₀ 突然合成：
```
U²³⁵(t)/U²³⁸(t) = 0.713 · 2^(12.3·(t₀ - t)/10⁹)
```
（用 λ₂₃₅/λ₂₃₈ = 0.693·4.51/0.713·7.04 = 0.640）

**情形 3：观测值 [FACT]**
```
U²³⁵/U²³⁸（太阳系）= 0.0072
U²³⁵/U²³⁸（初始，46 亿年前）= 0.0072 × 2^(12.3×4.6/10)
```

### 7.4.4 论文推断 [FACT]

[FACT] 论文明确得出：
- 太阳系中初始 **U²³⁵/U²³⁸ ≈ 0.72**
- 由此推出**银河系年龄 ~ 1.5×10¹⁰ 年**（在"突然合成"极限下）
- 或者 ~ **6×10⁹ 年**（在"连续合成"极限下）

[FACT] 论文明确结论："The age of the elements and of the Galaxy is probably of the order of 10¹⁰ years."

**[CRITIQUE]** 1957 年的估计 ~10¹⁰ yr 与今日已接受的 **~13.8×10⁹ yr** 宇宙年龄相当接近——考虑到论文发表时宇宙年龄争议巨大（从 10⁸ 到 10¹⁰ yr），这是令人印象深刻的估计。

## 7.5 s 过程的终止（VIII.D，P64–P65）[FACT]

### 7.5.1 Pb²⁰⁸ 的丰度 [FACT]

- s 过程在 Pb²⁰⁸（Z=82, N=126）处**终止**。
- 论文给出 Pb²⁰⁴, Pb²⁰⁶, Pb²⁰⁷, Pb²⁰⁸ 的丰度比例：
  - Pb²⁰⁴（非 s/r 过程）：0.014%
  - Pb²⁰⁶（4n 系产物）：24%
  - Pb²⁰⁷（4n+3 系产物）：22%
  - Pb²⁰⁸（4n+2 系产物，**s 过程终点**）：52%

### 7.5.2 陨石铅比 [FACT]

[FACT] Patterson et al. (1953, 1955) 陨石铅同位素比：
```
Pb²⁰⁶/Pb²⁰⁴ = 18.14
Pb²⁰⁷/Pb²⁰⁴ = 15.33
Pb²⁰⁸/Pb²⁰⁴ = 36.74
```
（这些数值随陨石类型略有变化）

### 7.5.3 Bismuth 与 Th/U [FACT]

- Bi²⁰⁹：半衰期 ~1.9×10¹⁹ yr，实际上是 s 过程的**最终稳定终点**（因 α 衰变极慢）。
- Th²³² 与 U²³⁸ 的丰度比：r 过程合成时的初始比 ~ 1.6。

## 7.6 作者论证链

```
r 过程在裂变处终止 
→ 最终产物为 U、Th
→ U²³⁵/U²³⁸ 双衰变定年 
→ 推出银河系年龄 ~10¹⁰ yr
```

## 7.8 [INTERPRETATION]

1. U²³⁵/U²³⁸ 定年法是**核天体物理学中第一个**系统性的"时钟"——今日仍是恒星考古学（stellar archaeology）的核心工具。
2. 论文对银河系年龄的估计（~10¹⁰ yr）在**当时是革命性的**——首次将核衰变时钟系统引入天体物理学。

## 7.9 [CRITIQUE]

1. Cf²⁵⁴ 作为 I 型超新星供能者的主张被**后来修正**——Ia 型超新星的真实供能是 ⁵⁶Ni/⁵⁶Co 衰变链。
2. U²³⁵/U²³⁸ 定年的**初始比值**（P₂₃₅/P₂₃₈）在不同 r 过程模型中有争议——论文的"突然合成"与"连续合成"两种极限是合理的但简化。
3. 论文使用 4.51×10⁹ yr 作为 U²³⁸ 半衰期——今日已精确为 4.468×10⁹ yr。
