# 4. The $\epsilon$ (Equilibrium) Process（第 IV 章，P31–P36）

## 4.1 本节核心内容

论述在极高温度（T ≈ $10^{9}$ K）和高密度下，通过核统计平衡（nuclear statistical equilibrium, NSE）合成的铁峰元素（V, Cr, Mn, Fe, Co, Ni）。

## 4.2 基本原理（Hoyle 平衡过程）[FACT]

### 4.2.1 物理条件 [FACT]
- **温度**：T ~ 5×$10^{9}$ K 量级（$T_{9}$ ≈ 5）
- **密度**：极高（$\rho$ ~ $10^{7}$ g/cm³）
- **场所**：超新星爆发前的最后稳定阶段（iron-group synthesis）
- **时标**：秒或分钟

### 4.2.2 平衡条件 [FACT]

当核反应速率**远大于**系统演化速率时，核素组成达到**化学平衡**：核子被"搅拌"成满足热力学平衡的组合。

**核心假设 [FACT]**：
1. 铁（A=56, Z=26）是平衡下的**最丰核素**。
2. 平衡分布由**Wapstra 核质量表**决定。

## 4.3 Saha 方程与核统计平衡 [FACT]

### 4.3.1 核素 i 与核素 j 的数密度比 [FACT]

```
n_i / n_j = (g_i / g_j) · (A_j / A_i) · ($\rho$ N_A / A_i)^(A_i - A_j) · 
            (2$\pi$ ℏ² / m_u kT)^(3(A_j - A_i)/2) · exp(-Q_ij / kT)
```

其中 Q_ij = (M_j - M_i)·c² 是核反应 Q 值。

### 4.3.2 简化近似（以 Fe⁵⁶ 为基准）[FACT]

[FACT] 设 N(A,Z) 为质量数 A 电荷 Z 的核的摩尔分数。相对于 Fe⁵⁶ 的对数丰度：

```
$\log_{10}$(N(A,Z)/N(Fe⁵⁶)) = $\log_{10}$(g_AZ / g_Fe56) - 27·$\log_{10}$($\rho$·N_A/56) · (1 - 56/A) 
                       + 1.5·(A-56)·$\log_{10}$(kT / (2$\pi$·m_u·c²))
                       - (Q_AZ - Q_Fe56) / (kT·ln10)
```

Q_AZ = (Z·m_p + N·m_n - M(A,Z))·c² —— 结合能。

### 4.3.3 N/Z 平衡（自由中子与质子）[FACT]

在极高 T 下，自由中子与质子达到平衡：

```
n_n / n_p = (m_n / m_p)^(3/2) · exp(-$\Delta$m·c² / kT)
```

**T = 5×$10^{9}$ K**：n_n/n_p ≈ **0.5**（约等于），允许富中子的铁峰核素合成。

**关键判据 [FACT]**：
- 在 T < 5×$10^{9}$ K 下，质子相对丰度更高，产生富质子的铁峰核。
- 随着 T 上升，中子丰度增加，允许更富中子的核素出现。

## 4.5 计算结果与观测对比 [FACT]

[FACT] 论文的核心发现：
1. **Fe⁵⁶ 的极端富集**（结合能最大的核）——自然地从平衡计算中出现。
2. **Co⁵⁹/Ni⁵⁸/Ni⁵⁹/Ni⁶⁰** 等富中子核素的丰度——需要 T > 5×$10^{9}$ K。
3. **Mn⁵⁵** 等核素——需要精确的 T 与 $\rho$ 组合。
4. **Z=26（铁）的"峰值"丰度**是包层分数曲线的直接反映——Fe⁵⁶ 处于结合能最小点（最稳定）。

## 4.6 稳态流的类比 [FACT]

[FACT] 论文强调，$\epsilon$ 过程与 s 过程的**稳态流**概念在数学上类似：
```
$\epsilon$ 过程：结合能 Q(A,Z) 决定分布
s 过程：$\sigma$(A)·N(A) = const 决定分布
```
两者都体现了"最稳定"或"最大截面"位置的"堆积"。

## 4.7 双/三重 $\beta$ 衰变与稳定性 [FACT]

[FACT] 论文讨论：对某些（A,Z）点，可能存在三个稳定核素（对应 $b_{2}$ > $B_{2}$ 的条件），允许**双 $\beta$ 衰变**，其半衰期 > $10^{18}$ yr。

## 4.8 作者论证链

```
恒星演化到极高 T（~$10^{9}$ K）
→ 核反应速率快于演化
→ 达到核统计平衡（NSE）
→ 丰度分布由 Wapstra 质量表决定
→ Fe⁵⁶ 是自然"谷底" → 产生丰度峰
```

## 4.9 [INTERPRETATION]

1. $\epsilon$ 过程本质上就是**核统计平衡（NSE）**——这一概念今日仍在恒星演化模拟中被使用。
2. 论文提出的 T=3.78×$10^{9}$ K 作为铁峰合成的典型温度，与今日硅燃烧阶段的标准温度一致。
3. 铁的"自然"丰度峰不需要任何特殊假设——它只是结合能曲线的直接反映。

## 4.10 [CRITIQUE]

1. **今日已知**铁峰元素的最终丰度主要由**硅燃烧阶段的爆炸性核合成**决定，而非简单的静态 NSE——超新星爆炸的非均匀性、对流、核统计平衡偏离（nuclear statistical disequilibrium）在现代模型中是关键。
2. 论文使用 1955 年的 Wapstra 质量表；今日 AME2020 原子质量评价**已大幅修正**了 1950 年代的若干核素质量。
3. 论文给出的"fair agreement"数值在细节上与现代计算的**差异可达 20-30%**，但**定性图景正确**。
