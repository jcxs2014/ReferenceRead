# 8. The p Process — Proton-Rich Nuclei（第 IX 章，P65–P74）

## 8.1 本节核心内容

论述 p 过程（proton-rich process）：质子富集核（p-nuclei）的合成机制，包括 (p,$\gamma$) 质子俘获与 ($\gamma$,n) 光致蜕变，以及 p 过程在 (Z,A) 平面中的路径。

## 8.2 p 过程的定义与识别 [FACT]

### 8.2.1 什么核素属于 p 过程 [FACT]

**定义 [FACT]**：
- p 过程核是**质子富集同位素**，其丰度相对于邻近的中子富集同位素**极低**（低 1–3 个数量级）。
- 这些核素**不能**通过 s 或 r 过程的中子俘获链到达（被"屏蔽"）。
- p 过程核主要分布在**轻质量（A<90）与中等质量（A=90–200）**区间。

### 8.2.2 p 过程的物理机制 [FACT]

[FACT] 论文提出两种机制：
1. **(p,$\gamma$) 质子俘获**——直接加质子。
2. **($\gamma$,n) 光致蜕变**——光子打出中子（在稳定核上）。

## 8.3 图 IX.1 — p 过程核的丰度 [FACT]

图 IX.1（P70）展示 p 过程核的丰度：
- 大多数 p 核的丰度 ~$10^{-6}$–$10^{-4}$（相对于 Si=$3.16\times10^{4}$）
- 部分"仅 p 过程"核素丰度低于 $10^{-7}$

**关键观察 [FACT]**：p 核丰度在 N=50, 82, 126 附近的"缺口"（这些位置由 s/r 过程核素占据）明显可见。

## 8.4 图 IX.2 — p 过程在 (Z,A) 平面的路径 [FACT]

**物理图像 [FACT]**：
- 物质在**稳定线**上（先由 r 过程产生）。
- 经历**光致蜕变 ($\gamma$,n)**：光子打出中子，原子核向质子富集方向移动。
- 每打出一个中子，Z 不变但 A 减小 1 → 在 (Z,A) 平面向左上方移动。

**位移量 $\delta$Z [FACT]**：
```
$\delta$Z ≈ $\Delta$Z/$\Delta$A × $\Delta$A = 3 × $\Delta$A
```
其中 Z,A 平面中稳定线的斜率 ≈ 1/3（即每增加 3 个 A，Z 增加 1）。

## 8.5 反应截面与速率 [FACT]

### 8.5.1 (p,$\gamma$) 反应 [FACT]

[FACT] 论文引用 §III.A 的一般公式，代入 $Z_{1}$=1 后：
```
1/$\tau_\gamma$(p) ≈ $3.1\times10^{5}$ · ($\rho$·X_p / √(A_p·$A_{0}$)) · S_p · $T_{9}$^(-2/3) 
          · exp(-11.61·Z_p·√(A_p/$T_{9}$)·A^(-1/6))
```

### 8.5.2 ($\gamma$,n) 光致蜕变 [FACT]

[FACT] 光致蜕变反应率：
```
1/$\tau_\gamma$($\gamma$,n) = ∫ $\sigma$($\gamma$,n)·$\phi$($\gamma$) d$\gamma$
```
其中 $\phi$($\gamma$) 是黑体辐射光子谱。

**关键阈值 [FACT]**：
- ($\gamma$,n) 反应要求光子能量 > 中子分离能 Q_n（通常 7–10 MeV）。
- 这需要**极高温度**：T ~ 2–$3\times10^{9}$ K。

### 8.5.3 关键判据 [FACT]

[FACT] p 过程发生的必要温度：
```
T > $2\times10^{9}$ K（产生 7–8 MeV 光子）
```
这一温度对应**超新星爆发壳层**的外层。

## 8.6 p 过程的场所 [FACT]

[FACT] 论文明确指出：
1. **超新星 I 型外抛壳层**——爆炸时的高温（$~3\times10^{9}$ K）和**中等密度**允许光致蜕变发生。
2. 超新星 II 型的外层。

**[FACT]** "It has previously been suggested that this process takes place in the outbursts of supernovae of Type II on a time-scale comparable to that for the r process."

## 8.7 时间标度 [FACT]

[FACT] p 过程的时间标度 ~**分钟**（与 r 过程相当），因为需要极高温以产生足够 7–10 MeV 光子。

## 8.8 [INTERPRETATION]

1. **今日已知** p 过程的主要场所是**核心坍缩超新星（CC-SNe）的 O/Ne 壳层**——在爆炸激波通过后，温度升至 ~2–$3\times10^{9}$ K，光致蜕变占主导。
2. 论文提出的两个机制 ((p,$\gamma$) 与 ($\gamma$,n)) 中，**今日 ($\gamma$,n) 光致蜕变被确认为主要机制**（因为 (p,$\gamma$) 在如此高温下逆反应 ($\gamma$,p) 太快）。
3. **p 过程核素的起源**至今仍是活跃研究领域——特别是**部分 p 核可能来自 $\nu$ 过程（中微子驱动的核合成）**。

## 8.9 [CRITIQUE]

1. 论文对 p 过程场所的判断（超新星外抛壳）今日**基本正确**，但详细物理已大幅丰富。
2. 论文未讨论**中微子过程（$\nu$ 过程）**——1957 年时太阳中微子问题尚未被认识。
