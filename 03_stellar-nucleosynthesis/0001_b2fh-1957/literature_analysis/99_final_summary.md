## 15.1 一句话总结

Burbidge, Burbidge, Fowler, Hoyle (1957) 提出**宇宙中所有比氦重的元素都由恒星内部的八大核过程（H 燃烧、He 燃烧、$\alpha$、$\epsilon$、s、r、p、x）从原始氢逐步合成**，并系统解释了观测到的元素丰度曲线的全部精细结构——这是核天体物理学领域最具影响力的奠基论文之一。

## 15.2 科学问题

**元素从何而来？** 三种"原始合成"理论（Gamow/Alpher/Herman；Mayer/Teller；Klein/Beskow/Treffenberg）都要求特殊的宇宙初始条件，且无法解释观测到的元素分布。B$^2$FH 论文将问题转向：恒星内部正在进行的核反应，是否足以解释全部 327 种天然核素的丰度分布？

## 15.3 核心方法

1. **数据驱动**：以 Suess & Urey (1956) 元素丰度表为基准。
2. **过程分类**：根据丰度曲线的异常特征（幻数峰、$\alpha$ 粒子核的过剩、质子富集核的稀少）反推需要的合成机制 → 八大过程。
3. **稳态流分析**：$\sigma$(A)·N(A) = const 判据区分 s/r 过程。
4. **等待点近似**：r 过程丰度由 $\beta$ 衰变能量 W_$\beta^{5}$ 决定。
5. **平衡态**：铁峰由核统计平衡（NSE）决定。
6. **双衰变定年**：U$^{235}$/U$^{238}$ 比值推算银河系年龄。

## 15.4 最重要结果

| 结果 | 内容 |
|---|---|
| 八大合成过程 | H 燃烧、He 燃烧、$\alpha$、$\epsilon$、s、r、p、x |
| s 过程丰度峰 | A=90 (Zr), 138 (Ba), 208 (Pb) — Z=50, 82 处 |
| r 过程丰度峰 | A=80 (Se), 130 (Xe), 194 (Os) — N=50, 82, 126 处 |
| 稳态流判据 | $\sigma$·N = const（s 过程） |
| Tc$^{99}$ 观测证据 | S 型星中的短寿命核素 → s 过程正在发生 |
| 中子源 | $^{12}{\rm C}$($\alpha$,n)$^{16}{\rm O}$ 与 $^{20}{\rm Ne}$($\alpha$,n)$^{24}{\rm Mg}$ |
| 银河系年龄 | ~$10^{10}$ yr（由 U$^{235}$/U$^{238}$ 定年） |
| U、Th 起源 | r 过程 |

## 15.5 核心创新

1. **首次系统性地将核物理与天体物理结合**——建立完整的恒星核合成理论。
2. **八大过程分类框架**——至今仍在使用。
3. **$\sigma$N=const 稳态流判据**——s 过程分析的标准工具。
4. **等待点近似**——r 过程理论的核心。
5. **U$^{235}$/U$^{238}$ 双衰变定年法**——核天体物理学中第一个系统性"时钟"。
6. **Tc$^{99}$ 作为直接证据**——将"元素合成"从一个假设升级为"当前正在发生"的过程。
7. **"1 barn = 24¢/mol"**——首次系统的中子俘获截面估算规则。

## 15.6 主要局限

1. **Cf$^{254}$ 供能假设**——后来被 $^{56}{\rm Ni}$/$^{56}{\rm Co}$ 衰变链取代。
2. **r 过程场所**——论文认为在超新星中，今日主流观点是**中子星并合**。
3. **忽略 $\nu$ 过程**——中微子驱动的核合成在 1957 年尚未被认识。
4. **忽略 $^{13}{\rm C}$($\alpha$,n)**——今日 AGB 星 s 过程的第一脉冲中子源。
5. **非稳态效应**——现代模型必须考虑中子源关闭、循环、多次脉动。
6. **原子质量数据**——1955 年 Wapstra 质量表已被 AME2020 大幅改进。
7. **数值精确度**——许多具体数值已被修正，但定性图景依然正确。

## 15.7 我应该记住什么

1. **B$^2$FH = Burbidge, Burbidge, Fowler, Hoyle**（1957），Rev. Mod. Phys. 29:547。
2. **八大过程**：H 燃烧、He 燃烧、$\alpha$ 过程、$\epsilon$ 平衡过程、s 过程、r 过程、p 过程、x 过程。
3. **s 过程峰**：A=90/138/208（质子幻数 Z=50/82 处）。
4. **r 过程峰**：A=80/130/194（中子幻数 N=50/82/126 处）。
5. **$\sigma$N=const** 是 s 过程的稳态流判据。
6. **等待点近似**决定 r 过程丰度。
7. **Tc$^{99}$ 在 S 型星中被观测到**——s 过程正在发生的直接证据。
8. **U 和 Th 是 r 过程的产物**。
9. **U$^{235}$/U$^{238}$ 双衰变定年法**估计银河系年龄 ~$10^{10}$ yr。
10. **超新星**是重元素散布到银河系的关键机制。
11. **中子源**：$^{12}{\rm C}$($\alpha$,n) 与 $^{20}{\rm Ne}$($\alpha$,n)。
12. **铁峰**由核统计平衡（NSE）产生。
13. **p 核**由 ($\gamma$,n) 光致蜕变产生于超新星外抛壳。
14. **D** 主要来自 Big Bang 核合成（今日观点，1957 年论文仅提出可能性）。
15. **$^{12}{\rm C}$ 的 Hoyle 态（7.65 MeV）**是 3$\alpha$ 反应的关键。
