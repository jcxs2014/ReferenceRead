# 3. Hydrogen Burning, Helium Burning, α Process & Neutron Production（第 III 章，P13–P31）

## 3.1 本节核心内容

建立核反应截面的恒星内处理形式（S 因子）、详细推导 pp 链与 CN 循环的能量产率、氦燃烧的 3α 反应及进一步 α 俘获链（直至 ⁴⁸Ti）、并分析恒星中子源（¹²C(n,α) 与 ²⁰Ne(α,n)）。

## 3.2 反应截面与反应率（III.A，P13–P16）[FACT]

### 3.2.1 核心公式：S 因子（cross-section factor）

```
S = σ(E) · E · exp(31.28 · Z₁ · Z₀ · √(A/E))   keV·barn
```

其中：
- σ(E)：质心系能量 E (keV) 下的截面 (barn, 10⁻²⁴ cm²)
- Z₁, Z₀：反应粒子的电荷（质子电荷单位）
- A = A₁·A₀/(A₁+A₀)：折合质量（原子质量单位）
- S 在质心系下测量

**从实验室系推导 S**：
```
S = σ(E_l) · E_l · exp(31.28 · Z₁ · Z₀ · √(A_l/E_l))   keV·barn
   · A₁/(A₁+A₀) · (A_l+A₀)/A_l  （实验室到质心换算）
```

### 3.2.2 有效热能量（Gamow 峰）[FACT]

```
E_0 = 1.220 · (Z₁²·Z₀²·A·T₉²)^(1/3)   keV·barn
ΔE_0 = 0.75 · (Z₁²·Z₀²·A·T₉²)^(1/6)   keV
```
T₉ 是以 10⁹ K 为单位的温度。

### 3.2.3 平均反应率 [FACT]

```
R = n_0 · n_1 · <σv> = 3.63×10⁻¹² · (X₀·X₁/√(A₀·A₁)) · (σv)   反应数·cm⁻³·s⁻¹
```

以 S₀=S(E₀) 表达的恒星温度下的反应率：
```
R = 7.20×10⁻¹¹ · T₉⁻²/³ · exp(-3τ) · (A·Z₁²·Z₀²)^(-1/3) · f_c · S₀   反应数·cm⁻³·s⁻¹
```
其中 τ = 42.48·(Z₁·Z₀·√(A/T₉))^(1/3)，f_c 是电子屏蔽（Salpeter, 1954）因子。

### 3.2.4 核子平均寿命 [FACT]

```
1/τ_γ(0) = 4.34×10⁻¹¹ · X₁ · ρ · S₀ · f_c · (A·Z₁²·Z₀²)^(-1/3) · T₉⁻²/³ · exp(-τ)   s⁻¹
```

### 3.2.5 共振截面的 Breit-Wigner 公式 [FACT]

对落在 Gamow 窗外 (E₀±2ΔE₀) 的孤立共振：
```
σ = πλ̄² · g · (Γ₀·Γ₂)/((E-E₀)² + Γ²/4)
S_0 = 3.10×10¹³ · g · (E₀/R) · (Γ₀·Γ₂) / (A · K_{l₀+l₁}(x) · (E₀+Γ²/4))   keV·barn
```

**关键参数：**
- λ̄ = 144·√(A/E) fermi —— De Broglie 波长
- E_R = 1.44·(A₁^(1/3) + A₀^(1/3)) fermi —— 相互作用半径
- E_c = 1.44·Z₁·Z₀/R × 10⁶ keV —— 库仑势垒高度
- E_l = 20.9/(A·l²) × 10⁶ keV —— 离心势垒
- x = 2·(E_c/E_l)^(1/2) = 0.525·(A·Z₁·Z₀·R)^(1/2)
- K_{l₀+l₁}(x)：修正 Bessel 函数

### 3.2.6 非共振区平均截面 [FACT]

Blatt & Weisskopf 关系：
```
D/(Γ_R·P_l) = ρ(E₀)
```
对 l=0 且大 x：
```
S₀(l=0) = 1.8×10⁻²⁰ · (E₀/R) · (1/A) · (Γ₂) · (1/(ΔE)) · exp(+4τ)
```
典型值：(p,γ) 在轻核上，S₀ ≈ 1–100 keV·barn；(p,n)，S₀ ≈ 10⁻³–10⁻⁴ keV·barn。

### 3.2.7 落在 Gamow 窗内的共振 [FACT]

```
σ_res = πλ̄² · g · 4·Γ₁·Γ₂/Γ²
```
两种极限情况：Γ₁=Γ₂≫Γ₀ 与 Γ₀≫Γ₁。

## 3.3 纯氢燃烧（III.B，P16–P31）[FACT]

### 3.3.1 直接 pp 反应 [FACT]

**首步：**
```
p + p → d + e⁺ + ν_e + 0.421 MeV
```
[FACT] 截面在 1 MeV 实验室能量下 ≈ **10⁻⁴⁷ cm² = 10⁻²³ barn**——极小，无法在实验室观测。

### 3.3.2 pp 链 [FACT]

```
pp I:  p + p → d + e⁺ + ν;    d + p → ³He + γ;    ²³He + ³He → ⁴He + 2p
pp II: ... + ⁴He → ⁷Be + γ;   ⁷Be + e⁻ → ⁷Li + ν;   ⁷Li + p → ²⁴He
pp III: ... + p → ⁸B + e⁺ + ν;   ⁸B → ²⁴He + e⁺ + ν
```

### 3.3.4 CN 循环 [FACT]

```
¹²C(p,γ)¹³N(β⁺)¹³C(p,γ)¹⁴N(p,γ)¹⁵O(β⁺)¹⁵N(p,α)¹²C
```
**限制步**：¹⁴N(p,γ)¹⁵O。

[FACT] 能量释放每循环（不含 6% 中微子损失）= **25.04 MeV = 4.011×10⁻⁵ erg**（用 Wapstra 1955 质量）。

### 3.3.5 产能率 [FACT]

```
ε_CN = (0.786 ± 0.16) · (X_C · X_H) · 10²⁸ erg·s⁻¹·g⁻¹
```

**H 的寿命：**
```
τ_γ(H) = 1.90 · (X_H/X_CN) · 10¹⁰ yr
        = (2.42 ± 0.48) · (X_C·X_CN)⁻¹ · 10¹⁰ yr
```

**N¹⁴ 循环时间：**
```
τ_γ(N¹⁴) = 0.55 · (X_CN/X_CN) · 10¹⁰ yr
         = (0.70 ± 0.14) · (X_CN·X_CN)⁻¹ · 10¹⁰ yr
```

### 3.3.6 氢燃烧的产物扩展 [FACT]

- **CNO 循环**：产生 N¹⁴ 堆积（因 ¹⁴N(p,γ) 是限制步）。
- **Ne-Na 循环**：²²Ne(p,γ)²³Na(p,γ)²⁴Mg 等。
- **Mg-Al 循环**：²⁶Al(β⁺)²⁶Mg 等。
- 合成产物：F¹⁹、Na²³、Na²⁴、Mg²⁵、Mg²⁶、Al²⁷、Al²⁸、Si²⁹、Si³⁰。

## 3.4 氦燃烧（III.C，P20–P23）[FACT]

### 3.4.1 三 α 反应 [FACT]

**第一步：**
```
²⁴He + ²⁴He ↔ ⁴⁸Be  (激发态，不稳定)
⁴⁸Be + ²⁴He → ¹²C* (7.65 MeV 激发态) → ¹²C + γ
```
**关键共振**：¹²C* 的 **7.65 MeV 激发态**（Hoyle 态，1954 预测），对恒星 3α 反应速率**决定性**的作用。

### 3.4.2 进一步 α 俘获 [FACT]

```
¹²C(α,γ)¹⁶O  →  ¹⁶O(α,γ)²⁰Ne  →  ²⁰Ne(α,γ)²⁴Mg
```

### 3.4.3 16O(α,γ)²⁰Ne 的共振 [FACT]

16O 的 4.95 和 5.62 MeV 激发态的自旋宇称（偶-偶或奇-奇）决定了反应能否进行。
[FACT] "These states probably have even parity and even spin..."
对 T>10⁸ K，因 E₀=246·T₉^(1/3) keV，共振有效。

## 3.5 α 过程（III.D，P21–P23）[FACT]

**定义**：从 ²⁰Ne 起逐次 α 俘获：
```
²⁰Ne(α,γ)²⁴Mg → (α,γ)²⁸Si → (α,γ)³²S → (α,γ)³⁶Ar → (α,γ)⁴⁰Ca → (α,γ)⁴⁴Ca → (α,γ)⁴⁸Ti
```
[FACT] α 过程不同于 He 燃烧的关键点：**α 粒子来源**不同——此处来自中子源反应中的 ⁴He 产物。

## 3.6 恒星演化中的核燃料序列（III.E，P23–P29）[FACT]

- 温度序列：**H → He → C → Ne → O → Si → Fe**。
- 每步时间逐步缩短（因反应率对 T 强烈指数依赖）。
- 铁为终点：聚变不再放能。

## 3.7 恒星中子源（III.F，P29–P31）[FACT]

### 3.7.1 两大中子源 [FACT]

| 反应 | 提出者 | 条件 |
|---|---|---|
| **¹²C(α,n)¹⁶O** | Cameron (1954/55) & Greenstein (1954) | 红巨星 C/O 核心 |
| **²⁰Ne(α,n)²⁴Mg** | Fowler, Burbidge, Burbidge (1955) | 需要混合核心与包层（H+He 产物） |

### 3.7.2 中子密度估计 [FACT]

- ¹²C(α,n) 在红巨星内部提供**充足中子通量**以覆盖整个重元素合成，**但**需要**混合**（core-envelope mixing）。
- ²⁰Ne(α,n) 可避免混合问题，**但**需要某些条件满足。
- Tc⁹⁹ 的存在（Merrill 1952）证明 S 型星正在合成并混合到表面：时间 < Tc⁹⁹ 半衰期（2×10⁶ yr）。

### 3.7.3 超新星包层中的中子源（图 III.6）[FACT]

在超新星中，H 燃烧与 He 燃烧的副反应产生大量中子：
```
¹⁰B(n,α) + ¹⁶O(γ,n) + ²⁰Ne(α,n)²⁴Mg + ¹³C(α,n)¹⁶O
¹⁷O(α,n)²⁰Ne + ¹⁸O(α,n)²¹Ne ...
```
图 III.6 显示：所有 β 衰变时标都很短（秒级），中子可在 H 比 Ne²⁰ 多 1–5 倍时持续产生。

### 3.7.4 中子-质子平衡 [FACT]

在极高 T（>10⁹ K）下，中子-质子数比由**麦克斯韦-玻尔兹曼分布**决定：
```
n_n / n_p ≈ exp(-Δm·c² / kT)
```
Δm·c² = 1.293 MeV（中子-质子质量差）。
在 T~5×10⁹ K，n_n/n_p ≈ 0.5。

## 3.8 作者论证链

```
H 燃烧的 pp 链与 CN 循环给出 He⁴
→ 温度升高后 He 燃烧 3α→¹²C
→ 12C(α,γ)¹⁶O → 16O(α,γ)²⁰Ne → 20Ne(α,γ)²⁴Mg ...
→ 到 48Ti 因库仑势垒过大而终止
→ 中子源：12C(α,n) 与 20Ne(α,n) 为 s/r 过程提供"种子"中子
```

## 3.9 [INTERPRETATION]

1. **Hoyle 态（7.65 MeV）**是 3α 反应的关键：没有它，恒星内 ¹²C 生成率会**指数级**低——这就是著名的"碳共振"论据。
2. 16O(α,γ)²⁰Ne 反应截面决定了**宇宙中 O/C 比值**——这是 1957 年至今天仍在争论的中心问题。
3. 论文提出的两个中子源反应中，**¹²C(α,n)** 今日仍是 AGB 星 s 过程的主要中子源。

## 3.10 [CRITIQUE]

1. 论文明确提到 pp 反应截面"太小无法在实验室观测"——**今日已实现**：Borexino 实验（2008–2017）首次直接测量了太阳 pp 中微子通量，反推了 pp 反应速率。
2. 论文估计的 CN 循环能量释放（25.04 MeV）与今日标准值（26.73 MeV）**差异 ~6%**——来自 1955 年的核质量表（Wapstra）。
3. 论文的"恒星中子源"讨论忽略了今天已知的 **¹³C(α,n)** 反应——这是现代 AGB 星 s 过程**第一脉冲**的中子源。
