# 6. Details of the r Process（第 VII 章，P48–P59）

## 6.1 本节核心内容

第 VII 章深入阐述 r 过程的：(A) 路径（Z,A 平面中的快中子俘获轨迹）；(B) r 过程丰度的计算方法（"等待点"近似）；(C) 时间标度（稳态流与循环）；(D) 冻结（fission 终止）。

## 6.2 r 过程路径（VII.A，P48–P50）[FACT]

### 6.2.1 等待点 [FACT]

r 过程的**核心概念**——"等待点（waiting point）"：
- 在极高中子密度下，中子俘获极快。
- 但某些核素**中子分离能 Q_n 较小**——这些核素成为"等待点"。
- 在等待点上，中子俘获被"暂停"，$\beta$ 衰变进行。

**关键判据 [FACT]**：
```
如果 Q_n > Q_0（指定阈值，约 2 MeV），中子继续俘获
如果 Q_n < Q_0，$\beta$ 衰变发生
```

### 6.2.2 中子分离能公式 [FACT]

```
Q_n(A, Z) = M(Z, A-1) + m_n - M(Z, A)
```
其中 M(Z,A) 是核质量，m_n 是中子质量。

**论文明确指出 [FACT]**：
- 在中子幻数（N=50, 82, 126）附近，Q_n 出现**不连续下降**。
- 这导致 r 过程路径在幻数处**"等待"**，产生丰度峰。

### 6.2.3 中子分离能与质子分离能的关系 [FACT]

```
Q_n = M(Z, A-1) + m_n - M(Z, A)
Q_p = M(Z-1, A-1) + m_p - M(Z, A)
$\Delta$(Q_n - Q_p) = [M(Z, A-1) - M(Z-1, A-1)] + [m_n - m_p] - $\Delta$Q
```

### 6.2.4 f 函数 [FACT]

[FACT] 论文引入函数 **f(N)** 表示 A 附近的中子富集偏移：
```
f(N) = [M(Z, A) - M(Z-1, A)]_symmetry
```
即**对称能项**——决定 r 过程路径在 Z,A 平面中偏向中子富集一侧多少。

### 6.2.5 幻数区间的 Q_n 差异 [FACT]

[FACT] 论文对幻数 N=50, 82, 126 附近给出：
```
$\Delta$Q_n / $\Delta$A ≈ -0.25 to -0.10 MeV
```
（在 A=100 与 A=200 处分别确定数值）

**[INTERPRETATION]** 这一数值决定 r 过程路径在 (Z,A) 平面中"弯折"的程度。

## 6.3 r 过程丰度计算（VII.B，P44–P52）[FACT]

### 6.3.1 稳态流类比 [FACT]

[FACT] 论文指出，r 过程丰度也呈现**稳态流**的特征：
```
$\sigma_\gamma$(A)·N(A) = $\lambda_\gamma$(A-1)·N(A-1) = const
N(A) ∝ 1/$\sigma_\gamma$(A)
```

### 6.3.2 中子俘获截面 [FACT]

r 过程中，中子能量远高于热中子（~10–100 keV 量级）。因此使用中子俘获的**几何截面**：
```
$\sigma_\gamma$ ≈ $\pi$·(R + $\lambda$)$^{2}$ ≈ 几何截面（~4–5 barns）
```

### 6.3.3 等待点公式 [FACT]

在等待点（$\beta$ 衰变主导），丰度由 $\beta$ 衰变半衰期决定：
```
N(A_waiting) ∝ 1 / $\lambda_\beta$(A_waiting) = t_$\beta$(A_waiting) / ln2
```

### 6.3.4 $\beta$ 衰变能量 W_$\beta$ [FACT]

**关键公式 [FACT]**：
```
t_$\beta$ ∝ 1/W_$\beta^{5}$      （Fermi $\beta$ 衰变理论）
```

论文明确指出，对中子富集的重核：
```
W_$\beta$(A) ≈ 有效 $\beta$ 衰变能量（MeV）
```

### 6.3.5 平均过量中子结合能（图 VII.1）[FACT]

图 VII.1（P46）展示了 A 附近的**平均过量中子结合能**（相对于平滑的 Weizsäcker 原子质量公式）：

```
平均过量 $\Delta$B_n = B_n(实测) - B_n(Weizsäcker)
```

- 中子幻数 N=50, 82, 126 处出现**负峰**（结合能特别大 → 中子非常紧束缚 → Q_n 大 → 需要更多中子才能越过）。
- 球形形变稳定性在 N=152 附近出现（对应超重元素）。

## 6.4 r 过程的时间标度（VII.C，P52–P55）[FACT]

### 6.4.1 "稳态流" [FACT]

在持续中子照射下，各 A 的核素丰度达到稳态：
```
dN(A)/dt = $\lambda_\gamma$(A-1)·N(A-1) - [$\lambda_\gamma$(A) + $\lambda_\beta$(A)]·N(A) = 0
```

### 6.4.2 "循环"（Cycling）[FACT]

论文明确提出 r 过程的**循环**概念：
- 中子链从 Fe$^{56}$ 起运行到**裂变**（自发裂变或中子诱发裂变）。
- 裂变产物重新进入 Fe 族。
- 这一**循环**解释了为什么**每个 Fe 核能合成约 200 个中子**（对应约 10–20 次循环）。

**循环数估计 [FACT]**：
```
总中子数 ≈ 循环次数 × 每次循环的中子数（~10–20 中子/循环）
```

### 6.4.3 r 过程的总时间 [FACT]

[FACT] 论文估计 r 过程的总时间标度：
```
t_total ≈ 10–100 s
```
对应 ~200 中子/Fe 核的俘获量。

## 6.5 冻结（VII.D，P55–P59）[FACT]

### 6.5.1 中子照射终止 [FACT]

当超新星爆炸使中子源**突然停止**：
- 富中子的等待点核素开始**级联 $\beta$ 衰变**回到 $\beta$ 稳定线。
- 最终产生中子富集一侧的稳定同位素。

### 6.5.2 冻结时间 [FACT]

冻结时间 ~ 最后等待点的 $\beta$ 衰变半衰期（~秒级）。

### 6.5.3 重核的生成 [FACT]

[FACT] 论文明确指出，r 过程的最终产物包括：
- **铀 (U$^{235}$, U$^{238}$)**
- **钍 (Th$^{232}$)**
- **钚 (Pu$^{244}$)**（半衰期 $~8\times10^{7}$ yr，今日确认为 r 过程产物）

### 6.5.4 自发裂变终止（图 VII.4）[FACT]

图 VII.4（P50）：重核在 r 过程路径上的丰度分布，显示**中子诱发裂变**（N=152 附近，形变壳）与**自发裂变**（Cf$^{254}$, Fm$^{258}$）竞争。

**中子诱发裂变 [FACT]**：
- 在 N≈152 附近（形变壳），裂变势垒降低。
- 中子俘获到达 Fm$^{258}$ 附近时**自发裂变**（~370 µs）。

## 6.6 数值结果 [FACT]

### 6.6.1 r 过程丰度峰位置 [FACT]

| 幻数 | r 过程峰 | s 过程峰 |
|---|---|---|
| N=50 | A=80 | A=90 |
| N=82 | A=130 | A=138 |
| N=126 | A=194 | A=208 |

### 6.6.2 r 过程 A=194 峰的产生 [FACT]

[FACT] 论文明确说明：
- r 过程在 N=126 处堆积。
- 冻结后 $\beta$ 衰变链将 N=126 → A=194（Os$^{194}$, Ir$^{194}$, Pt$^{194}$, Au$^{197}$）。

## 6.7 作者论证链

```
高中子密度 
→ 中子链超越稳定线至等待点
→ 等待点：$\beta$ 衰变决定丰度
→ 幻数处 $\beta$ 衰变"堵塞" → 丰度峰
→ 裂变终止链
→ 冻结后级联 $\beta$ 衰变
```

## 6.8 [INTERPRETATION]

1. **等待点近似（waiting-point approximation）**——1957 年首次系统提出，今日仍是 r 过程理论的核心工具。
2. 论文明确预测 r 过程应能合成 U、Th——**今日已确认**。
3. 裂变终止（特别是中子诱发裂变在 N=152 附近）——这一预测今日仍是 r 过程研究的核心问题。

## 6.9 [CRITIQUE]

1. 论文使用的 Wapstra (1955) 原子质量表已被现代 **AME2020** 大幅改进——许多 r 过程路径附近的核质量至今仍是**实验盲区**。
2. 论文的"10–100 s"时间标度今日对应**r 过程场所**的估计：
   - 核心坍缩超新星（经典 r 过程场所，但现代模拟难以重现完整 r 过程）
   - **中子星并合（neutron star mergers, 2017 GW170817 后确认）**
   - 磁星驱动的超新星（magnetorotational SNe）
3. 论文提出的"裂变循环"概念今日**仍是活跃的 r 过程研究问题**——特别是超重核素（Z>92）的裂变性质。
