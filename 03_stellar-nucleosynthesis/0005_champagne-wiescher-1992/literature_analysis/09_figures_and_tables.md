## 9.2 Figure 1 — The Hot CNO Cycles（p. 43）

### 1. 图的目的
展示 **HCNO 循环**中的反应路径，区分不同温度下的主导路径。

### 2. 图型
反应路径图（反应核素以方框表示，箭头表示反应类型）。

### 3. 图中元素
- **粗箭头**：主导反应路径
- **细箭头**：高温下 ¹⁴O(α,p)¹⁷F 启动的分支路径
- **虚线箭头**：更高温度下跳出 HCNO 进入 rp-process 的路径

### 4. 关键反应路径

**主导循环（粗箭头）**：
¹²C(p,γ)¹³N(p,γ)¹⁴O(β⁺)¹⁴N(p,γ)¹⁵O(β⁺)¹⁵N(p,α)¹²C

**¹⁶O 分支**（低温）：
¹⁶O(p,γ)¹⁷F(β⁺)¹⁷O(p,α)¹⁴N → 回到主循环

**¹⁶O 分支**（高温）：
¹⁶O(p,γ)¹⁷F(p,γ)¹⁸Ne(β⁺)¹⁸F(p,α)¹⁵O

### 5. 关键观察
- HCNO 循环有**两个 β 等待点**：¹⁴O ($T_{1}$/₂ = 71 s) 和 ¹⁵O ($T_{1}$/₂ = 122 s)
- 18Ne 处标注 **$T_{9}$ = 0.5** 为跳出 HCNO 的温度门槛
- 跳出路径有三条：¹⁵O(α,γ)¹⁹Ne、¹⁸F(p,γ)¹⁹Ne、¹⁸Ne(α,p)²¹Na

### 6. 作者的解释
见正文 §2.1。

### 7. 与正文的关系
支撑 §2.1 对 HCNO 循环与 rp-process 过渡的定性描述。

### 8. 物理意义
HCNO 循环是**中等温度**（$T_{9}$ = 0.1–0.4）下氢燃烧的主力；图展示了**如何"漏出"**进入 rp-process。

### 9. 需要注意的问题
无。

## 9.3 Figure 2 — Transition from HCNO to rp-process（p. 44）

### 1. 图的目的
展示 HCNO → rp-process 过渡的核素图，标示稳定核素区域。

### 2. 图型
核素图（chart of nuclides），质子数 Z 为横轴，中子数 N 为纵轴。

### 3. 图中元素
- **阴影区域**：稳定核素
- 反应箭头沿稳定线 → 质子滴线

### 4. 关键观察
- HCNO 区：A ≈ 12–20 区域
- rp-process 起始：¹⁹Ne 或 ²¹Na 附近
- rp-process 路径位于**稳定线与质子滴线之间**

### 5. 作者的解释
见 §2.1 与 §4 引言。

### 6. 物理意义
直观展示 rp-process 的**拓扑位置**——它不是单一反应链，而是在质子滴线附近"蜿蜒"前进。

## 9.4 Figure 3 — Level Structure of the ¹⁸O–¹⁸Ne Analog Pair（p. 51）

### 1. 图的目的
比较 ¹⁸O 与 ¹⁸Ne 的能级结构，标示已确认的类比对。

### 2. 图型
双侧能级图，左为 ¹⁸O，右为 ¹⁸Ne。

### 3. 图中元素
- 激发能 Ex（MeV）纵轴
- J^π 标注每态
- 连接线标示**已确认的类比**（analog）对

### 4. 关键数值
- **¹⁸O 已知至 Ex ~ 8.28 MeV**（含 8.09, 7.91, 7.08, 6.88, 6.35, 5.45, 4.59, 3.58, 1.98, 0 MeV 态）
- **¹⁸Ne 已知至 Ex ~ 8.21 MeV**
- **¹⁸O 中 Ex = 6.198 MeV, J^π = $1^{-}$** → 类比 ¹⁸Ne 中 Ex ~ 6.13 MeV
- **¹⁸O 中 Ex = 5.38 MeV, J^π = $3^{+}$** → 类比 ¹⁸Ne 中 Ex ~ 4.56 MeV（Garcia 64 实验确认）

### 5. 关键观察
- ¹⁸Ne 中**若干态尚未发现**（与 ¹⁸O 相比缺失）
- 已知态的**类比对应**部分未完全建立（图中标注了已知连接）

### 6. 物理意义
此图是 §3.3 讨论 ¹⁴O(α,p)¹⁷F 与 ¹⁷F(p,γ)¹⁸Ne 反应率的**基础**——因反应率依赖于 ¹⁸Ne 的能级结构。

## 9.5 Figure 4 — rp-process Reaction Path at $T_{9}$ = 0.3, ρ = $10^{3}$（p. 67）

### 1. 图的目的
展示**低 T/低 ρ 条件**下 A = 20–60 质量区的 rp-process 反应流（10 s；虚线为 100 s 延展）。

### 2. 图型
核素图 + 反应流箭头。

### 3. 坐标
- 横轴 Z（质子数）10–18（Ne 至 Ar）
- 纵轴 A（质量数）10–36

### 4. 图中元素
- **阴影方块**：稳定核素
- **实线箭头**：10 s 积分主反应流
- **虚线箭头**：100 s 后额外加工路径

### 5. 关键观察
- HCNO 循环清晰（¹²C → ¹⁴O 等待点 → ¹⁴N）
- HCNO 与 NeNa 区**无连接**
- NeNa 循环闭环：²⁰Ne → ²¹Na → ²²Mg → ²²Na → ²³Mg → ²³Na → ²⁰Ne
- 弱流通过 SiP 区至 ⁴⁰Ca

### 6. 端点核素
- **t = 10 s**：**³²S**
- **t = 100 s**：**⁴⁰Ca**

### 7. 物理意义
在 nova 的低 $T_{9}$ 情形下，rp-process 被**Se 严重阻碍**——NeNa 与 SiP 循环是主要"囚笼"。

## 9.6 Figure 5 — Abundance Evolution at $T_{9}$ = 0.3（p. 68）

### 1. 图的目的
展示 $T_{9}$ = 0.3, ρ = $10^{3}$ 条件下 ²⁰Ne、²²Mg、³²S、⁴⁰Ca 同位素丰度随时间演化。

### 2. 坐标
- 横轴：时间 (sec)，对数坐标 $10^{-3}$ 至 $10^{2}$
- 纵轴：同位素丰度 (对数坐标，未标定量)

### 3. 图中元素（4 条曲线）
- ²⁰Ne（初始丰度，快速消耗）
- ²²Mg（快速上升至峰值 ~10 s 后衰减，因 $T_{1}$/₂ = 3.86 s）
- ³²S（缓慢上升，因 SiP 循环净积累）
- ⁴⁰Ca（更慢上升）

### 4. 关键数值
- ²⁰Ne 耗尽时间 ~1 s
- ²²Mg 峰值 ~10 s
- ³²S 持续增长（净积累）
- ⁴⁰Ca 100 s 后成为端点

### 5. 物理意义
³²S 作为 A = 20–32 物质的**最终汇**（10 s）直观可视化。

## 9.7 Figure 6 — rp-process Reaction Path at $T_{9}$ = 0.4, ρ = $10^{4}$（p. 70）

### 1. 图的目的
展示**中等 T/中等 ρ 条件**（极端 nova 峰条件）下的反应流（100 s 燃烧）。

### 2. 关键观察
- CNO → A~20 区有显著流（通过 ¹⁴O(α,p)¹⁷F → ¹⁸Ne → ¹⁹Ne → ²⁰Na → ²¹Mg）
- ²²Mg 处**分叉**为两条路径：
  1. ²²Mg(p,γ)²³Al → ... → ²⁷Si（绕过 NeNa 与 MgAl 循环）
  2. ²²Mg(β⁺)²²Na → 回到 NeNa 循环
- A ~ 40 区：SiP、SCl、ArK 三循环互连
- 经 ³⁹Ca(p,γ)⁴⁰Sc、⁴⁰Ca(p,γ)⁴¹Sc → CaSc 循环
- A = 50 区：⁴³Ti(p,γ)⁴⁴Y → ⁴⁴Ti(p,γ)⁴⁵Y；⁴³Sc(p,γ)⁴⁴Ti → ⁴⁵Y
- **端点 ⁵²Fe**

### 3. 端点核素
**⁵²Fe**（$T_{1}$/₂ = 8.28 h，弱 ⁵²Fe(p,γ)⁵³Co 衰变率）

### 4. 物理意义
在**极端 nova**条件下，rp-process 可以**完全绕过 NeNa/MgAl 循环**，直达铁峰。

## 9.8 Figure 7 — Abundance Evolution at $T_{9}$ = 0.4（p. 71）

### 1. 坐标
- 横轴：时间 (sec)，对数坐标
- 纵轴：同位素丰度（对数）

### 2. 图中元素（5 条曲线）
- ²⁰Ne：快速耗尽 (~1 s)
- ²²Mg：快速上升后下降
- ³⁴Ar：~10 s 达生产-衰变平衡，随后下降
- ⁴⁰Ca：显著增强
- ⁵²Fe：最终上升

### 3. 关键数值
- ²²Mg 有效半衰期 $T_{1}$/₂,eff = 2.4 s（因 (p,γ) 破坏）
- ⁵²Fe 为最终端点（$T_{1}$/₂ = 8.28 h）

### 4. 物理意义
展示中等温度下 rp-process 如何**逐级穿透等待点**，最终到达 ⁵²Fe。

## 9.9 Figure 8 — rp-process Reaction Path at $T_{9}$ = 1.5, ρ = $10^{6}$（p. 72）

### 1. 图的目的
展示**高温高密度**（X 射线暴）条件下的完整反应流。

### 2. 坐标
- 横轴 Z：1 (H) 至 36 (Kr)
- 纵轴 A：2 至 80

### 3. 关键观察
- **从 ⁴He 连续流至 ⁷³Kr**——反应网络的最大范围
- ¹²C 由**三聚反应**产生 → 快速转 ¹⁴O
- **轻等待点** ¹⁴O, ¹⁸Ne, ²²Mg, ²⁸Si, ³⁰S, ³⁴Ar **由 (n,p) 反应跨越**（np-process）
- **A > 38**：质子滴线附近的 (p,γ) + β⁺ 序列
- **⁵⁴Ni 粒子未束缚** → 路径经 ⁵³Co(β⁺)⁵³Fe(p,γ)⁵⁴Co(p,γ)⁵⁵Ni(p,γ)⁵⁶Cu(β⁺)⁵⁶Ni(p,γ)⁵⁷Cu
- **⁶⁴Ge** 是重要节点
- **⁷²Kr** 是最终端点（⁷³Rb 质子未束缚 → 终止）

### 4. 端点核素
**⁷²Kr**（$T_{1}$/₂ = 17.2 s）

### 5. 物理意义
X 射线暴条件下 rp-process 可到达**最重的核素**——但因不抛射，**宇宙学贡献为零**。

## 9.10 Figure 9 — Abundance Evolution at $T_{9}$ = 1.5（p. 73）

### 1. 坐标
- 横轴：时间 (sec)，对数坐标 $10^{-1}$ 至 $10^{2}$
- 纵轴：同位素丰度（对数，$10^{0}$ 至 $10^{-8}$）

### 2. 关键时间线
| 时间 | 事件 |
|------|------|
| 0.5 s | CNO 与 NeNa → ³⁴Ar |
| 1 s | (α,p) → ³⁸Ca |
| 1.5 s | ⁵⁵,⁵⁶Ni 达峰值 |
| 5 s | 大部分物质到达 ⁶⁴Ge |
| 20 s | ⁷²Kr 达峰值 |

### 3. 物理意义
⁶⁴Ge 是**"暂态端点"**——其丰度缓慢下降，因 ⁶⁴Ge(p,γ)⁶⁵As 与 ⁶⁴Ge(β⁺)⁶⁴Ga 均弱。
