# 2. Nuclear Reactions During an Outburst (p. 42–47)

## 2.1 本节核心内容

建立爆炸性氢燃烧下的**反应网络**概念框架，并给出热核反应率的**标准形式**（Gamow 峰、S 因子、Breit-Wigner 共振）。

## 2.2 章节 2.1: Reaction Networks (p. 42–45)

### 2.2.1 温度-密度范围

**[FACT]** 考虑的产生场所温度为 **$T_{9}$ = 0.1–1.5**，密度为 **$\rho$ = $10^{3}$–$10^{8}$ g cm⁻³**。

### 2.2.2 HCNO 循环的由来

**[FACT]**

- 若种子为 C、O，反应网络**形似**氢流体静力学燃烧的 CNO 循环。
- 关键区别：**爆炸性燃烧中核反应时标可比或短于 $\beta$ 衰变时标**。
- 因此在 $^{12}{\rm C}$(p,$\gamma$)$^{13}{\rm N}$ 之后，**$^{13}{\rm N}$ 的 $\beta^{"+" if m.group(1)=="⁺" else "-"}$ 衰变 ($T_{1}$/₂ = 9.97 min) 被 $^{13}{\rm N}$(p,$\gamma$)$^{14}{\rm O}$ 反应绕过**——这就是 **Hot CNO (HCNO)** 循环的起源 (13–17)。

### 2.2.3 HCNO 主循环路径

**[FACT]** 从 $^{16}{\rm O}$ 进入 HCNO 的路径分两段：

- **低温段**（$T_{9}$ ≲ 0.2）：
  $^{16}{\rm O}$(p,$\gamma$)$^{17}{\rm F}$($\beta^{"+" if m.group(1)=="⁺" else "-"}$)$^{17}{\rm O}$(p,$\alpha$)$^{14}{\rm N}$(p,$\gamma$)$^{15}{\rm O}$
- **高温段**（$T_{9}$ ≳ 0.2）：
  $^{16}{\rm O}$(p,$\gamma$)$^{17}{\rm F}$(p,$\gamma$)$^{18}{\rm Ne}$ …（继续向重核推进）

**[FACT]** 主循环内能量产生速率受限于 $^{14}{\rm O}$ 与 $^{15}{\rm O}$ 的 $\beta^{"+" if m.group(1)=="⁺" else "-"}$ 衰变（$T_{1}$/₂ = 71 s 和 122 s）——因此平衡时催化物质以 $^{14}{\rm O}$、$^{15}{\rm O}$ 形式存在，最终在 nova 抛射物中以 **$^{14}{\rm N}$、$^{15}{\rm N}$** 富集。

**[FACT]** $^{15}{\rm N}$ 相对 $^{14}{\rm N}$ 富集，因为 $^{15}{\rm O}$ 的半衰期比 $^{14}{\rm O}$ 长。

### 2.2.4 跳出 HCNO 的路径

**[FACT]** 当温度升高到 **$T_{9}$ → 0.4**：

- $\alpha$ 诱导反应开始起作用，14O 的 waiting point 被序列 $^{14}{\rm O}$($\alpha$,p)$^{17}{\rm F}$(p,$\gamma$)$^{18}{\rm Ne}$($\beta^{"+" if m.group(1)=="⁺" else "-"}$)$^{18}{\rm F}$(p,$\alpha$)$^{15}{\rm O}$ 绕过，能量产生速率加快。
- 更高温度下，可**跳出 HCNO 进入 rp-process**，通过以下任一反应：
  - $^{15}{\rm O}$($\alpha$,$\gamma$)$^{19}{\rm Ne}$
  - $^{18}{\rm F}$(p,$\gamma$)$^{19}{\rm Ne}$
  - $^{18}{\rm Ne}$($\alpha$,p)$^{21}{\rm Na}$

**[FACT]** 一旦到达 $^{19}{\rm Ne}$ 或 $^{21}{\rm Na}$，将启动**一系列快速质子与 $\alpha$ 诱导反应**——即 **rp-process** (18, 19)。

**[FACT]** rp-process 也可能被**预爆炸的 Ne、Na、Mg 丰度**触发，**无需 HCNO 直接喂养**。

**[FACT]** rp-process 产物可能是新星 Cyg 1975、Aquilae 1982、CrA81、Vulpeculae 抛射物中观测到的 **Ne、Na、Mg、Al 丰度异常增强**的根源 (20–23)。

### 2.2.5 rp-process 的反应路径位置

**[FACT]**

- rp-process 路径位于**稳定线**与**质子滴线**之间。
- 其走向由**带电粒子反应速率与 $\beta$ 衰变速率的竞争**决定。
- 反应速率随温度指数上升；$\beta$ 衰变速率近似温度无关。
- 低温时二者可比，路径贴近稳定线；高温时反应更快，路径贴近质子滴线。
- 向重质量方向流动受限于：
  1. rp-路径上最慢的反应；
  2. $\beta$ 衰变 waiting points；
  3. 光裂（photodisintegration）反应；
  4. 反应循环（reaction cycles）。

**[FACT]** 粗略估计 rp-process 中核合成可达铁峰元素或更重，能量产生速率约为 HCNO 主循环的 **100 倍** (18)——**足以驱动 X 射线暴**。

### 2.2.6 反应率测量现状（作者评价）

**[FACT]**

- 只有 **$^{13}{\rm N}$(p,$\gamma$)$^{14}{\rm O}$** 的反应率被以合理精度测得（±13%）。
- **$^{15}{\rm O}$($\alpha$,$\gamma$)$^{19}{\rm Ne}$** 反应率不确定度在 2 倍以内。
- 其他许多反应的估计来自 Wagoner et al. (24) 和 Wagoner (25)；**这些早期估计已被大量新的核光谱学数据取代**。
- 但目前基于最新实验与理论结构信息的估计**仍不确定 5–1000 倍**。
- **[FACT]** "Because of these large uncertainties, models of cataclysmic binaries rely on rather suspect nuclear reaction input."

**[CRITIQUE]** 这句话是本文的**核心判断**——它奠定了整篇文章的基调：核反应率的"数据基础"仍是核天体物理的**瓶颈**。

## 2.3 章节 2.2: Thermonuclear Reaction Rates (p. 45–47)

### 2.3.1 标准反应率公式

**[FACT]** 热核反应率定义为 $\sigma$(E)·v 对 Maxwell 速度分布的均值：

$$\langle\sigma v\rangle = \left(\frac{8}{\pi\mu}\right)^{1/2} (kT)^{-3/2} \int_0^\infty \sigma(E) \, E \, \exp\left(-\frac{E}{kT}\right) \, dE \tag{2}$$

- **$\mu$** 约化质量
- **k** 玻尔兹曼常数
- **$\sigma$(E)** 反应截面
- **E** 质心系能量

### 2.3.2 库仑穿透与 Gamow 峰

**[FACT]** 非共振截面在低能下由库仑 + 离心势穿透因子主导：

$$\sigma_{\text{nonres}}(E) \propto \exp\left[-\left(\frac{E_G}{E}\right)^{1/2}\right] \tag{\text{3 中的因子}}$$

其中 **Gamow 能量**：

$$E_G = \frac{2\pi^2 e^4 Z_a^2 Z_b^2 \mu}{\hbar^2} \tag{3}$$

- **Z** 核电荷
- 此能量依赖导致积分 (2) 仅在受限能量区（**Gamow 峰**）内显著。
- 该区域即为截面测量的**关键能区**：
  - HCNO 中 (p,$\gamma$) 反应：**25 keV 至 1.1 MeV** (c.m.)
  - rp-process 上端：**150 keV 至 2.5 MeV**

### 2.3.3 S 因子参数化

**[FACT]**

$$\sigma(E) = \frac{S(E)}{E} \exp\left[-\left(\frac{E_G}{E}\right)^{1/2}\right] \tag{4}$$

- **1/E** 因子来自核截面中的 $\lambda^{2}$ 项
- **S(E)** = 天文 S 因子（含非运动学部分，通常随能量缓慢变化）——允许对式 (2) 做数值积分或解析近似 (26–29)。

### 2.3.4 Breit-Wigner 单共振形式

**[FACT]** 若截面由共振 E_r 主导：

$$\sigma(E) = \pi\lambda^2 \omega \frac{\Gamma_a \Gamma_b}{(E - E_r)^2 + \Gamma^2/4} \tag{5}$$

- **$\lambda$** = 约化康普顿波长
- **$\omega$** = 自旋统计因子
- **$\Gamma_{\rm a}$, $\Gamma_{\rm b}$, $\Gamma$** = 入射/出射道分宽度与总宽度

**[FACT]** 对**孤立窄共振**（$\Gamma$ ≪ E_r），式 (2) 可积分得到：

$$\langle\sigma v\rangle = \left(\frac{2\pi}{\mu}\right)^{3/2} \frac{\hbar^2}{(kT)^{3/2}} \omega\gamma \exp\left(-\frac{E_r}{kT}\right) \tag{6}$$

其中 **共振强度** $\omega$$\gamma$ = $\omega$·$\Gamma_{\rm a}$·$\Gamma_{\rm b}$/$\Gamma$。

**[FACT]** 各共振贡献**简单相加**；但若共振宽或重叠，必须**数值积分**式 (2)。

### 2.3.5 统计模型与 Hauser-Feshbach

**[FACT]** 当许多共振（可能重叠）贡献时，截面呈**统计特征**；此时**能级密度、质量、能量学**比单个共振性质更重要。对稳定核，**Hauser-Feshbach 计算**能精确复现这些截面 (30, 31)。

**[INTERPRETATION]** 这里已经埋下后文反复使用的判据：

> 能级密度 ≳ 10/MeV → 可用 Hauser-Feshbach；否则需逐共振处理。

### 2.3.6 测量方法：放射性束 vs. 间接核光谱

**[FACT]** 大多数目标反应需要**放射性束**或**放射性靶**。放射性束方法优于放射性靶（后者对半衰期 < 数小时的靶有严重本底问题，而这类靶恰好是兴趣靶）。

**[FACT]** 互补方法是**传统的核光谱学**：用稳定束 + 稳定靶产生**复合同位素**（compound nucleus），通过测量激发能、自旋宇称、宽度、衰变分支确定所有共振信息（式 6 中所需参数）。

## 2.6 作者的逻辑

```
三类场所 → 温度/密度范围 → 决定反应时标相对β衰变
   ↓ 反应时标 ≪ $\beta$ 衰变时标 → HCNO 循环
   ↓ HCNO 内反应饱和 → 跳出到 rp-process
   ↓ rp-process 由 $\beta$ 衰变、光裂、循环三种阻抗调节
   ↓ 反应率的理论形式：非共振 (S 因子) + 共振 (BW) + 统计 (HF)
   ↓ 测量途径：放射性束 / 间接核光谱
```

## 2.7 潜在问题与值得关注之处

1. **[CRITIQUE]** 作者提到"rp-process 能量产生速率约为 HCNO 主循环的 100 倍"——但后文计算中 rp-process 路径因 **impedance effects** 而大大减慢。因此"100 倍"指的是**理想情况下（无 waiting points 时）的功率**，而非实际净能量释放。
2. **[FACT]** 只有两个反应的速率被较好约束：$^{13}{\rm N}$(p,$\gamma$)$^{14}{\rm O}$（±13%）和 $^{15}{\rm O}$($\alpha$,$\gamma$)$^{19}{\rm Ne}$（因子 2）。
3. **[CRITIQUE]** 现代核天体物理已在此后的 30 年中大幅推进：放射性束设施（FRIB、FAIR、RIBF、HIE-ISOLDE）已使本文列为"难以测量"的许多反应（如 $^{19}{\rm Ne}$(p,$\gamma$)$^{20}{\rm Na}$）得到约束。1992 年的"5–1000 倍"不确定性**已大为降低**，但部分 rp-process 中段核素（A ≈ 60–70）的实验数据仍稀缺。
