## 0.3 全文论证链

```
古代对"不可见物质"的猜想
→ Kelvin / Poincaré / Kapteyn / Oort 首次动力学估计银河系暗物质
→ 1933 Zwicky 用维里定理发现 Coma 星系团存在暗物质
→ 1930s-1950s：星系自转曲线初步探测，M31 等
→ 1970s：Freeman 1970、Roberts & Rots 1973、Bosma 1978、Rubin et al. 1978
    确立平坦自转曲线 → 大量"隐形质量"
→ 1974 Einasto/Kaasik/Saar & Ostriker/Peebles/Yahil 提出"大质量晕"概念
→ 1973 Ostriker-Peebles：旋转盘需嵌入大质量晕才稳定
→ MACHO 微引力透镜探测（1993-）+ BBN/CMB 重子预算 → 排除重子暗物质
→ 1982 Milgrom 提出 MOND（及其 TeVeS 相对论化）作为替代
→ 1966 Gershtein-Zeldovich 首次考虑宇宙学中的中微子
→ 1982 Pagels-Primack、1981 MSSM、1983 Weinberg/Goldberg → 中性微子候选
→ 1977 Peccei-Quinn、1978 Wilczek/Weinberg → 轴子
→ 1980s 末：冷暗物质（CDM）范式确立（数值模拟 + CfA 巡天）
→ 1996 NFW 普适晕密度分布
→ 1985 Goodman-Witten → 直接探测原理
→ 1978 Gunn et al. / Stecker → 间接探测（γ射线）
→ 1983 Sikivie → 轴子探测（ADMX）
```
