## 4.1 本节核心内容

rp-process（rapid proton-capture process）是比 HCNO 更高温、更高速的核合成路径，路径介于稳定线与质子滴线之间，受四类**阻抗效应 (Impedance Effects)** 调控：β 等待点、光致分解、瓶颈反应、反应循环。作者逐一分析 19Ne(p,γ)20Na（触发反应）、早期 rp（20Na/22Na/26Al 通道，与 γ 射线天文学直接相关）、A = 30–60 的反应速率，以及 A = 56Ni 附近的滴线物理。

## 4.2 §4.1 反应速率通论 [FACT]

- A > 20 稳定核附近 (p,γ) 通常有**较高 Q 值**（~5 MeV 以上），复合核能级密度高 → **Hauser-Feshbach 计算**适用。
- 对稳定靶核，HF 计算与实验速率**符合极好**（Ref. 31）。
- **对不稳定核（近滴线 / 近闭壳），此法不可信**：
  - 复合核在低激发能形成 → 低能级密度；
  - 速率由**孤立共振 + 非共振直接俘获**决定；
  - 需要直接测量或基于复合核谱学性质计算。
- **[FACT]** 直接测量需放射性靶或放射性束；放射性靶对长寿命核可行，**放射性束技术在 1990 年代初仍发展中**（Ref. 74-77）。
- **[FACT]** 轻核放射性束测量已初步成功，但 rp 路径上重核的库仑势垒更大，截面更小，直接测量更困难。

## 4.3 §4.2 19Ne(p,γ)20Na 反应——rp-process 触发反应

### 4.3.1 理论估算 [FACT]

- Wallace & Woosley (18)：借用 20F 已知谱构（无位移修正）→ 类比 20Na。
- Langanke et al (68)：加入 **Thomas-Ehrman 位移**计算；单粒子方势波函数 + 由漫势还原宽度约束位移大小；系统误差存在。

### 4.3.2 实验进展

- Lamm et al (78)：**20Ne(³He,t)20Na** 测量质子未束缚态激发能。
- 后续更高分辨 (79)：20Ne(³He,t) + 20Ne(p,n) 复核；早期部分态系污染反应（Ref. 80）。
- **修订速率 (79)：在 T9 = 0.5 时约为理论 (68) 的 100×**——差异来自共振能不同。
- **主贡献共振：Ecm = 445 keV（Ex = 2.644 MeV），Jπ = 1⁺**（由 (³He,t) 与 (p,n) 角分布推得）。
- **[CRITIQUE]** 速率 (79) 直接采用 (68) 的共振参数（未修正能量差异），质子宽度对能量极敏感 → **速率 (79) 有误**。

### 4.3.3 确认性测量

- Smith et al (82)：植入 20Ne 靶，分辨率最优：
  - **共振能 Ecm = 447±5, 658±5, 787±5, 857±5 keV**
  - 最低共振最重要；假设为 1⁺ 类比态（对应 20F 中 3.173 MeV 粒子-空穴态）
  - 共振强度主要由 **Γγ** 决定；
  - **[FACT]** 即使类比 E1 强度已知，此质量区粒子-空穴态系统学**仍不允许简单 E1 估算** → **速率不确定度可能达几个数量级**。

### 4.3.4 自旋宇称争议

- Descouvemont & Baye (83)：三集团微观模型预测 20F 中 3.173 MeV 态 **Jπ = 1⁻**（及其 20Na 类比态）；
- B. A. Brown et al（私人通信）：基于谱学与壳模型，**Jπ = 0⁻ 更受偏好**；
- **[FACT]** 若确认为 0⁻，则因 M1 衰变强度相对于 1⁺ 的 E1 **被抑制**而大幅增强 → **速率至少提高 10×**。

### 4.3.5 直接测量尝试

- 20Mg β 衰变未观测到该态（84）；20O β 衰变未观测到类比态（85）——**与 Jπ = 0⁻ 或 1⁻ 一致**，但对确定 Jπ 无最终裁决。
- 加速 19Ne 束已发展（Ref. 86，Galster et al.），直接测量即将可行。
- **12C(19Ne,p)19Ne** 直接散射：观测到 Ecm = 839 与 904 keV 共振；最低共振可能对应 (³He,t) 研究的 Ecm = 857±5 keV。
- **[FACT]** 最终天体速率还需包含 **19Ne 激发态贡献**（§3.6.1）。

## 4.4 §4.3 早期 rp-process：20Na(p,γ)21Mg、22Na(p,γ)23Mg、26Al(p,γ)27Si

### 4.4.1 20Na(p,γ)21Mg

- 24Mg(³He,⁶He)21Mg 反应研究 21Mg 能级（Ref. 87）；
- **[FACT]** 21F–21Mg 类比对的能级位移比此前假设更大（Ref. 18, 19）；
- **[FACT]** 反应速率可能比原先预期**低两个数量级**。

### 4.4.2 22Na(p,γ)23Mg 与 26Al(p,γ)27Si

这两个反应控制 **22Na（T1/2 = 2.61 yr）** 与 **26Al（T1/2 = 7.2×10⁵ yr）** 的产额——可通过 COMPTEL、NUSTAR 等空间 γ 射线探测器直接观测。

#### 22Na(p,γ)23Mg

- **[FACT]** 24Mg(³He,α)23Mg 与 24Mg(p,d)23Mg 转移反应：精确激发能、Jπ（Ref. 92, 93）；
- 22Na + p 阈值附近（Q = 7.554 MeV）能级密度高 → **统计模型 (HF) 适用**；
- 早期直接测量（蒸发 22Na 靶）因污染与本底失败（Ref. 95）；
- **[FACT]** Seuthe et al. (96)：植入 22Na 靶，NaI + D2O 探测器，能量范围 **0.17–1.29 MeV**，观测多个 >0.29 MeV 共振；
- **[FACT]** 结果：共振能与转移反应一致 → **T9 = 0.3–1.5 速率精确**；HF 计算重现。

#### 26Al(p,γ)27Si

- **[FACT]** Buchmann et al. (98)：7 个孤立共振，**276 ≤ Ecm ≤ 893 keV**；
- Vogelaar (99)：额外 7 个共振；
- **[FACT]** **T9 ≥ 0.15 速率充分理解**；
- **[FACT]** 低温区 (T9 < 0.15) 需壳模型计算（Champagne 私人通信，未完成）；
- **[FACT]** T9 ≥ 0.4 时 26Al 基态与第一激发态（Ref. 103）**达到热平衡**，激发态效应必须包含。

## 4.5 §4.4 A = 30-60 的 rp-Process

### 4.5.1 T = 0 偶偶核 (p,γ) 反应

- **[FACT]** T9 ≤ 0.5 时，A = 30–50 流经由 **28Si、32S、36Ar、40Ca** 的 (p,γ)；
- Q 值低、能级密度低 → 孤立共振主导；
- **[FACT]** 均已通过**固体靶+质子束**直接测量（Ref. 65, 104, 105）；速率由激发函数精确确定。

### 4.5.2 铁区与 56Ni(p,γ)57Cu

- **[FACT]** 铁区反应流经过 **56Ni**（T1/2 = 6.1 d，但爆发期间近似稳定）。
- 56Ni(p,γ)57Cu 直接测量目前不可行；从核谱学获得：
  - Q = **740 keV**（57Cu 新质量测量，Ref. 106-108）
  - **58Ni(⁶Li,⁸He)57Cu (107)** 与 **58Ni(¹⁴N,¹⁵C)57Cu (108)**：两个质子未束缚态 Ex = **1.04 与 2.52 MeV**
  - 57Ni 类比态 Thomas-Ehrman 位移计算 → 每个 57Cu 态为**二重态**
  - 均为强单粒子态；质子宽度由单粒子谱因子估计 → 主要贡献
- **[FACT]** 速率不确定度**至少一个数量级**。

## 4.6 §4.5 Impedance Effects（阻抗效应）

Woosley (73) 仅从库仑势垒估计 rp 在电荷数与质量数上随时间的推进——**实际反应流可能被四种类阻抗效应显著延迟**：

### 4.6.1 等待点 (Waiting Points)

- 反应流到达质子滴线（单质子未束缚）时，(p,γ) 不再可能；
- 只能通过 β⁺ 或 EC 衰变；
- 等待点核素通过绘制质子滴线与测半衰期确定；
- **[FACT]** A = 20–40 质子滴线已确立于 24Si、29S、33Ar、37Ca、38Ca、41Ti 等（Ref. 65）。
- **[FACT]** 更高质量区原子质量预测（109）存在分歧：43V、47Mn、50,51Co、60Ga、55As、59Br、73Rb 是否质子束缚。
- **[FACT]** Mohar et al. (110) 系统研究 A = 50–100：
  - 61Ga、65As、69Br 寿命 **≥ 150 ns**；
  - **73Rb 未观测到 → 质子滴线在 72Kr**。
- **[FACT]** 72Kr 半衰期 **17.2 s** → rp 持续时间 <17 s 时终止于 72Kr。

### 4.6.2 光致分解 (Photodisintegration)

- 偶偶 T = 1 核的 (p,γ)（²²Mg、²⁶Si、³⁰S、³⁴Ar、⁴²Ti、⁴⁶Cr 等）Q 值很小（Q ≲ 0.5 MeV），高温下被 T = 3/2 复合核的光致分解**强烈抑制**；
- 若光致分解速率 > (p,γ) 速率 → 进一步反应停止，直到 T = 1 核 β 衰变；
- **[FACT]** T = 1 与 T = 3/2 核达到平衡丰度 → 第二个 (p,γ) 可能跨越 T = 3/2 核；
- **[FACT]** 高温高密度下 (p,γ) 涉及孤立共振（第一、二激发态）+ 到基态的直接俘获；
- **[FACT]** T = 3/2 核低激发态的实验知识**非常有限**。
- **[FACT]** 例：22Mg(p,γ)23Al —— 23Al 第一激发态 Ex = **460 ± 60 keV**（Ecm = 360 ± 60 keV，Ref. 111）；
  - 自旋宇称采用镜像态 23Ne；
  - 谱因子与 B(E2) 用 Brown-Wildenthal sd 模型 (112) 计算；
  - **[FACT]** 作者强调：这些能级参数**需实验验证**。

### 4.6.3 瓶颈反应 (Bottleneck Reactions)

- T = 1/2 奇偶核 (p,γ)（²³Mg、²⁷Si、³¹S、³⁵Ar、³⁹Ca、⁴³Ti、⁵⁵Ni）Q 值低（Q ≲ 2.0 MeV）；
- 速率由孤立共振 + 非共振直接俘获决定；
- **HF 方法不适用**；
- **[FACT]** T9 < 1 时这些是**通往更重元素的唯一通道** → 定义为"瓶颈"。
- **[FACT]** **31S(p,γ)32Cl**（Q = 1.574 MeV）：
  - SiP 循环的重要分支出口；
  - 阈值至 Ecm = 1 MeV 之间已定位 3 个态（³²Se(³He,t)³²Cl，Ref. 113, 114）；
  - 两个测量激发能相差 ~20 keV，后者与 32Ar β 延迟 α 衰变一致；
  - 共振参数取自 32P 类比态；
  - **[FACT]** T9 典型值下速率**完全由 Ecm = 568 keV (Ex = 2.142 MeV, Jπ = 3⁺) d-波共振**决定；
  - ρ ≤ 10⁶ 时 31S β 衰变远快于 (p,γ) → **该反应是重质量通道瓶颈**。

### 4.6.4 反应循环 (Reaction Cycles)

- T9 ≲ 0.4 时，不稳定奇偶 T = 1/2 核（²³Mg、²⁷Si、³¹S、³⁵Ar、³⁹Ca、⁴³Ti）优先 β⁺ 衰变到 ²³Na、²⁷Al、³¹P、³⁵Cl、³⁹K、⁴³Sc；
- 这些核的 (p,γ) 与 (p,α) 通道同时开放：
  - (p,γ)：继续向重质量推进；
  - (p,α)：闭合循环 → **NeNa, MgAl, SiP, SCi, ArK, CaSc cycles**；
- **[FACT]** 反应分支比 b = (p,α)/(p,γ)：
  - 循环使物质存储于循环中 over b·T 周期；
  - 循环作为流量阻抗，时间常数 **b·T**（温度依赖）；
- **[FACT]** (p,γ) 通道：高激发能（Ex = 8–12 MeV），高能级密度，HF 适用；
- **[FACT]** (p,α) 通道：仅自然宇称 T = 0 态开放，能级密度可能不够 → HF 不一定可靠。

#### 实测循环分支比 [FACT]

| 循环 | 反应对 | 分支结果 |
| --- | --- | --- |
| **NeNa** | 23Na(p,γ)24Mg vs 23Na(p,α)20Ne | T9 ≳ 0.2 时大部分通过 23Na(p,α)20Ne **再循环** |
| **MgAl** | 27Al(p,γ)28Si vs 27Al(p,α)24Mg | T9 = 0.2 时仅 **0.1–1%** 循环；更高 T9 约 **10%** → 大部分流向重质量 |
| **SiP** | 31P(p,γ)32S vs 31P(p,α)28Si | 31P(p,α) 中仅 **一个**强共振（383 keV）；31P(p,γ) 中 >250 keV 多个共振；**T9 ≥ 0.4 可靠** |

## 4.8 作者的逻辑

1. 一般速率方法（HF 适用/不适用）→ 2. 触发反应 19Ne(p,γ)20Na → 3. 早期 rp 通道（与 γ 天文学联系）→ 4. 中质量区稳定靶核（精确）→ 5. 铁区与滴线附近 → 6. 系统性阻抗效应分类与量化。

## 4.9 我的理解 [INTERPRETATION]

- 四类阻抗效应构成 rp-process 的**"交通模型"**：等待点 = 红绿灯；光致分解 = 逆向流；瓶颈反应 = 单行道；反应循环 = 环岛。
- 19Ne(p,γ)20Na 的 Jπ 争议揭示：rp-process 速率的不确定度可能达 **数个数量级**——作者明确指出，这一反应速率直接决定 X 射线暴 rp 能否真正发生。
- 22Na、26Al 通道是唯一能与**观测**（空间 γ 射线）直接对比的 rp-process 部分——这是核天体物理中"可检验"的关键窗口。
- 作者对 56Ni 附近反应流的分析预见了后来的"56Ni 瓶颈"讨论（Fowler et al. 1997）。

## 4.10 潜在问题与值得关注的地方 [CRITIQUE]

- **Jπ 争议的影响**：19Ne(p,γ)20Na 447-keV 共振的 Jπ 若为 0⁻，速率提高 10×——这会改变 X 射线暴 rp 能否突破到中等质量区。
- **22Na 与 26Al 的观测**：本文写作时 COMPTEL 已有观测（Ref. 88-91）；后续 INTEGRAL 卫星（2002+）给出更精确 26Al 银河盘分布，验证了超新星主导起源的假设。
- **73Rb 束缚性问题**：若 73Rb 质子束缚（后续研究有不同结论），rp 终点可推至 74Rb 或更远——决定 X 射线暴是否产生 A > 72 核素的关键。
- 本文"X 射线暴不是核合成贡献者"（§1.2）——被后来 rp/x 过程研究推翻（见 Batan & Fuller 2013）。
