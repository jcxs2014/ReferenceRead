# 7. The rp-Process (下)：§4.4–4.5 Impedance Effects (p. 61–66)

## 7.1 本节核心内容

讨论 **A = 30–60** 的 rp-process 段，以及**四种阻抗效应（impedance effects）**——等待点（waiting points）、光裂（photodisintegration）、瓶颈（bottlenecks）、反应循环（reaction cycles）——决定 rp-process 最终能到达何处的物理机制。

## 7.2 章节 4.4: The rp-Process for A = 30–60

### 7.2.1 T₉ ≳ 0.5 反应流

**[FACT]** A = 30–50 质量区，反应流**期望经过 T = 0 的偶偶核**的 (p,γ) 反应：

$$^{28}\text{Si},\ ^{32}\text{S},\ ^{36}\text{Ar},\ ^{40}\text{Ca}$$

**[FACT]** 这些反应**Q 值低、能级密度低** → **孤立共振主导**。

**[FACT]** 通过**高强度质子束轰击固体靶**直接测量 (65, 104, 105) → **反应率从测量的激发函数中精确确定**。

**[FACT]** **[FACT]** 此处是本文的一个**罕见"确定性"区域**：稳定偶偶核 (p,γ) 反应的速率**确实已知**。

### 7.2.2 铁区与 ⁵⁶Ni

**[FACT]** 反应流在铁区**期望经过 ⁵⁶Ni**。

**[FACT]** ⁵⁶Ni 在地球上是短寿命的（T₁/₂ = **6.1 天**），但在**爆发短时标**内**本质稳定** → 可能是**超越 Fe-Ni 质量的重要链**。

**[FACT]** ⁵⁶Ni(p,γ)⁵⁷Cu 反应目前**无法直接测量**——但核光谱学提供了相关信息：

- **Q 值**（Q = **740 keV**）来自 ⁵⁷Cu 近期质量测量 (106–108)
- ⁵⁸Ni(⁶Li,⁸He)⁵⁷Cu (107) 与 ⁵⁸Ni(⁴N,¹⁵C)⁵⁷Cu (108) 反应观测到 **Ex = 1.04 和 2.52 MeV** 两个质子未束缚态
- Thomas-Ehrman 位移计算（⁵⁷Ni 中已知态）表明每个 ⁵⁷Cu 态都是**双重态 (doublet)** (108)
- 所有态预期为**强单粒子态**
- 质子宽度由这些态的**单粒子谱因子估计**→ 反应率的主要贡献者
- **不确定度至少一个量级**——因核结构**不够清楚**
- **验证需要放射性束的直接测量**

## 7.3 章节 4.5: Impedance Effects

**[FACT]** Woosley (73) 基于库仑势垒估计了 rp-核合成随时间在电荷和质量上的推进——但**反应流可能被阻抗效应显著延迟**，即物质在**某质量范围内"存储"**一段时间后才能进一步加工。

**[FACT]** rp-process 内原则上可运作的**四种阻抗效应**：

1. **等待点（Waiting Points）**
2. **光裂（Photodisintegration）**
3. **瓶颈反应（Bottleneck Reactions）**
4. **反应循环（Reaction Cycles）**

**[FACT]** A = 20–40 质量区，这些效应的核结构系统学**理解良好**；但 A = 40–70 区，**质子滴线附近核的实验信息缺乏**，**一般预测困难**。

### 7.3.1 §4.5.1 Waiting Points

**[FACT]** 一旦反应流抵达**质子滴线内侧一个质子**，进一步质子俘获**不可能**（复合核粒子未束缚）——只能靠 **β⁺ 或电子俘获**衰变消耗。

**[FACT]** 重核合成**必须等待这些衰变**——这就是**等待点**。

**[FACT]** 识别等待点需要**质子滴线映射**和**寿命测量**——对**确定高温 rp-process 端点**至关重要。

**[FACT]** A = 20–40 区质子滴线已确立在：

$$^{24}\text{Si},\ ^{29}\text{S},\ ^{33}\text{Ar},\ ^{37}\text{Ca},\ ^{38}\text{Ca},\ [^{41}\text{Ti}],\ \ldots$$

**[FACT]** 更高质量和特别在 **⁴³V, ⁴⁷Mn, ⁵⁰,⁵¹Co, ⁶⁰Ga, ⁵⁵As, ⁵⁹Br, ⁷³Rb** 处，**不同原子质量预言**（109）对这些核**质子束缚/未束缚**状态**存在分歧**。

**[FACT]** A = 50–100 富质子核的系统学研究 (110) 表明 **⁶¹Ga, ⁶⁵As, ⁶⁹Br 的寿命至少 150 ns**。

**[FACT]** **⁷³Rb 未被观测** → 暗示 **⁷²Kr 处为等待点**。

**[FACT]** ⁷²Kr 半衰期 **17.2 s** → **rp-process 若持续少于 17 s 将停在此点**。

### 7.3.2 §4.5.2 Photodisintegration

**[FACT]** 对偶偶 T = 1 核（²²Mg, ²⁶Si, ³⁰S, ³⁴Ar, ⁴²Ti, ⁴⁶Cr 等）的质子俘获**Q 值很小 (Q ≲ 0.5 MeV)**，在高温下**被 T = 3/2 复合核的逆光裂强烈抑制**。

**[FACT]** 若光裂速率 > 质子俘获速率 → 反应被中止，**等待 T = 1 核的 β 衰变**。

**[FACT]** **典型地**，T = 1 与 T = 3/2 核保持**平衡丰度** → **第二次质子俘获可跨越 T = 3/2 核**（高温高密度下）。

**[FACT]** T = 3/2 复合核中**质子阈值低** → (p,γ) 反应通常涉及**孤立共振**（第一、第二激发态）和**直接俘获到基态**。

**[FACT]** 但目前对 T = 3/2 核的能级知识（包括低激发态能量）非常有限。

**[FACT]** 例：**²³Al 第一激发态**（与 ²²Mg(p,γ)²³Al 相关），通过 ²⁴Mg(⁶Li,⁸He)²³Al 反应 (111) 观测到 **Ex = 460 ± 60 keV**（对应 E_cm = 360 ± 60 keV）。

**[FACT]** 自旋宇称从 ²³Ne 镜像态采用；单粒子谱因子与 B(E2) 强度用 **Brown-Wildenthal sd 模型** (112) 计算。

**[FACT]** 这些能级参数的**实验验证很有必要**。

### 7.3.3 §4.5.3 Bottleneck Reactions

**[FACT]** 对奇偶 T = 1/2 核（²³Mg, ²⁷Si, ³¹S, ³⁵Ar, ³⁹Ca, ⁴³Ti, ⁵⁵Ni）的质子俘获 Q 值**通常低 (Q ≲ 2.0 MeV)** → **孤立共振 + 非共振直接俘获**主导 → **Hauser-Feshbach 不适用**。

**[FACT]** 在 **T₉ < 1** 时，这些反应是**通向更重元素唯一可能链** → 称为**瓶颈**。

**[FACT]** 它们的反应率**限制整体反应流**——**小速率可导致显著延迟**。

### 7.3.4 ³¹S(p,γ)³²Cl 示例

**[FACT]** Q = **1.574 MeV**——SiP 循环到重核的重要分支。

**[FACT]** ³²S(⁶He,t)³²Cl 研究 (113, 114) 在阈值至 E_cm = 1 MeV 定位 **3 个态**。

**[FACT]** 两测量激发能**差 ~20 keV**——但后者与 **³²Ar β 延迟质子衰变**测量**极好一致**。

**[FACT]** 共振参数来自 ³²P 中已知类比态的性质 (65)。

**[FACT]** 天体物理相关温度下反应率**完全由 E_cm = 568 keV (Ex = 2.142 MeV, J^π = 3⁺) 的 d 波共振贡献**决定。

**[FACT]** 在此温度与 **ρ ≲ 10⁶ g cm⁻³** 下，³¹S 的 β 衰变**显著快于**质子俘获 → **此反应是通向重质量路径的瓶颈**。

**[FACT]** 强调：**测量该能级参数或共振强度的直接研究极为可取**。

### 7.3.5 §4.5.4 Reaction Cycles

**[FACT]** 对 **T₉ ≲ 0.4**，不稳定奇偶 T = 1/2 核（²³Mg, ²⁷Si, ³¹S, ³⁵Ar, ³⁹Ca, ⁴³Ti）更可能 β 衰变至**奇偶 T = 1/2 核**（²³Na, ²⁷Al, ³¹P, ³⁵Cl, ³⁹K, ⁴³Sc），而非进一步反应。

**[FACT]** 对衰变产物质子俘获，**(p,γ) 与 (p,α) 通道均开启**：
- (p,γ) 分支继续向重质量推进
- (p,α) 竞争反应完成**循环**：
  - **NeNa cycle**
  - **MgAl cycle**
  - **SiP cycle**
  - **SCl cycle**
  - **ArK cycle**
  - **CaSc cycle**

**[FACT]** 反应分支比 **b = (p,α)/(p,γ)** → 反应流被**在循环中存储 b·τ 个循环时**（τ 为循环时间）所阻碍——**循环成为流阻抗**，**温度依赖的时间常数 b·τ**。

**[FACT]** 因此研究爆炸性燃烧时标需**确定循环时间**（低温由质子俘获决定，高温由 β⁺ 衰变决定）与**分支比 b**。

### 7.3.6 循环测量的实验结果

**[FACT]** (p,γ) 反应率可用 Hauser-Feshbach（T=0 复合核激发能高 8–12 MeV，能级密度高，所有布居共振均可 γ 衰变）；**(p,α) 竞争通道只开自然宇称 T=0 能级**——可能**密度不够**使 HF 可靠 → 需**研究 T=0 核的自然宇称态能级密度、(p,α) 通道的能量和共振强度**。

**[FACT]** **NeNa 循环**：²³Na(p,γ)²⁴Mg 与 ²³Na(p,α)²⁰Ne 竞争——直接布居 ²³Na + p 共振，**同时测量两通道** (115, 116)。

**[FACT]** **T₉ ≳ 0.2 时**，**大量 NeNa 物质通过 ²³Na(p,α)²⁰Ne 循环再循环**。

**[FACT]** **MgAl 循环**：²⁷Al(p,γ)²⁸Si 竞争 ²⁷Al(p,α)²⁴Mg (117)。

**[FACT]** (p,α) 通道低能共振搜索给出**对已知强 (p,γ) 共振强度的严格上限** (117)——由 ²⁷Al(⁶He,d)²⁸Si 反应（衰变质子/α 与氘符合）(118)**独立技术确认**。

**[FACT]** **与 NeNa 循环相反**，MgAl 循环在 **T₉ = 0.2 时仅 0.1–1% 的时间循环**，更高温度 ~10% → **MgAl 循环中大部分物质被加工至更重质量**。

**[FACT]** **SiP 循环**：³¹P(p,γ)/(p,α) 分支比 (119)，与 NeNa/MgAl 测量方式相同。

**[FACT]** ³¹P(p,γ)³²S 中 E > 250 keV 若干共振被观测；**³¹P(p,α)²⁸Si 中仅一个强共振**（在 383 keV）被识别。

**[FACT]** **T₉ ≳ 0.4 两通道反应率可靠计算**。

**[FACT]** 低温下，³²S 中 **Ex = 9.060 MeV (J^π = 0⁻ – 2⁻)** 态**未知自旋**引入**不确定**：
- 自然宇称 (1⁻) → ³¹P(p,α) 通道主导
- 非自然宇称 (0⁻, 2⁻) → α 通道关闭，仅 (p,γ) 通道强共振预期

## 7.5 作者的逻辑

```
rp-process 到铁峰需要克服四种"阻抗"：
  ① 等待点：质子滴线边界 → β 衰变等待
  ② 光裂：T=1→T=3/2 逆反应抑制
  ③ 瓶颈：T=1/2 奇偶核 (p,γ) 慢
  ④ 循环：(p,α) 分支造成循环再循环
  ↓ A=20–40 系统学已知，但 A=40–70 实验数据缺 → 端点不确定
  ↓ ⁷²Kr (T₁/₂ = 17.2 s) 是最可能的等待点端点
```

## 7.6 潜在问题与值得注意之处

1. **[FACT]** ⁷²Kr 半衰期 **17.2 s** 这一"时间门"非常直观：**X 射线暴 (~10 s) 无法到达此点；长 X 射线暴或 nova (100–1000 s) 才可能**——这是**端点核素与天体物理事件时标的直接耦合**。
2. **[CRITIQUE]** ¹⁹⁰As 在文中原为 "⁵⁵As"（OCR 错误）——实际应为 **⁶⁵As**（与 ⁶¹Ga、⁶⁹Br 同系统）。已按核物理语境校正。
3. **[FACT]** 循环分支比 **b = (p,α)/(p,γ)** 是**温度强依赖**——这意味着**相同反应网络在不同 T₉ 下的产物可以完全不同**。这一点在 §5 网络计算中会被验证。
