## 2.1 本节核心内容

建立爆炸性氢燃烧的基本反应网络框架：从 CNO 循环出发，区分静水燃烧与爆炸燃烧的根本差异（β 衰变时标 vs 反应时标），引入 **Hot CNO (HCNO) 循环**与 **rp-process** 两条主链，并给出热核反应速率的严格数学表达式（含 Gamow 峰、Breit-Wigner 共振公式）。

## 2.2 原文内容

### 2.1 Reaction Networks

- **[FACT]** 反应场所温度区间 **T9 = 0.1–1.5**；密度 **ρ = 10³–10⁸ g cm⁻³**。
- **[FACT]** 若种子物质为 C、O，反应网络类似静水 CNO 循环。
- **[FACT]** 关键差异：**爆炸燃烧中核反应时标与 β 衰变时标相当或更短**。
- **[FACT]** 因此 12C(p,γ)13N 后，**13N 的 β 衰变 (T1/2 = 9.97 min) 被 13N(p,γ)14O 反应旁路**，形成 **Hot CNO (HCNO) 循环**（Ref. 13–17）。
- **[FACT]** 16O 进入 HCNO 的两条路径：
  - 低温：16O(p,γ)17F(β⁺)17O(p,α)14N(p,γ)15O
  - 高温：16O(p,γ)17F(p,γ)18Ne 等
- **[FACT]** 主循环中能量产生速率受限于 14O、15O 的 β⁺ 衰变（T1/2 = 71 s, 122 s）。
- **[FACT]** 平衡态下，催化物质主要以 14O、15O 存在，最终作为 14N、15N 留在新星抛射物中。
- **[FACT]** 15N 相对于 14N 增强——因为 15O 的半衰期比 14O 长。
- **[FACT]** T9 → 0.4：α 诱导反应开始起作用，如 **14O(α,p)17F(p,γ)18Ne(β⁺)18F(p,α)15O**，加速产能。
- **[FACT]** 更高温度下，可通过 **15O(α,γ)19Ne、18F(p,γ)19Ne、18Ne(α,p)21Na** 突破 HCNO 循环，进入 **rp-process**（Ref. 18, 19）。
- **[FACT]** rp-process 也可由**预爆炸丰度**的 Ne、Na、Mg 触发（无需直接来自 HCNO）。
- **[FACT]** 新星抛射物中 Ne、Na、Mg、Al 增强的候选来源——Cygnus 1975、Aquilae 1982、CrA 81、Vulpeculae 等（Ref. 20-23）。

#### rp-Process 特征 [FACT]

- 反应路径介于稳定线（line of stability）与质子滴线（proton drip line）之间；
- 由带电粒子反应速率与 β 衰变速率竞争决定：
  - 带电反应速率呈指数温度依赖；
  - β 衰变速率**近似与温度无关**；
- 低温时两者相当 → 反应路径贴近稳定线；
- 高温时反应更快 → 反应路径贴近质子滴线；
- 向重质量推进的流量受限于路径上最慢的反应速率，以及阻碍因素：β 衰变等待点、光致分解、反应循环。
- **[FACT]** 粗略估计：rp-process 核合成可达铁峰以外；产能速率约为 HCNO 主循环的 **100 倍**（Ref. 18），**足以驱动 X 射线暴**。

### 2.2 Thermonuclear Reaction Rates (p.45-46)

#### 2.2.1 基本定义

热核反应速率 = 反应截面 σ 与质心速度 v 之积对麦克斯韦速度分布的加权平均：

**公式 (2)**
```
<σv> = (8/πμ)^(1/2) (kT)^(-3/2) ∫ σ(E) E exp(-E/kT) dE
```
其中 μ 为约化质量，k 为玻尔兹曼常数。

#### 2.2.2 非共振（直接俘获）部分

- **[FACT]** σ(E) 一般包含非共振直接反应（或辐射反应的直接俘获）与共振俘获贡献。
- **[FACT]** 对带电粒子反应，非共振截面由库仑势与离心势垒穿透因子主导；低能时近似 ∝ exp[−(EG/E)¹ᐟ²]，其中 **Gamow 常数**：

**公式 (3)**
```
EG = (2π e² Z₁ Z₂ / ℏ)² μ
```

- **[FACT]** 结合麦克斯韦分布，积分主要在**Gamow 峰**附近非零 → Gamow 峰的位置与宽度定义了截面测量的关键能量区间。
- **[FACT]** HCNO (p,γ) 反应：Gamow 峰范围 **25 keV – 1.1 MeV**（c.m.）；rp-process 上端 **150 keV – 2.5 MeV**。
- **[FACT]** 非共振截面常用参数化形式：

**公式 (4)**
```
σ(E) = (S(E)/E) exp[−(EG/E)¹ᐟ²]
```

其中 S(E) 为**天体物理 S 因子**，是慢变函数，包含截面的非运动学部分。

#### 2.2.3 共振俘获（Breit-Wigner）

- **[FACT]** HCNO 与 rp-process 速率主要由**共振俘获**决定（基于复合核能级密度考虑）。
- **[FACT]** 单一共振 E = Er 时的 Breit-Wigner 形式：

**公式 (5)**
```
σ(E) = π λ² ω · (Γa Γb) / [(E − Er)² + Γ²/4]
```

其中 λ 为约化康普顿波长，ω 为自旋统计因子，Γa、Γb 分别为入射与出射通道分宽度，Γ 为总宽度。

- **[FACT]** 对于孤立窄共振（Γ ≪ Er），公式 (2) 积分得到：

**公式 (6)**
```
<σv> = (2π)^(3/2) / (μ (kT)^(3/2)) · ω γ · exp(−Er / kT)
```

其中 **ωγ = ω Γa Γb / Γ** 为**共振强度 (resonance strength)**；
- **[FACT]** 各共振的贡献简单求和。
- **[FACT]** 宽共振或重叠共振情形下，截面偏离洛伦兹形状，需数值积分公式 (2)。
- **[FACT]** 多共振统计情形（如稳定核）可用 **Hauser-Feshbach 统计模型**（Ref. 30, 31）。

#### 2.2.4 实验测量方法

- **[FACT]** 对感兴趣反应，σ(E) 的直接测量需**放射性束或放射性靶**：
  - 放射性束优于放射性靶（半衰期 < 数小时的靶带来严重本底）；
  - 补充途径：用稳定束与稳定靶产生复合核，通过核谱学测量激发能、自旋宇称、宽度、衰变分支 → 确定公式 (6) 的共振信息。
- **[FACT]** 上述两种方法均已应用于 HCNO 与 rp-process 研究。

## 2.3 关键公式汇总

| 编号 | 公式 | 用途 |
| --- | --- | --- |
| (2) | <σv> = (8/πμ)¹ᐟ² (kT)⁻³ᐟ² ∫ σ(E) E exp(−E/kT) dE | 热核反应速率定义 |
| (3) | EG = (2π e² Z₁ Z₂/ℏ)² μ | Gamow 常数 |
| (4) | σ(E) = (S(E)/E) exp[−(EG/E)¹ᐟ²] | 非共振参数化 |
| (5) | σ(E) = πλ² ω ΓaΓb / [(E−Er)² + Γ²/4] | Breit-Wigner 截面 |
| (6) | <σv> = (2π)³ᐟ² (μ(kT)³ᐟ²)⁻¹ ωγ exp(−Er/kT) | 窄共振速率 |

## 2.4 关键参数

- Gamow 峰能量区间：HCNO: 25–1100 keV；rp: 150–2500 keV
- 反应速率典型不确定度：**5–1000×**（除 13N(p,γ)14O 达 ±13%、15O(α,γ)19Ne 达因子 2 外）
- 能量产生速率：rp-process 约为 HCNO 主循环的 **100×**
- 主循环 β 衰变半衰期：13N 9.97 min，14O 71 s，15O 122 s

## 2.5 作者的逻辑

1. 由宏观物理条件（T, ρ）出发，识别主导反应链（HCNO vs rp）；
2. 明确速率控制的数学形式（非共振 vs 共振 vs 统计）；
3. 指出实验测量的两种路径（放射性束 vs 核谱学）；
4. 为 §3、§4 的具体反应分析奠定方法论基础。

## 2.6 我的理解 [INTERPRETATION]

- **公式 (6) 是本文的核心公式**：几乎所有反应速率讨论最终归结为确定 ωγ。
- 核天体物理的一个关键**方法论洞察**：直接测量截面困难，因此大量工作通过类比核、镜像核、激发态转移反应**间接**确定 ωγ。
- 100× 的产能加速因子意味着 rp-process 在 T9 ≳ 0.5 时完全主导产能，这解释了 X 射线暴中温度骤升的物理机制。

## 2.7 潜在问题与值得关注的地方 [CRITIQUE]

- 公式 (6) 依赖窄共振近似；对 T9 ≳ 0.7 时的高激发能区，Γ 可能不可忽略，需要用统计模型（Hauser-Feshbach）。
- 公式 (5) 中总宽度 Γ 与 E 的依赖关系在共振宽度随能量变化显著时（如低能质子宽度）会导致速率对 Ecm 选择极度敏感——§3.2、§4.2 中多次出现此类问题。
