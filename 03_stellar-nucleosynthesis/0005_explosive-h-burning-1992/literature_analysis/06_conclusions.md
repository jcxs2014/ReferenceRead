## 6.1 §6 Concluding Remarks（结论）

- **[FACT]** 尽管对爆炸性氢燃烧的核合成已投入大量研究，**仍有很多工作要做**。
- **[FACT]** 本文讨论的反应只是感兴趣的少数；所有反应均存在某种程度的不确定度；未讨论的反应可能同样重要，但速率基本未知。
- **[FACT]** 网络计算虽然令人印象深刻，但基于我们对反应速率的认识，**"是否可以视为空中楼阁 (house of cards)？"**
- **[FACT]** **没有替代测量速率的途径**。这要求：
  1. 持续开发**放射性束**技术；
  2. 继续沿用**传统核谱学**方法；
  3. 核谱学还需提供其他必要的核输入，如质量、寿命等。
- **[FACT]** 若要推进到质子滴线，**放射性束是必需的**。

## 6.4 论证链重建

```
天体场景 (新星/XRB/SN) 
  → 极端 T9=0.1–1.5, ρ=10³–10⁸ 物理条件
  → 反应时标 < β 衰变时标 → HCNO 主循环
  → T9↑ → α 突破 → rp-process 启动
  → 反应速率 = 非共振 (S 因子) + 共振 (Breit-Wigner ωγ) + 统计 (HF)
  → 实验：放射性束 / 库仑解离 / 类比核谱学
  → 速率不确定度 5-1000× → 网络计算"house of cards"
  → 网络 (216 核素, 946 反应)
  → T9=0.3: 终点 32S；T9=0.4: 52Fe；T9=1.5: 72Kr
  → 结论：需更精确测量 + 放射性束发展
```

## 6.5 作者的隐含假设 [CRITIQUE]

- 常数 T、ρ 假设下反应路径可代表实际天体物理（真实有冷却曲线）；
- 太阳初始丰度代表新星/H 富集层（实际有核燃烧污染）；
- 速率不确定度对各产物的影响**线性可加**（实际可能非线性，因流量竞争）；
- "X 射线暴不贡献核合成"——隐含假设 XRB 抛射物可忽略，这一假设后来被质疑。
