## 5.1 本节核心内容

用大规模反应网络数值模拟，把 §3、§4 讨论的反应速率综合成三类天体物理条件（新星温和、新星剧烈、X 射线暴）下的**完整核合成路径与产物丰度**演化。每类条件都配以反应路径图（Figure 4/6/8）与关键核素时间演化图（Figure 5/7/9）。

## 5.2 网络方程

- **[FACT]** 两核素 i 与 j 之间的净反应流：

**公式 (8)**
```
Fij = ∫ [λ(i → j) − λ(j → i)] dt
```

其中 λ(i → j) 是时间相关反应速率；Yi = Xi/Ai 为质量分数除以原子序数。

- **[FACT]** 同位素丰度 Yi 的时间演化：

**公式 (9)**
```
dYi/dt = Σj λij β + Σj,k λijk (jk → i) Yj Yk
```

第一项包括 β⁺ 衰变和光致分解；第二项描述两粒子反应 j+k → i。

## 5.3 网络规模与条件设置 [FACT]

- **[FACT]** 反应网络：**216 稳定+不稳定核素**，**946 核反应**；
- 包含 β⁺ / EC 弱相互作用、(p,γ)、(p,α)、(α,γ)、(α,p) 及其逆反应；
- **[FACT]** 网络扩展自 Wallace & Woosley (18)（原 A ≤ 40）；
- **[FACT]** 三类典型条件（常数 T、ρ）：

| 编号 | 天体场景 | T9 | ρ (g/cm³) | 计算时长 |
| --- | --- | --- | --- | --- |
| §5.1 | 超新星激波加氢烧 | **0.3** | 10³ | 10 s（+100 s 虚线） |
| §5.2 | 新星热失控（剧烈） | **0.4** | 10⁴ | 1000 s |
| §5.3 | X 射线暴热失控 | **1.5** | 10⁶ | 10 s |

- **[FACT]** 初始丰度：太阳同位素丰度（Anders & Ebihara 1982，Ref. 121）。

## 5.4 §5.1 低温低密度（T9 = 0.3, ρ = 10³ g/cm³, t = 10 s）

### 5.4.1 反应流模式（Figure 4）

- **[FACT]** A = 20-60 反应流图。
- **[FACT]** 明确显示 HCNO 循环的流量 → 14O、15O 及 18Ne 丰度增强（由 12,13C、16O 两次 (p,γ) 累积）。
- **[FACT]** **HCNO 与 NeNa 区间之间无连接** → 若无预设 A ≥ 20 物质，则不发生 rp。
- **[FACT]** NeNa 区内的热循环：

**公式 (10)**
```
20Ne(p,γ)21Na(p,γ)22Mg(β⁺ν)22Na(p,γ)23Mg(β⁺ν)23Na(p,α)20Ne
```

- **[FACT]** 向重质量的流经由两个瓶颈反应 **23Mg(p,γ)24Al** 与 **24Mg(p,γ)25Al**。
- **[FACT]** NeNa 循环的 breakout 时间常数很大 → 计算时长内大部分物质**困于 NeNa 区**。
- **[FACT]** 连续反应序列进入 SiP,S 区：

**公式 (11)**
```
24Al(p,γ)25Si(β⁺ν)25Al(p,γ)26Si(β⁺ν)26Al(p,γ)27Si(p,γ)28P(β⁺ν)28Si
```

- **[FACT]** SiP 热循环：

**公式 (12)**
```
28Si(p,γ)29P(p,γ)30S(β⁺ν)30P(p,γ)31S(β⁺ν)31P(p,α)28Si
```

- **[FACT]** 显著部分物质通过 **31P(p,γ)32S(p,γ)33Cl** 流向更高 A，仅弱流继续至终点 40Ca。

### 5.4.2 丰度演化（Figure 5）

- **[FACT]** 初始 20Ne 主要转为 22Mg，因半衰期长（T1/2 = 3.86 s）**被困**。
- **[FACT]** 预设 24Mg 与 28Si 转为 26Si（T1/2 = 2.23 s）与 30S（T1/2 = 1.18 s）。
- **[FACT]** 这些 β 衰变导致 31S（T1/2 = 2.57 s）**富集**。
- **[FACT]** 31S 主要 β 衰变至 31P，被 (p,α) 再循环回 28Si（SiP 循环，Ref. 18）。
- **[FACT]** 循环时间常数 τSiP = τβ(31S) · (p,γ)/(p,α)。
- **[FACT]** 31P(p,γ)32S 产生速率比 32S(p,γ)33Cl 破坏速率**大约三个数量级** → 每循环净产 32S。
- **[FACT]** **32S 是 A = 20–32 初始物质在 10 s 燃烧后的产物终点**。
- **[FACT]** 更长燃烧时间 → 终点 40Ca。
- **[FACT]** **[关键修正]** 该结果与 Wallace & Woosley (18) 旧网络计算不同——后者使用的 32S(p,γ)33Cl 速率比 Iliadis et al. (104) 实测**大约两个数量级**。

## 5.5 §5.2 中间温度密度（T9 = 0.4, ρ = 10⁴ g/cm³, t = 1000 s）

- **[FACT]** 代表**剧烈新星**峰值条件。
- **[FACT]** 反应流图（Figure 6）显示 CNO 到 A ≈ 20 区间的**显著流量**，路径：

**公式 (13)**
```
15O(α,γ)19Ne(p,γ)20Na(p,γ)21Mg(p,γ)22Al(β⁺ν)22Ne 或 21Mg(β⁺ν)21Na(p,γ)22Mg
```

- **[FACT]** 在等待点 22Mg 分支为两条绕过 NeNa 与 MgAl 循环的路径：
  - **路径 (14)** 由 22Mg(p,γ)23Al 启动：
    ```
    22Mg(p,γ)23Al(p,γ)24Si(β⁺ν)24Al(p,γ)25Si(β⁺ν)25Al(p,γ)26Si(β⁺ν)26Al(p,γ)27Si
    ```
  - **路径 (15)** 沿 22Mg β 衰变：
    ```
    22Mg(β⁺ν)22Na(p,γ)23Mg(β⁺ν)23Na(p,γ)24Mg...
    ```
- **[FACT]** 27Si(p,γ)28P(p,γ)29S(β⁺ν)29P(p,γ)30S 沿质子滴线推进至 SiP 区。
- **[FACT]** A ≈ 40 区由**三个循环**特征化：**SiP、SCi、ArK**，通过瓶颈反应 31S(p,γ)32Cl 与 35Ar(p,γ)36K 相互分支。
- **[FACT]** 向 A > 40 由两个弱 (p,γ) 反应通道化：**39Ca(p,γ)40Sc** 与 **40Ca(p,γ)41Sc**（Ref. 122）→ CaSc 循环；约 20 s 燃烧后达到此阶段。
- **[FACT]** A ≈ 50 区：CaSc 循环通过 **43Ti(p,γ)44Y(β⁺ν)44Ti(p,γ)45Y** 与 **43Sc(p,γ)44Ti(p,γ)45Y** 泄漏，最终产物终点 **52Fe**。

### 5.5.1 丰度演化（Figure 7）

- **[FACT]** T9 = 0.4 时 20Ne 在 1 s 内耗尽 → 转 22Mg（T1/2 = 3.86 s）；
- **[FACT]** 22Mg 可被 (p,γ) 破坏，有效半衰期 **T1/2 eff = 2.4 s**；
- **[FACT]** 此期间物质转为等待点 34Ar 与 40Ca；
- **[FACT]** 10 s 后 34Ar、40Ca 达平衡丰度；
- **[FACT]** 40Ca 因极弱的破坏反应 40Ca(p,γ)41Sc 而**显著增强**；
- **[FACT]** 进一步加工将 40Ca 完全转为 52Fe；
- **[FACT]** 52Fe 因**长 β 半衰期 T1/2 = 8.28 h** + 弱破坏 52Fe(p,γ)53Co → **52Fe 是 T9 = 0.4 条件下 rp 的终点**。

## 5.6 §5.3 高温高密度（T9 = 1.5, ρ = 10⁶ g/cm³, t = 10 s）

- **[FACT]** 代表 **X 射线暴** 条件，预计持续 **10 s 或更短**（Ref. 11）。
- **[FACT]** 反应流（Figure 8）显示 **4He 到 73Kr** 的连续流（网络终点）。
- **[FACT]** 爆发初期：12C 由三重 α 产生并迅速转为 14O。
- **[FACT]** **轻等待点 14O、18Ne、22Mg、28Si、30S、34Ar 被 (n,p) 反应序列桥接**——即 **np-process**（Ref. 73）。
- **[FACT]** A > 38 后，rp 路径由**质子俘获 + β 衰变**沿质子滴线推进至 Ni 区。
- **[FACT]** 随库仑势垒增加，(n,p) 反应太慢，无法与 β 竞争。
- **[FACT]** 54Ni 被预测为质子未束缚（Ref. 123）→ 反应流沿：

**公式 (16)**
```
53Co(β⁺)53Fe(p,γ)54Co(p,γ)55Ni(p,γ)56Cu(β⁺)56Ni(p,γ)57Cu
```

- **[FACT]** 55,56Ni(p,γ) Q 值很低（0.459、0.767 MeV），受光致分解抑制（Ref. 120）。
- **[FACT]** 反应继续至 **64Ge（T1/2 = 63.7 s）**，在爆发期间近似稳定。
- **[FACT]** 若 65As 质子未束缚 → 64Ge 终止 rp。
- **[FACT]** 若 65As 稳定 → 路径延续：

**公式 (17)**
```
65As(p,γ)66Se(β⁺)66As(p,γ)67Se(β⁺)67As(p,γ)68Se
```

**公式 (18)**
```
68Se(p,γ)69Br(p,γ)70Kr(β⁺)70Br(p,γ)71Kr(β⁺)71Br(p,γ)72Kr
```

- **[FACT]** 因 73Rb 质子未束缚（Ref. 110），**rp 终止于 72Kr（T1/2 = 17.2 s）**。

### 5.6.1 丰度演化（Figure 9）

- **[FACT]** 0.5 s 后：预设 CNO 与 NeNa 物质转为 34Ar。
- **[FACT]** 1 s 后：ap-process 产生 38Ca。
- **[FACT]** 1.5 s 时：55Ni、56Ni 达到丰度峰。
- **[FACT]** 5 s 后：大部分原始物质到达 64Ge。
- **[FACT]** 64Ge 因两个破坏过程（64Ge(p,γ)65As、64Ge(β⁺)64Ga）都弱 → 缓慢减少。
- **[FACT]** 最终 64Ge 转为 72Kr，**20 s 后 72Kr 达到丰度峰**。

## 5.7 三类条件下 rp-process 产物终点总结

| 条件 | 天体 | 主要等待点 | 循环 | 终点 |
| --- | --- | --- | --- | --- |
| T9=0.3, ρ=10³, 10 s | 超新星激波 | 22Mg, 31S | NeNa, SiP | **32S** (10 s) / **40Ca** (>10 s) |
| T9=0.4, ρ=10⁴, 1000 s | 剧烈新星 | 22Mg, 34Ar, 40Ca | SiP, SCi, ArK, CaSc | **52Fe** |
| T9=1.5, ρ=10⁶, 10 s | X 射线暴 | 14O, 18Ne, 22Mg, 28Si, 30S, 34Ar | —（np 桥接） | **72Kr**（或 64Ge） |

## 5.9 作者的逻辑

1. 用 §3、§4 中推荐/最佳速率做数值模拟；
2. 三类天体条件覆盖温度谱，揭示 rp 的演化阶段；
3. 明确产物终点随温度升高而向更重核素推进；
4. 强调速率不确定度如何影响产物终点（如 32S(p,γ)33Cl 的修正）。

## 5.10 我的理解 [INTERPRETATION]

- T9 从 0.3 → 1.5，产物终点从 **32S → 52Fe → 72Kr**——质量数几乎三倍；这直接验证了 rp-process 在极端条件下的合成能力。
- T9=1.5 时的 **np-process 桥接**（Ref. 73）是关键发现——Woosley 1992 提出的该机制解释了 rp 如何跨越轻等待点。
- 64Ge 作为**观测探针**：半衰期 63.7 s 与 X 射线暴 5-10 s 尺度可比，其后续衰变链产生 64Zn，是未来伽马/中微子观测的候选信号。

## 5.11 潜在问题与值得关注的地方 [CRITIQUE]

- 网络模拟采用**常数 T、ρ**——实际天体物理环境中温度密度随时标变化，会显著改变反应流路径。
- 52Fe 作为 T9=0.4 终点——其 T1/2 = 8.28 h 意味新星抛射物中 52Fe 衰变产生的 52Mn 是潜在观测探针。
- 本文网络使用 Wallace & Woosley (18) 更新版；Cowan, Thielemann & Truran 1991 (Ref. 31) 给出了更完整的 A ≤ 100 网络，本文未对比。
- **32S(p,γ)33Cl 修正**（Iliadis et al. 1992，Ref. 104）：直接导致 §5.1 终点从 >40Ca 变为 32S——单一反应速率修正改变整个核合成图景的典型案例。
