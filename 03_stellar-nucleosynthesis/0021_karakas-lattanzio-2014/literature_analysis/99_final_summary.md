# 99 Final Summary（最终总结）

## 一句话总结
Karakas & Lattanzio (2014) 系统综述了质量 ≤10M⊙ 恒星从主序到 AGB 尖端的全部核合成途径——FDU/SDU/TDU、热脉冲、HBB、s-过程与 PIE——并以 1–8M⊙、Z=10⁻⁴–0.02 的详细 AGB 产额表为基础阐明这些恒星对银河系 C、N、F、Na、s-过程重元素与尘埃化学增丰的决定性贡献。

## Top findings
1. **AGB 核合成核心机制**：热脉冲 + TDU + HBB 构成 AGB 表面化学演化的"三角"。
2. **λ 参数**：TDU 效率参数 λ = ΔM_dredge/ΔM_core 是 AGB 产额最关键的可调参数，仍由对流实现决定。
3. **C 星形成**：低金属度 + 中等 TDU 效率 → ¹²C 超过 ¹⁶O → C 星；HBB 阻止中高质量 AGB 成为 C 星。
4. **s-过程源**：低质量 AGB 的 ¹³C 袋 + 中质量 AGB 的 ²²Ne → 分别贡献太阳系统 s-过程轻、重峰与 Pb（91%）。
5. **银河增丰**：AGB 贡献银河系 ¹²C ~50–60%、¹⁴N 主要部分、s-过程重元素主体、~90% 尘埃。
6. **不确定性**：对流边界实现、质量损失率是产额系统误差两大主导源。
7. **元数据一致性**：目录名、任务上下文、PDF 首页三源一致，无勘误。

## 关键公式
- λ = ΔM_dredge / ΔM_core（TDU 效率）
- L/L⊙ ≈ 59200(M_c/M⊙ − 0.522)（Paczynski 关系）
- 3 ⁴He → ¹²C + γ（三 α，壳闪主要能源）
- ¹³C(α,n)¹⁶O（低质量 AGB 中子源）
- ²²Ne(α,n)²⁵Mg（中质量 AGB 中子源）

## Critique
- 本文是 review，非原始数据；关键数字多来自 Karakas & Lattanzio 2007、Karakas 2010 等作者自身工作。
- s-过程产额表在 Z ≲ 10⁻³ 仍有系统缺口，10 年后仍未完全解决。
- 对流与质量损失参数化高度依赖经验校准，3D 模拟进展缓慢。
