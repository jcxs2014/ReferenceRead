# §10 Concluding Remarks — 结论

- [FACT] 本文报告两类**大质量 SN** 的性质与核合成：
  1. **超新星 (Hypernovae)**：动能是正常核心坍缩 SN 的**10 倍以上**
  2. **暗淡 SN (Faint SNe)**：能量极低、抛射极微
- [FACT] **物理图像**：两类 SN 均为 **"BH-形成" SN**，区别在于 BH 是否**自转**：
  - 自转 BH → HN（喷流抛射）
  - 非自转 BH → Faint SN（"安静"坍缩）
- [FACT] **HN 的核合成特征**：**大 [(Zn, Co, V, Ti)/Fe]**，优于正常 SN，可**解释 EMP 星**的观测比值
- [FACT] **Faint SN 的核合成特征**：**大量回落**，可解释**最贫铁恒星**（HMP 等）的丰度模式
- [FACT] **核心论断**：**BH-形成 SN 对早期银河系（及宇宙）的化学演化做出了重要贡献**
- [FACT] 通过**把异常 SN 的核合成属性与 EMP 星的异常丰度模式联系起来**，可以对**第一星的性质**施加重要约束

> [INTERPRETATION] §10 用 3 句话完成闭合：**双分支图像**（§2） → **核合成指纹**（§6/§8） → **GCE 建模输入**（§9）。全文逻辑自洽、闭环明确。
