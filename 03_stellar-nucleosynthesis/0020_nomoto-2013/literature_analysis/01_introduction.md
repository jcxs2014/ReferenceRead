## 1.1 本节核心内容

[FACT] BBN 之后，几乎全部 Z>2 元素都在恒星的演化与爆发中合成，其中 **大质量恒星的核心坍缩超新星 (CC-SN) 与热核爆炸 (SN Ia) 是宇宙中最主要的重元素工厂**。本文 §1 开篇即点明这一"重元素从恒星起源"的 B²FH 传统（§0001），并把 2013 年的前沿聚焦在三个交叉领域：**极贫金属 (EMP/UMP/HMP) 星** 的化学考古、**伽马射线暴 (GRB)** 作为高红移探针、以及 **银河系化学演化 (GCE)** 对产额的自洽约束。

[FACT] 全文逻辑骨架：§2 AGB 星（低-中质量）→ §3 CC-SN 的爆炸核合成物理 → §4 大质量星（10–140 M☉）产额 → §5 极重星 (140–1000 M☉) 的对不稳定超新星 → §6 SN Ia → §7 GCE → §8 EMP/CEMP 星观测 → §9 Galactic Archaeology 巡天 → §10 展望。

## 1.2 核心坍缩超新星的中心地位

[FACT] **核心坍缩**（Chandrasekhar 极限 ~1.4 M☉ 的 Fe 核引力坍缩）是大质量恒星 (M ≳ 8 M☉) 的宿命；坍缩释放的引力结合能约 `3×10⁵³ erg`，其中 ~1% 转化为中微子，再加热外壳触发爆炸。

[FACT] **质量-命运关系**（Fig. 1，本文关键图谱之一）：
- **8–10 M☉**：电子俘获超新星 (EC-SN)，$E \sim 10^{50}$ erg，"最弱"超新星
- **10–25 M☉**：普通核心坍缩 SN (Type II/Ib/Ic)，$E \sim 10^{51}$ erg（"1 foe" = 10⁵¹ erg）
- **25–40 M☉**：Hypernovae / 长暴 γ 射线暴前身星，$E \sim 10^{52}$ erg，与 §0023 (Eichler 1989) 联系
- **40–140 M☉**：失败超新星 (failed SN)，直接坍缩为 BH，几乎没有抛射
- **140–260 M☉**：对不稳定超新星 (PISN)，完全瓦解，几乎无残留
- **>260 M☉**：直接坍缩成中间质量黑洞

[FACT] **EMP 星的独特价值**（§1 提出的"宇宙化石"论点）：当宇宙金属丰度 $Z \lesssim 10^{-4} Z_\odot$ 时，单个超新星的抛射物质可以在未被稀释的情况下形成下一代恒星。因此 **[X/Fe] 比值的"指纹"可反推前身星的质量与爆发能量**，无需 GCE 的积分效应。

## 1.3 极贫金属星的观测进展

[FACT] **金属丰度等级**（按 [Fe/H] 划分，本文 §8 沿用）：
- **VMP** (Very Metal-Poor)：$-4.0 < \text{[Fe/H]} < -2.5$
- **EMP** (Extremely Metal-Poor)：$-3.0 < \text{[Fe/H]} < -4.0$，本文重点
- **UMP** (Ultra Metal-Poor)：$-5.0 < \text{[Fe/H]} < -3.0$
- **HMP** (Hyper Metal-Poor)：$-5.0 < \text{[Fe/H]} < -6.0$，仅极个别发现（如 HE 1327-2326、HE 0107-5240）
- **Pop III** (Primordial)：[Fe/H] → $-\infty$，尚未观测

[FACT] **HE 1327-2326** ([Fe/H] ≈ −5.24)：C 相对 Fe 富集约 $10^3$ 倍（[C/Fe] ≈ 2.3），O、Na、Mg 极低——这是 **Pop III 前身星**（低质量 CEMP-no 或电子俘获 SN）的强约束，也是本文 §8.5.1 的关键案例。

## 1.4 Γ 射线暴作为高红移核合成探针

[FACT] 长暴 γ 射线暴 (long-GRB) 与坍缩的大质量星（magnetar / collapsar）紧密相关（§0023 Eichler 1989 预言的暴-星关联）。z>6 的 GRB 后随星观测为宇宙再电离时期的化学演化提供了独立约束。

## 1.5 Yields Table 2013

[FACT] 本文随文发布 **Yields Table 2013**（Kobayashi et al. 2011），首次将 Pop III / CC-SN / AGB / SN Ia 统一到一个可供 GCE 直接使用的框架：
- 金属丰度覆盖：$Z = 0, 0.001, 0.004, 0.02$
- 恒星质量覆盖：0.1 M☉ 到 100 M☉
- 同位素覆盖：从 H 到 U 的主要稳定/长寿命放射性核素（含 $^{26}$Al、$^{60}$Fe、$^{13}$C、$^{15}$N、$^{18}$O 等诊断核素）

[FACT] 与 B²FH (§0001) 和 Cameron 1968 (§0014) 太阳丰度表的联系：GCE 模型的终态必须自洽地复现太阳丰度，这是产额表的"总验收测试"。

## 1.6 [INTERPRETATION] 逻辑意义

- **观测-理论双向约束**：EMP 星给出 Pop III 产额的"下界"（不能太稀释），GCE 给出"上界"（不能过量）；只有在这两束光线之间，模型才能通过。
- **B²FH 传统的完成**：B²FH 用丰度表倒推核过程；本文反过来——用核合成产额表正推观测。方向对称但工具不同。

## 1.7 [CRITIQUE] 批判性分析

- **未解问题**：EMP 星的 [C/O] 极端分布（从 0.5 到 4.0）不能用单一 Pop III 前身星解释，暗示 IMF 多样性或 fallback 机制的复杂性。
- **观测限制**：[He/H]、[Li/H] 在 EMP 星中几乎不可测，但 He 与 Li 是 BBN 的关键诊断。
