# 2. HEAVY ELEMENT FORMATION

上一章：[01_introduction](01_introduction.md)
下一章：[03_solar_system_abundances](03_solar_system_abundances.md)

## 2.1 s- 与 r-process 的定义

[FACT] 铁族以上（Z > 26）元素难以通过带电粒子聚变合成：铁以后聚变吸能，且库仑势垒随 Z 增加。因此靠中子俘获推进——中子无库仑势垒。
[FACT] 区分 s-process 与 r-process 的判据：中子俘获时标 τₙ 与不稳定核 β 衰变时标 τ_β 之比。
- **s-process（slow）**：τₙ ≫ τ_β，相邻中子俘获间隔数百至数千年；沿 β 稳定谷进行（Fig. 1, Möller/Nix/Kratz 1997）。
- **r-process（rapid）**：τₙ ≪ τ_β；大数量中子/秒被俘获，合成发生远离稳定线的中子过剩区；分布由光致分解与中子俘获的化学平衡决定，r-process path 定义为每条同位素链的最大丰度。

[FACT] 中子数密度对比悬殊：
- s-process：nₙ ≲ 10⁸ cm⁻³（Busso, Gallino & Wasserburg 1999）
- r-process：nₙ ∼ 10²⁴–10²⁸ cm⁻³（Kratz et al. 2007）

[FACT] r-process 相关同位素的放射性半衰期通常 0.01–0.1 s，导致大多数 r-process 核的实验质量等性质目前无法测量。

## 2.2 s-only / r-only / (s,r) 同位素分类

[FACT] 同位素分为三类：
- **s-only**：仅由 s-process 产生（被 r-process path 绕开的稳定谷核）。
- **r-only**：仅由 r-process 产生（r-process path 上、稳定谷之外的稳定核，例如 ¹³⁰,¹³⁶Xe；¹⁴⁶,¹⁵⁰Sm；¹⁵⁴Eu 等的 r-only 同位素集合）。
- **(s, r)**：两者均可产生（如 ¹³⁵,¹³⁷Ba），需逐个核处理。

[FACT] 中子幻数（N = 50, 82, 126）效应：例如 ¹³⁸Ba 官定为 s,r 核，但 N=82 使其 σ 极小，s-process 中堆积，实际以 s-process 起源为主。

[FACT] **p-nuclei**（质子富余同位素）由 (p,γ) 与 (γ,n) 反应产生，占元素总量 0.1–0.2%，仅可通过陨石同位素测量；本文不予进一步讨论（Lambert 1992；Arnould & Goriely 2003）。

## 2.3 s-process 位点

[FACT] Merrill (1952) 在 S 星中识别放射性 Tc（τ₁/₂ = 2.1 × 10⁵ yr 的 ⁹⁹Tc）——首次证明 n-capture 元素可于恒星原位合成。
[FACT] 现代理论确定 s-process 位点为低-中质量恒星（M ≃ 1.3–8 M_⊙）的 AGB 阶段（Busso, Gallino & Wasserburg 1999；Herwig 2005 等综述）。

## 2.4 r-process 位点

[FACT] B²FH (1957) 与 Cameron (1957) 首次建议位点为新生的中子星外部的中子过剩区（超新星爆发环境）。
[FACT] 迄今无观测在中子星或超新星中直接探测到原位 r-process 元素。多种候选环境：坍缩型超新星、中子星-中子星并合（NS-NS）、黑洞-中子星并合、坍缩磁旋恒星（collapsing magnetorotational stars）——但没有一个模型成功再现 r-process 总丰度分布（Arnould, Goriely & Takahashi 2008）。

## 2.5 s-process branching points 与 components

[FACT] τₙ ∼ τ_β 处出现 branching points，依赖中子密度与温度（如 ⁸⁵Kr, ¹³⁰Te, ²⁰⁴Pb 等关键点）。
[FACT] 需要"weak"成分（大质量星 He 核心燃烧，A ≤ 88）与"strong"成分（解释约 50% 太阳 ²⁰⁸Pb）（Clayton & Rassbach 1967；Käppeler et al. 1982）。

[INTERPRETATION] §2 是全文的核物理基础层：所有后续观测对比、同位素分解、位点讨论，都要回到 τₙ/τ_β 判据和中子幻数结构。Cowan 2021 的进展仍在这一框架内推进。
