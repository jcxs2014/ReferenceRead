**逻辑功能分布**：
- 转折/对比：however, nevertheless, in contrast, whereas, alternatively（5）
- 因果：thereby, consequently, hence, thus, accordingly（5）
- 递进：likewise, furthermore, moreover（3）
- 让步：although, despite, while（3）
- 限定：insofar as, provided that, primarily（3）
- 举例：namely, such as, e.g., for instance（4）
- 结论：overall, clearly（2）

## C. 长难句摘录（5 句）

### C1. [§1, 引言——两种视角的统一]

> "Both ways of looking at the problem are valid up to a point, but for consistency a unified approach would be desirable and to our knowledge has never been attempted."

**主干**：Both ways ... are valid（分句1主谓）；a unified approach would be desirable and ... has never been attempted（分句2，并列谓语）
**修饰**："up to a point"（状语，限定 valid 的程度）；"but"（转折连词，引出对"统一方法"的诉求）；"for consistency"（状语，说明统一的原因）；"to our knowledge"（插入语，弱化论断的语气）
**翻译**：这两种看待问题的方式在一定范围内都是有效的，但为了自洽性，一个统一的方法将是可取的，而据我们所知，这种统一方法从未被尝试过。

---

### C2. [§2.2, 传播方程的数值求解策略]

> "Starting with the solution for the heaviest primaries and using this to compute the spallation source for their products, the complete system can be solved including secondaries, tertiaries etc."

**主干**：the complete system can be solved（被动语态主谓）
**修饰**：句首两个现在分词短语 "Starting with ..." 和 "using this to ..." 作状语，说明求解策略（先解最重初级核，再用它计算碎裂源项）；"including secondaries, tertiaries etc."（介词短语，说明求解对象的完整范围）
**翻译**：从最重的初级核的解开始，再用它来计算其产物的碎裂源项，整个系统就能被求解，包括次级、三次核等。

### C3. [§2.10, GALPROP 第一设计原则]

> "All data relate to the same system, the Galaxy, and one cannot for example allow a model which fits secondary/primary ratios while not fitting γ-rays or not being compatible with the known interstellar gas distribution."

**主干**：All data relate to the same system（并列分句1）；one cannot allow a model（并列分句2）
**修饰**："the Galaxy"（同位语，解释 the same system）；"which fits ... while not fitting ... or not being compatible with ..."（定语从句修饰 model，说明不允许的模型类型）；"for example"（插入语，引出例证）
**翻译**：所有数据都对应同一个系统——银河系——例如，我们不能接受一个拟合了次级/初级比却不拟合伽马射线、或与已知星际气体分布不兼容的模型。

### C4. [§3.2.5, 放射性时钟的逻辑——传播建模核心论断]

> "It is precisely the combination of stable and radioactive data which does allow this: the radioactives determine the diffusion coefficient, which then allows the size of the full propagation region to be determined from the stable secondary/primary ratio."

**主干**：It is precisely the combination ... which does allow this（强调句型，主句）；the radioactives determine the diffusion coefficient（分句1）；the size ... to be determined（分句2，which 引导定语从句含嵌套被动）
**修饰**："precisely"（强调副词）；"which"（关系代词引导定语从句修饰 diffusion coefficient，包含嵌套被动 "to be determined"）；冒号后两个分句为因果链：稳定+放射性 → 扩散系数 → 传播区大小
**翻译**：正是稳定数据与放射性数据的组合允许做到这一点：放射性数据确定扩散系数，而扩散系数又允许通过稳定的次级/初级比确定整个传播区域的大小。

### C5. [§2.11, Wallace 引述——作者对数值法的辩护]

> "It is unclear whether one would wish to go much beyond the generalizations discussed above for an analytically soluble diffusion model. The added insight from any analytic solution over a purely numerical approach is quickly cancelled by the growing complexity of the formulae."

**主干**：It is unclear whether ...（主句，形式主语 it + 表语）；The added insight ... is quickly cancelled by ...（被动语态）
**修饰**：第一句 whether 引导的宾语从句中 "discussed above" 是分词短语作后置定语修饰 generalizations；"for an analytically soluble diffusion model" 介词短语作目的状语；第二句 "from any analytic solution over a purely numerical approach" 是"insight"的来源状语，"by the growing complexity of the formulae" 是被动式的施动者状语
**翻译**：人们是否愿意在解析可解的扩散模型方面超越上面讨论的推广范围，这并不清楚。任何解析解相对于纯数值方法所带来的额外洞察，很快就被公式日益增长的复杂性所抵消。
