# 3. Statistical Method — 统计方法

## 3.1 本节核心内容

§III 描述定义 min/med/max 的统计方法——基于 Wechsler 等的最新 B/C 数据后验分布，从 10⁵ 个 SLIM 模型样本中按分位数选择。

核心方法：**"pinching"（挤压）**——在 $L$ 和 $\ell$ 方向上同时取上/下分位数，得到 min 和 max。

## 3.2 后验样本

**数据来源**：AMS-02 Li/C、Be/C、B/C 联合分析（Wechsler et al. 2020）的最佳拟合值和协方差矩阵。

**采样方法**：从后验协方差矩阵抽取 $10^5$ 个相关 SLIM 传播参数样本。

## 3.3 "Pinching" 方法

**定义**：

| 模型 | 选择准则 |
|---|---|
| MIN | $\log_{10}L$ 和 $\ell$ 的分位数均**小于**中值（晕小 + 扩散弱）|
| MAX | $\log_{10}L$ 和 $\ell$ 的分位数均**大于**中值（晕大 + 扩散强）|
| MED | $\log_{10}L$ 和 $\ell$ 的分位数均**等于**中值 |

**物理含义**：因为 $L/K \sim$ 常数（B/C 约束），$L$ 和 $K_0$ 强相关——选择 $L$ 也同时选择了 $K_0$。

> **分析 / Interpretation**："pinching" 方法的创新在于——不是简单地分别优化每个参数，而是同时沿**物理相关的方向**选择，使得 min 和 max 在物理上一致（即 $L$ 增大时 $K$ 也增大）。

## 3.4 关键参数表（SLIM 方案）

| 参数 | MIN | MED | MAX | 单位 |
|---|---|---|---|---|
| $L$ | 1.0 | 4.0 | 8.0 | kpc |
| $\log_{10} K_0$ | 27.62 | 27.97 | 28.36 | cm²/s |
| $\delta$（$R_1=4$ GV）| 0.52 | 0.46 | 0.42 | — |
| $R_l$ | 4.0 | 5.0 | 6.0 | GV |
| $\ell$（$R_l$ 指数）| 1.30 | 1.50 | 1.70 | — |
| $\dot{E}_0$ | 2.11 | 2.11 | 2.11 | 10¹⁶ GeV/s |
| $V_A$ | 25.0 | 25.0 | 25.0 | km/s |
| $V_c$ | 0.0 | 0.0 | 0.0 | km/s |

**关键观察**：$L$ 和 $K_0$ 同步变化——min 有最小 $L$ + 最小 $K_0$，max 有最大 $L$ + 最大 $K_0$。

## 3.6 作者的逻辑

```
AMS-02 数据 → 后验分布（协方差矩阵）
→ 抽取 10^5 个相关样本
→ 沿 (L, ℓ) 方向取分位数 → MIN/MED/MAX
→ 确保 L 和 K 同步变化（B/C 约束）
```

## 3.7 潜在问题与值得关注的地方

1. **$10^5$ 样本的充分性**：高维参数空间（5 个自由度），$10^5$ 样本是否充分？

2. **"pinching" 方向的选择**：为什么沿 $(L, \ell)$ 而不是 $(L, K_0)$？这是因为暗物质通量标度 $\propto L^2/K$，而 $K/K_0$ 受其他参数影响——$\ell$ 更直接相关。

3. **SLIM vs BIG vs QUAINT**：本文主要分析 SLIM。BIG 和 QUAINT 在附录 C 中讨论，但精度较低。
