## 15.1 一句话总结

Berlin et al. (2026, PRL 137:021804) 证明**百年历史的 Cavendish 库仑定律检验**可作为**室温毫电荷粒子（mCPs）的探测器**，重新解读 PL (1936) 和 BGP (1970) 实验给出与离子阱互补的 mCP 约束；进一步提出 **accumulator+Cavendish 方案**，用几十年前技术即可探测宇宙线不可约 mCP 通量，**在 sub-GeV 质量区间超越未来加速器（LDMX、LHC）**。

## 15.2 核心方法

1. **Cavendish 实验物理**：带电导体壳内部电场本应为零，任何非零值暗示新物理
2. **mCP 选择性透过**：导体壳 work function ~few eV 阻挡 SM 离子，但 $q_\chi \lesssim 10^{-2}$ 的 mCPs 可穿透
3. **两 regime 积聚理论**：
   - 弱耦合：Debye 屏蔽 $\rho_{\rm weak} \simeq \epsilon_{\rm weak}\, m_D^2\, \phi_0$
   - 强耦合：电学捕获 $\rho_{\rm strong} \sim \frac{2}{\pi} \epsilon_{\rm strong}\, eq_\chi n_\chi V_E t_{\rm osc}/R_0$
4. **accumulator 壳方案**：2 m 铁壳 / -1 MV / 内 10⁻⁶ atm 真空 / 1 yr 积分 → 噪声降至 $10^{-11}$ V
5. **不可约通量**：宇宙线簇射 $n_\chi \sim 10^{-5}$ cm⁻³ $(q/10^{-4})^2$

## 15.4 核心创新

1. **Cavendish 重新解释为 mCP 探测器**——把 250 年库仑定律检验传统重新赋予暗物质搜索意义
2. **Cavendish 本身既是 accumulator 又是探测器**——双重角色，无需独立源
3. **accumulator+Cavendish 方案以老技术超越未来加速器**——sub-GeV 区间
4. **不可约通量的直接测试**——不依赖暗物质 relic 丰度假设，等价于"测试模型本身"

## 15.6 主要局限

1. **效率因子 $\epsilon_{\rm weak/strong}$** 具体函数仅在 SM [41]，正文不可复现
2. **PL 壳厚度未知**（原文仅 "sheet iron"），采用 1 mm 假设
3. **1 yr 积分噪声外推**未经实验验证——Johnson 噪声是否仍主导未知
4. **1 MV 跨 2 m 铁壳的击穿/泄漏电流**完全未讨论
5. **Fig. 2 中"超越加速器"的精确质量区间**未在正文明确给出
6. **$E_\oplus \neq 0$ 增强效应**缺乏独立实验验证

## 15.7 我应该记住什么（10 条）

1. **Cavendish = 库仑定律检验 = 天然 mCP 探测器**——导体壳对 mCPs 透明、对 SM 离子不透明
2. **两个历史实验**：PL 1936（mV–V 噪声）和 BGP 1970（1.2 nV 噪声）——BGP 的锁相放大器是关键
3. **弱耦合 = Debye 屏蔽**；**强耦合 = 电学捕获**
4. **accumulator 壳**：静电壳通过"拖曳-散射-束缚"循环把 mCP 密度提升 $10^{10}$–$10^{12}$ 倍
5. **accumulator 参数**：2 m 铁壳 / -1 MV / $10^{-6}$ atm 真空 / 1 yr → 噪声 $10^{-11}$ V
6. **不可约通量** $n_\chi \sim 10^{-5}$ cm⁻³ $(q/10^{-4})^2$，来自宇宙线簇射
7. **sub-GeV 质量**下 Cavendish+accumulator 可超越 LDMX/LHC——用几十年前技术
8. **地电场 $E_\oplus \sim 1$ V/cm** 阻止 mCP 蒸发，是积聚增强的关键物理
9. **图 1**（历史实验重新解读）vs **图 2**（accumulator 未来灵敏度）——前者是现状，后者是目标
10. **哲学优势**：Cavendish 探测"已存在"的 mCPs；加速器探测"新产生"的 mCPs——两者在参数空间不同区间互补
