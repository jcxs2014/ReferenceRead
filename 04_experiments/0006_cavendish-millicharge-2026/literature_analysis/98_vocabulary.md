## B. 领域术语

### mCP 物理

| 术语 | 中文 | 说明 |
|---|---|---|
| millicharged particle (mCP) | 毫电荷粒子 | 有效电荷 $eq_\chi \ll 1$ 的新粒子 |
| charge $eq_\chi$ | 有效电荷 | $q_\chi$ 无量纲，典型 $10^{-6}$–$10^{-2}$ |
| Debye mass $m_D$ | Debye 质量 | mCP 对光子屏蔽质量的贡献，$m_D = \sqrt{eq_\chi n_\chi/T}$ |
| weak-coupling regime | 弱耦合区 | $eq_\chi \ll T$，Debye 屏蔽主导 |
| strong-coupling regime | 强耦合区 | $q_\chi \gtrsim T/(e\phi_0)$，电学捕获主导 |
| accumulation / accumulator | 积聚 / 积聚器 | 静电壳把 mCPs 拖入壳内并捕获 |
| thermalization | 热化 | mCPs 与大气散射至室温 ~300 K |
| overdensity | 密度增强 | 地球附近 mCP 密度相对宇宙背景的提升 |
| kinetically mixed dark photon | 动力学混合暗光子 | mCPs 与 SM 耦合的 mediator |
| effective charge density $\rho_{\rm eff}$ | 等效电荷密度 | 壳内 mCPs 产生的等效体积电荷 |
| irreducible population | 不可约通量 | 宇宙线簇射产生的持续 mCP 通量 |
| cosmic ray air shower | 宇宙线空气簇射 | 产生不可约 mCP 的机制 |

## C. 长难句

| 原文 | 直译 | 逻辑拆解 |
|---|---|---|
| "A terrestrial population of room-temperature millicharged particles can arise if they make up a dark matter subcomponent or if they are light enough to be produced in cosmic ray air showers." | 室温水星级 mCP 的地球族群可以产生，如果它们是暗物质成分，或者足够轻以至于在宇宙线簇射中产生。 | 主语："population"；两个并列条件："if...or if..."；核心动词："can arise"；后置定语链："of room-temperature" 修饰 "millicharged particles" |
| "Here we demonstrate that Cavendish tests of Coulomb's Law, performed since the late 18th century, function as both quasistatic accumulators and detectors for this overdensity." | 此处我们证明，自 18 世纪末以来执行的库仑定律 Cavendish 检验，可同时作为该密度增强的准静态积聚器和探测器。 | 主语："Cavendish tests"；插入语："performed since..." 描述历史；谓语："function as"；宾语："both A and B"（积聚器 + 探测器） |
| "Since mCPs are able to penetrate conducting surfaces, the electric field generated outside the shell induces a charge density of mCPs on the interior." | 由于 mCPs 能穿透导体表面，壳外产生的电场在壳内诱导出 mCP 电荷密度。 | 原因从句："Since mCPs can penetrate..."；主句："electric field induces..."；因果链：穿透能力 → 外部电场进入壳内 → 内部电荷密度 |
