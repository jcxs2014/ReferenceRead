# 2. 地球表面 mCP Population

## 2.1 背景：mCP 如何到达地球

[FACT] 对于足够大电荷的 mCPs，当它们穿越地球时会因与地球原子的碰撞而急剧减速。图 2 给出了在初始 boost × 速度 γχvχ 取不同值时，使 mCP 在地球半径 R⊕ 内热化到室温所需的最小电荷。

[INTERPRETATION] γχvχ 表征入射 mCP 的能量：γχvχ ≫ 1 对应相对论性宇宙线 mCPs；γχvχ ≪ 1 对应非相对论性暗物质子成分。图 2 覆盖这两种极端情况，提供了完整参数空间的 stopping power 约束。

[FACT] 对于 qχ ≳ me/μχN（me = 电子质量，μχN = mCP-核约化质量），负电荷 mCPs 会被原子核有效捕获成束缚态。

[FACT] 对于 mχ ≫ 1 GeV：mCPs 在减速后被引力束缚积累在地球上，产生巨大的 overdensity（引用 13, 14）。对于 mχ ≲ 1 GeV：热速度 > 地球逃逸速度，若无额外相互作用会从地球蒸发。但即使在这种情况下，mCPs 在蒸发前在地球内部的缓慢扩散也能产生不可忽略的 overdensity（引用 14）。

[INTERPRETATION] ~1 GeV 是 mCP 能否被地球引力势阱保留的分水岭：高于此质量，引力束缚可积累巨大密度；低于此质量，需要依赖大气电场的额外捕获效应。

## 2.2 大气电场捕获

[FACT] 大气电场 E⊕ ~ 1 V/cm（地面典型值）在整个大气层中存在，在地壳和电离层之间产生约 φ⊕ ~ 0.3 MV 的平均电压差。晴天条件下稳定维持；雷暴和地磁活动会局部畸变但不影响整体结论。

[INTERPRETATION] 0.3 MV 的大气电压是一个持续稳定数十亿年的全球电路系统的表现。这种持续稳定的大气电结构为 mCP 捕获提供了可靠的背景条件。

[FACT] 结果：qχ ≳ (300 K)/(0.3 MeV) ~ 10⁻⁷ 的正电荷 mCPs 在热化后被 φ⊕ 捕获，主要停留在地壳以下，高度约：
$$h \sim \frac{300 \,\text{K}}{e q_\chi E_\oplus} \sim 1 \,\text{mm} \times q_\chi^{-1}$$

[FACT] 对于动生混合暗光子模型，电捕获饱和：当正 mCPs 积累到一定程度，产生的排斥暗电场可抵消地球大气场，对应体积平均密度上限：
$$n_\chi \sim \frac{3 e q_\chi E_\oplus}{e_0^2 R_\oplus} \sim 10^{-5} \,\text{cm}^{-3} \times \left(\frac{q_\chi}{10^{-3}}\right) \left(\frac{10^{-1}}{e_0}\right)^2$$

## 2.3 A. 暗物质子成分

[FACT] 对于 qχ ≳ 10⁻⁷ × (mχ/GeV)^{1/2}（覆盖大多数感兴趣参数空间），mCPs 在宇宙早期辐射温度 T ≳ mχ 时与 SM 浴达到热平衡。

[FACT] 大耦合也意味着 mCPs 在复合时期（recombination）与光子-重子流体紧耦合。若 mCPs 构成 O(1) 分数的暗物质，这将与 CMB 测量强烈冲突。因此它们必须只占暗物质的一个小分数 fDM ≪ 1。

[INTERPRETATION] fDM ≪ 1 的物理来源：若 qχ ≫ 10⁻³ × (mχ/GeV) 或 e' ≫ 10⁻² × (mχ/GeV)^{1/2}，mCPs 可高效湮灭到 SM 费米子对或暗光子。极端情况下 fDM ~ 10⁻¹⁰ × (mχ/GeV)² 仍可实现。

[FACT] 直接探测实验对强耦合 mCP 子成分基本不敏感：当 fDM ≲ 10⁻⁸ 时实验变成信号噪声受限；当 qχ ≳ 10⁻⁴ × (mχ/GeV)^{1/2} 时，mCPs 进入探测器前就早已热化到室温以下。

[FACT] 暗物质子成分的 overdensity 估算：
- mχ ≫ 1 GeV：引力束缚，地球上的 overdensity 可达 ~10¹⁶ 倍（宽范围电荷）
- mχ ≪ 1 GeV：蒸发前延长停留时间，overdensity ~ 10⁸

[INTERPRETATION] overdensity ~10¹⁶ 的含义：如果暗物质中有 10⁻¹⁶ 的极小分数以 mCP 形式存在，其在地球上的热化密度就与普通暗物质相当。这意味着对 fDM ≪ 1 的 mCP 子成分的探测等价于对整体暗物质性质的探测。

## 2.4 B. 宇宙线不可约 Population

[FACT] 与星系暗物质无关，宇宙线空气簇射会产生不可忽略的地球 mCP population。对于 mχ ≪ 10 GeV，主要产生机制是次级宇宙线介子的衰变。关键优势：**与宇宙早期演化模型无关**，不受太阳和地球磁场传播影响——因为这些 mCPs 是在地球大气中本地产生的。

[FACT] 相对论性宇宙线 mCPs（引用 16, 29, 30, 54, 55）可以有效散射进入地壳，热化到室温。即使最终非相对论性 population 会从地球蒸发，其在大气中的缓慢扩散也会增强 mCP 密度。

[FACT] 若 mCPs 不能被地球引力或电磁场束缚，最终会蒸发。此时在深度 x > 0（大气顶部以下）的非相对论 mCP 密度为：
$$n_\chi(x) \simeq \int dE_\chi \frac{d\Phi^{(\text{CR})}_\chi}{dE_\chi} P^{\oplus}_{\text{th}} \frac{\min(x,x_{\text{th}}) - x_{\text{LSS}}}{D_\chi}$$

其中：x_th = 热化深度；x_LSS = 最后散射面；P^{\\oplus}_{th} = 热化概率；D_χ = 扩散系数。

[FACT] 若 mCPs 被地球捕获（引力或电磁），积累时间 ~ t⊕ ≈ 4.5 × 10⁹ yr，体积平均密度为：
$$n_\chi \simeq \frac{3 t_\oplus}{R_\oplus} \int dE_\chi \frac{d\Phi^{(\text{CR})}_\chi}{dE_\chi} P^{\oplus}_{\text{th}}$$

[INTERPRETATION] 不可约性的重要意义：探测宇宙线 mCP population 等价于直接探测该粒子本身，与加速器探测等价，无需假设 mCP 是否构成暗物质或其宇宙学丰度。

[CRITIQUE] Refs. [54, 55] 声称质子韧致辐射（proton bremsstrahlung）是 0.1–1 GeV 质量区间的主要产生机制，但本文作者认为这可能是对同量光子-矢量介子混合共振增强的重复计算。保守地不予纳入，但这可能使结果在 100 MeV–1 GeV 区间偏保守。

[FACT] 本文改进了 Ref. [14] 的计算：使用了 Ref. [29] 的公开代码计算 Φ^{(CR)}_χ，包含了 π、η、ρ、ω、ϕ 和 J/ψ 介子衰变的贡献，并补充了 ϒ 衰变（按 Ref. [55] 的半解析步骤）。

[FACT] 图 3 的关键信息：左图（忽略 E⊕）和右图（包含 E⊕）比较——大气电场对亚 GeV mCPs 的密度有 ~10⁵ 倍的提升，对 GeV 以上质量则无影响（已被引力束缚）。
