# 6. 附录 A：室内 vs 室外

## 6.1 背景

[FACT] §IV A 研究 accumulator 放置位置（室内 vs 室外）对收集效率的影响。在 ~1 年的积分时间上灵敏度最大化的设计中，accumulator 最好放在室外，因为收集的 mCP 总数最终受限于电场范围所决定的最大包围空间。

## 6.2 室内约束

[FACT] 室内情形的通量约束（公式 10）来自四个来源：
1. **房间容积限制**：半径 R_room 的球形室内，mCPs 总数受限于房间体积内现有 mCP 数量，补充速度受进入壳层的速率限制
2. **通风口渗入**：空气（及伴随的碰撞耦合 mCPs）通过通风口以速度 V_vent 进入房间
3. **墙壁扩散渗透**：mCPs 通过扩散穿过墙壁进入
4. **重力沉降**：mCPs 在地球重力场中的漂移速度 V^{(air)}_g

[FACT] 墙壁扩散项中的扩散系数 D^{(wall)}_χ = Tχ/(mχΓ^{(wall)}_p)，其中 Γ^{(wall)}_p 是 mCP-墙材料碰撞的动量交换率。

[INTERPRETATION] 室内设计的本质挑战：在四个 mCP 来源之间存在竞争关系。任何减少 mCP 流入壳层的因素（如厚墙、低渗透率、良好密封）同时也减少了环境 mCP 的总体可用性。优化的室内设计需要在收集效率和可用粒子数之间找到平衡。

## 6.3 室外优势

[FACT] 室外（或更大的封闭结构）可以避免公式（10）中的多项限制，只保留电场范围本身的几何约束。对于半球形电场构型，有效收集半径由 φ₀/E₀ ~ R₀ 决定。

[INTERPRETATION] 室外的本质优势：没有墙壁损失、没有通风稀释、没有空间上限——只有 mCP 从周围空气持续进入电场范围的速率限制。这使 VE 的全几何利用成为可能。

## 6.4 β_E 参数

[FACT] 公式（8）中的无量纲参数 β_E 考虑了壳层电场被局部环境屏蔽的效应。对于按 r⁻²（单极子）或 r⁻³（偶极子）衰减的电场，在远距离处 β_E ≃ 1 或 β_E ≃ √(π e qχ φ₀/(2Tχ)) ≫ 1。

[FACT] 在没有任何附近图像电荷的情形（如壳层放在室内，远离任何更大的导体结构），电场在非零处纯粹是单极子的，在任何远处都如此。但若壳层放在室外靠近地球表面，地球表面的导电性质在其下方产生图像电荷，导致在足够远处形成偶极子型场。

[INTERPRETATION] β_E 的实际影响：对单极子场（β_E ≃ 1），VE 由碰撞率直接决定；对偶极子场（β_E ≫ 1），有效电场在远离壳层处被更强地压低，导致 VE 相对减小。因此室外偶极子效应会弱化收集效率。
