# 7. 附录 B：电捕获机制

## 7.1 捕获判据

[FACT] §IV B 推导了 mCP 在充电壳层中最终被电捕获的条件。在时间 t 内，被电势 φ₀ 捕获的 mCPs 产生的过量密度由时间积分给出。

## 7.2 捕获条件

[FACT] mCP 被捕获的判据来自两个关键条件：① 进入壳层内部（穿过导体表面的电势壁垒）；② 进入后通过碰撞损失足够的能量以至于无法克服壳层电势逃逸。

[INTERPRETATION] 第一个条件要求 mCP 的热能量 Tχ ≪ qχ |eφ₀|（否则无法进入内腔）；第二个条件要求 mCP 与壳内物质的碰撞率足够高，使其在穿越壳层到达中心前就完成能量损失。这两个条件共同决定了 ε_bound 的量级。

## 7.3 参考文献

[FACT] 附录 B 推导了在壳内物质（模拟为实心球）中碰撞热化的 mCP 的捕获概率，以及最终被 φ₀ 电势阱束缚的效率。
