# 5. 结论

## 5.1 核心结论

[FACT] 本文证明了带固定大电压的导体壳层（如 Van de Graaff generator）可以作为强大的 millicharged particles（mCPs）累积器。这样的装置能够在室温 mCP population 中将局部密度提升最多 ~10¹² 倍，相比地球平均密度。

[INTERPRETATION] 这一数量级的增强使现有探测策略（离子阱、Cavendish 实验、静电加速技术）在无需任何新技术的情况下，能够达到超越当前实验上限的灵敏度。

[FACT] Accumulator 内积累的过量 mCPs 同时覆盖宇宙学产生的 mCPs 和由宇宙线本地产生的 population。后者代表了不可约的 mCP 密度（即探测它直接等价于探测该粒子本身， agnostic 于其宇宙学丰度）。

## 5.2 物理意义

[FACT] 对于现实的实验配置，积累的密度可以达到接近宇宙线产生的不可约 mCP 密度的水平，其对应的灵敏度超越了未来加速器对 sub-GeV 质量的直接搜索能力。

[INTERPRETATION] 这一方案的本质优势：不需要假设 mCP 是否构成暗物质、丰度多少——只要 mCP 存在（由宇宙线在大气中产生是模型无关的），就可以被探测。这是一个真正"不可排除"的探测窗口。

[FACT] 本文的通用框架可以直接应用于任何封闭在 accumulator 壳层内部的探测器，对 mCP 参数空间的覆盖不依赖于具体的探测实现方式。

## 5.3 未来方向

[FACT] 进一步的改进方向（将在未来工作中探索）：如何增强 accumulator 本身的灵敏度；具体实验装置的工程优化；与其他 mCP 探测方案（暗光子暗物质、轴子等）的协同探测策略。

## 5.4 科学贡献总结

[FACT] 本文的主要科学贡献：
1. 提出了带电压壳层作为 mCP 累积器的通用方案（原创性）
2. 建立了从宇宙线在大气中产生 mCP 的不可约通量计算框架（改进自 Ref. [14]）
3. 推导了 accumulator 内密度增强因子的解析表达式（公式 7、8）
4. 将方案具体应用于 Cavendish 实验，展示了在 ~1 年积累时间内的实验灵敏度（companion paper）

[CRITIQUE] 本文的理论框架高度依赖 mCP 与普通物质的强耦合（qχ ≳ 10⁻⁷）假设。对于更小电荷的 mCPs（qχ ≲ 10⁻⁸），热化和捕获机制失效，本文的方案不再适用，需要其他探测策略。这意味着 accumulator 方案和现有的加速器/宇宙学约束共同覆盖的仅是 mCP 参数空间的一部分。
