# 1. 理论与实验背景

## 1.1 背景：mCP 与暗物质

[FACT] 标准模型（SM）尽管取得了巨大成功，但仍存在诸多未解之谜，推动物理学家寻找 SM 的扩展。新粒子 χ 具有极小的有效电磁电荷 qχ ≲ 10⁻¹，被称为 millicharged particles（mCPs）。

[FACT] mCPs 可以自然地通过 kinetic mixing 机制产生：新的长程 U(1) 暗规范光子 A' 与 SM 光子之间通过混合项 ℒ ⊃ (ε/2) F'μν Fμν 产生相互作用。

[INTERPRETATION] kinetic mixing 参数 ε 的量级估计：若 N 代重粒子同时带两种荷，则 ε ~ Ne²e'/(4π)²，进而 qχ ~ Nα'/4π。对于 e' 与 e 同量级的暗精细结构常数 α'，预期 qχ ~ N × 10⁻³。这给出了 mCP 电荷的自然量级。

[FACT] mCPs 既是可行的暗物质候选者，也可用来解释多个实验异常（引用 6-12）。

[FACT] 尽管数十年的严格检验，mCPs 的参数空间仍有大量未探索区域：对 GeV 质量级别的粒子，电荷 qχ ~ 10⁻³–10⁻¹ 的范围基本没有约束。

[FACT] 当 mCPs 存在于地球上时，由于长程电磁相互作用，它们会迅速与普通物质散射、热化到环境温度（约 300 K ≈ 25 meV），形成不可忽略的地面密度（引用 13, 14）。

[INTERPRETATION] 300 K 对应能量远低于典型实验传感器的探测阈值——这意味着热化后的 mCPs 对传统探测器是"隐形的"，但它们的高密度恰恰为累积捕获提供了基础。

## 1.2 目标：Accumulator 方案

[FACT] 本文提出一种简单修改：将探测器封闭在固定电压壳层内，可以在不改变探测器本身的前提下将 mCPs 的局部密度大幅提升。

[FACT] 这种带电压壳层（如 Van de Graaff generator）作为高效累积器，可在运行时间 t 年内将 mCPs 密度增强最多约 10¹² × (t/yr) 倍，相比地球平均密度。

[INTERPRETATION] 增强因子 10¹² 的物理来源：壳层电压 ~10 MV，对 mCPs 的静电吸引 + 多次散射热化的协同效应，将稀薄的宇宙线次级粒子流转化为高密度"陷阱内"population。

[FACT] Accumulator 内部几乎没有电场（除 mCPs 自身产生的场之外），因此可以容纳对过量密度敏感的精密探测器。

[FACT] 在姐妹论文（PRL 137, 021804）中，作者将这一方案具体应用于 Cavendish 实验，使用数十年历史的探测技术即可对宇宙线产生的不可约 mCP 密度达到探测灵敏度，超越未来加速器对 sub-GeV 质量的探索能力。

## 1.4 模型 I：动生混合

[FACT] 在暗光子模型中，拉格朗日量包含动生混合项：ℒ ⊃ ε/2 F'μν Fμν − j'μ A'μ，其中 F'μν 和 Fμν 分别是暗和 SM 的场强张量，ε 是小无量纲混合参数，j'μ 是粒子 χ 的暗流。

[FACT] 对 ε ≪ 1 做场重定义 A' → A' + εA，可将对角化做到领头阶。结果：χ 获得有效 SM 电磁荷 eqχ ≃ εe'，其中 e' 是暗规范耦合。

[INTERPRETATION] 这一机制优雅地解释了 mCP 的小电荷：只需假设 ε 很小（通常来自高阶圈图或小耦合），即可自然得到 qχ ≪ 1。若暗光子有质量 mA'，则 χ 仅在距离 < mA'⁻¹ 的尺度上表现得像有电荷。

[FACT] 若 mCP 直接带 SM 电磁荷（不通过暗光子），则需要保证整体规范不变性——要求 mCP 和电子的电荷量子化条件协调（qχ 和 qe 均取整数基本电荷的整数倍），然后通过 e ≪ 1 的小耦合来自然得到 eqχ ≪ 1。

## 1.5 模型 II：直接电磁荷

[FACT] 当 mCP 直接带 SM 电磁荷时，SM U(1) 规范变换是良好定义的，但要求 mCP 和电子的电荷（qχ 和 qe）相对于同一基本电荷单位取整数值。小耦合通过 e ≪ 1 实现，使得 eqχ ≪ 1 同时 qe ≫ 1。

[INTERPRETATION] 与暗光子模型不同，直接电磁荷模型的相互作用在真空中是任意长程的，没有质量门的截断。这两种模型在实验预言上有细微差别（尤其在实验室尺度上的屏蔽行为），本文在必要时分别讨论。

## 1.6 实验现状

[FACT] 现有最强约束来自离子阱实验中的反常加热效应（引用 17, 18）。其他约束来自加速器探测（29, 31-38）和 SN 1987A（39）。

[CRITIQUE] 现有实验策略均未能在 qχ ~ 10⁻³–10⁻¹ 区间达到有效灵敏度，而这一区间对于 GeV 质量级别的 mCP 来说恰恰是自然且未被排除的。Accumulator 方案正是要填补这一空白。

## 1.7 小结

[FACT] §I–§II 建立了 mCP 的理论框架：动生混合与直接电磁荷两种实现方式；地面 mCP 可以是暗物质子成分或宇宙线次级产物两种来源；现有探测器在 qχ ~ 10⁻³–10⁻¹ 参数区间的灵敏度严重不足。
