# §8 Conclusions — 结论
## [FACT] 8.1 结论一：天体物理中微子通量存在（4σ）

**核心结论**（原文 Summary, p.1）：
> "the directions, energies, and topologies of these events are not compatible with expectations for terrestrial processes, deviating at the **4σ level** from standard assumptions for the atmospheric background."

**关键数值**：
- 观测：28 起（30–1200 TeV）
- 预期背景：10.6<sup>+5.0</sup><sub>−3.6</sub> 起
- 显著性：4.1σ（先验 Fisher 合并）/ 4.8σ（事后）

## [FACT] 8.2 结论二：源方向未能识别

原文（p.1 Discussion）："With the current level of statistics, we did not observe significant clustering of these events in time or space, preventing the identification of their sources at this time."

- 最强空间聚类 TS 显著性：**8%**（5 起 shower，含第 2 高能量事件，RA=281°, Dec=−23°）
- 银心方向 TS 显著性：**5.4%**
- 无显著时间聚类

## [FACT] 8.3 结论三：与天体物理源模型一致

原文（p.1 Discussion）：
> "Although not compatible with an atmospheric explanation, the data do match expectations for an origin in unidentified high-energy galactic or extragalactic neutrino accelerators."

**关键证据**：
1. **能量过高**：2 起 >1 PeV（event 14: 1424 TeV, event 20: 1433 TeV）
2. **谱过硬**：E<sup>−2.2±0.4</sup> vs 大气 ν p/K 外推
3. **南天偏置**：~60% 来自南天（地球吸收效应）
4. **Track 分数过低**：25% vs p/K 大气 ν 预期 75%
5. **Flavor 混合**：与 1:1:1 equipartition 一致

## [FACT] 8.4 结论四：观测到的 ν 能量记录

**2 起 >1 PeV 事件**（原文 p.3）："These 28 events, which include the highest energy neutrinos ever observed"

- Event 14：1424<sup>+108</sup><sub>−137</sub> TeV（~1.4 PeV），Dec = −27.9°，RA = 265.6°
- Event 20：1433<sup>+143</sup><sub>−137</sub> TeV（~1.4 PeV），Dec = −67.2°，RA = 38.3°

**截至 2013 年，这是人类探测到的最高能量中微子**。

## [FACT] 8.5 结论五：IceCube 有效性的验证

- 全效率域：**>数百 TeV**
- 阈值：**30 TeV**
- 事件选择：**in-fiducial-volume first light + Q_tot ≥ 6000 photoelectron**
- Veto 效率：>6000 photoelectron 时 veto 掉 99.999% μ 背景

## [FACT] 8.6 结论六：对后续观测的指引

**原文隐含**（讨论段落）：
1. **增加曝光量**：28 起事件统计量不足以精确定位源（8 年数据 → IceCube 2016 Science 353 报告 57 起 >30 TeV 事件，最终 ~150+ 起）
2. **提升角分辨率**：shower 事件 10°–15° 是主要瓶颈 → 后续 track 样本积累
3. **识别源**：2017 IceCube-170922A / TXS 0506+056 → 首个识别的中微子源（blazar）
4. **多信使联合**：与 γ 射线、引力波、宇宙线观测联合

## [INTERPRETATION] 总结性评价

**IceCube 2013 是 21 世纪天体物理观测的里程碑论文之一**，其地位可比拟：
- **1968 Davis 太阳中微子**（发现中微子天文学）
- **1987A 超新星中微子**（多信使天文学起点）
- **2015 LIGO GW150914**（引力波天文学起点）

IceCube 2013 以 4σ 显著性**开启了 TeV–PeV 中微子天文学**，为后续的 IceCube-170922A（TXS 0506+056）、NGC 1068 等源识别奠定了基础。该论文的方法学范式（盲分析、data-driven 背景、多属性联合检验）成为高能中微子天文实验的标准做法。
