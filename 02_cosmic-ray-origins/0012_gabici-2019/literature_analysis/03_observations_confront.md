## 3.1 [FACT] 局域 CR 谱异常

### 3.1.1 [FACT] 核子谱异常

PAMELA 和 AMS02 揭示两个关键观测：

1. **质子谱比氦谱软 $\Delta\alpha \approx 0.1$**——在所有能量上
2. **两个谱都在 $\sim 300$ GV 处硬变**（$\Delta\alpha \approx 0.13$）

**碳和氧**（AMS02 精确测量至 3 TV）：
- He/C/O 谱指数在相同刚度和相同幅度硬变
- He/O 和 C/O 比值在 $< 60$ GV 时柔软下降
- **结论**：符合"相同注入谱 + 相同传输"的标准图像
- 但**质子与氦的谱差异**无法用纯传输解释

**§3.1.1 硬变起源的证据**：用 B/C 次级比数据验证——若硬变来自传播（扩散系数特征），次级谱硬变应是初级的两倍；若来自注入谱，应相同。AMS02 B/C 至 TeV 能量数据 + Li/Be/B 绝对谱 → **支持扩散传播起源**。

**物理模型**（硬变的物理解释）：
- **模型 A**：扩散系数在盘内/晕外具有不同的刚度依赖（非因子化）——盘内 SNR 驱动湍流，晕内不同起源
- **模型 B**（Gabici 更倾向）：外部湍流（Kolmogorov）+ CR 自激 Alfvén 波（streaming instability）——非线性阻尼率等于 streaming instability 增长率在 $R \approx 200$–$300$ GV 处——**惊人地接近观测硬变能量**

### 3.1.2 [FACT] B/C 比峰值与扩散再加速

B/C 在几 GeV 处出现峰值：

| 解释机制 | 能量注入成本 | 评价 |
|---------|------------|------|
| 扩散再加速 (DR) | $V_A \approx 30$ km/s → **30–50% 的 GeV CR 能量来自 ISM 而非 SNR** | 论文批评："不应仅因 DR 拟合好就盲目使用" |
| 银河风对流 | 能量无关项 → 低能主导 | 应被同等考虑 |
| 扩散系数在 $\sim 1$ GeV/n 处阻尼 | 较小的 DR 贡献 + Kraichnan 行为 | 可与所有 AMS-02 数据拟合 |

### 3.1.3 [FACT] 电子谱中的显著断点

**电子谱远陡于质子谱**——即使计入能量损失，电子注入谱与质子也不同。

**关键观测**：

| 实验 | 结果 |
|------|------|
| Fermi-LAT | $e^+ + e^-$ 谱在 7 GeV–2 TeV 为 $E^{-3.08 \pm 0.05}$；$E_b = (53 \pm 8)$ GeV 断点 |
| PAMELA | $e^-$ 在 30–625 GeV 为 $E^{-3.18 \pm 0.05}$，无显著特征 |
| AMS02 | $e^-$ 谱在 $> 10$ GeV 不能用单幂律拟合；$\sim 30$ GeV 处硬变 |
| H.E.S.S. | $\sim 1$ TeV 处急剧变陡：$\alpha = -3.04 \to -3.78$ |
| CALET/DAMPE | 至 5 TeV，$\alpha \approx -3.2 \to -4.1$ |
| VERITAS | 确认 H.E.S.S. 断点 |

**20 TeV 电子的来源**：能量损失时间极短 → 源必须在 $\lesssim 100$ pc 的极近邻

### 3.1.4 [FACT] 反物质（正电子和反质子）

**正电子分数** $e^+/(e^+ + e^-)$（PAMELA, AMS02）：
- $\sim 8$ GeV 以上显著上升
- IC 能量损失+同步辐射约束源年龄 $\lesssim 10^5$ yr，距离 $< 1$ kpc
- 暗物质解释被提出 → 但年轻脉冲星、附近 SNR 等天文源也能解释
- **AMS02 最新**：正电子分数在 $\sim 400$–$500$ GeV 下降 → **不利于脉冲星/脉冲星风**为主要高能轻子源

**反质子**：AMS02 至 300 GeV；$\bar{p}/p$ 在 $> 10$ GeV 几乎平坦 → 可能与纯次级产生一致

### 3.1.5 [FACT] "异端"解释的六种主张

论文列出挑战正电子/反质子谱的**六条异端主张**：

1. $e^-$ 与 $p$ 谱差异在源处产生（非传播）
2. CR 驻留时间极短（$\sim 0.5$–$1$ Myr at 1 TeV）
3. 正电子和反质子是标准次级产生（无额外源）
4. $(e^- + e^+)$ 的断点来自传播中的能量损失
5. 反物质与正物质的谱比较可估计驻留时间的刚度依赖
6. LiBeB 等次级核素很可能在源处产生

**需要澄清的关键问题**：
- $e^-$ 和 $e^+$ 谱分别的延伸测量
- Be 同位素能量范围扩展
- 银河系内 $e^-/e^+$ 空间依赖
- AMS02 $e^+$ 至 1 TeV：$e^-$ 谱的软化用指数抑制 $e^{-E/E_s}$，$E_s = 810^{+310}_{-180}$ GeV 拟合 → 可能是新硬源的最大能量，也可能是能量损失导致的断点

## 3.2 [FACT] 各向异性

### 3.2.1 大尺度各向异性（偶极子）

| 能量范围 | 幅度 | 相位 |
|---------|------|------|
| $< 10$ TeV | $\sim 10^{-3}$ 增长 | $\sim 45°$ R.A. |
| 几百 TeV | $\sim 10^{-4}$ 极小 | $\sim 45°$ R.A. |
| 几十 PeV | $\sim 10^{-1}$ | $\sim 270°$（银河系中心方向） |

**各向异性问题**：观测到的偶极幅度与简单扩散模型预言不一致。数据 $10$–$15$ 年持续确认这一差异。

**可能解**：
- 非各向同性扩散（梯度投影到磁场方向）
- 湍流磁场随机性 → 低偶极振幅的实现
- 源离散性 → 偶极振幅和相位的时空变化
- 扩散系数的刚度依赖修正
- 盘内扩散逃逸增强（自激湍流更强 → 垂直扩散更大）

### 3.2.2 小尺度各向异性

| 实验 | 发现 |
|------|------|
| Tibet, Milagro, ARGO-YBJ | TeV-PeV 能量局部热斑 $\sim 10^{-4}$ |
| IceCube | 小尺度角功率谱（证明 $10°$ 尺度结构存在） |
| HAWC + IceCube | 平滑角功率谱至 $10°$ 尺度 |

**最简单解释**：**局域湍流磁场**——小角度到达的 CR 经历了相似的湍流场取向，轨迹相关产生小尺度结构（分析+数值研究已证明）

## 3.3 [FACT] 远源 CR 观测

### 3.3.1 [FACT] GeV 超量

银河系中心 $\sim 3$ GeV 处的球对称超量：
- **暗物质解释**：最初声称（但被多种再分析削弱）
- **天体解释**：（1）中央分子区（CMZ）高恒星形成活动 + IC 模板修正；（2）未分辨毫秒脉冲星群
- **SkyFACT 分析**：超量形态与中央棒状/花生状核球的恒星分布相关 → **支持毫秒脉冲星假说**
- 底线上限：（1）中心区扩展信号存在；（2）特性依赖于 CR 源分布假设；（3）脉冲星解释未来可用射电验证

### 3.3.2 [FACT] 强子 γ 射线发射的渐进硬化

**Figure 5**：Fermi-LAT 推断的强子 CR 谱指数随银心半径变化——**向银心方向渐进硬化**（$\alpha \approx 2.8 \to 2.2$）

**物理解释竞争**：
- **方案 A**：内银河系对流主导（streaming instability 更强）
- **方案 B**：内银河系存在垂直极向磁场分量 + 平行扩散比垂直扩散更硬 → CR 从垂直逃逸渐进过渡到平行逃逸

### 3.3.3 [FACT] 梯度问题

**Figure 6**：Fermi-LAT 观测的 π⁰ 衰变发射度随银心半径变化——**在 $R > 5$ kpc 处仅下降 20–40%**

**张力**：标准传输理论预期 CR 密度在太阳圆外**快速下降**——观测远平坦。

**尝试解**：
1. 晕尺寸加大到 $\geq 10$ kpc → 缓解但仍不完全解决；与 ¹⁰Be/Be 和同步辐射数据有张力
2. 源分布更平坦 → 与 SNR/pulsar/OB 星 catalog 矛盾
3. $X_{\rm CO}$ 因子骤升（分子氢密度假设错误）→ Fermi-LAT 原子氢分析显示问题仍存在
4. **垂直扩散的空间依赖**（源密集区湍流更强 → 垂直扩散更强 → CR 密度平坦化）

### 3.3.4 [FACT] Fermi 气泡

- 银心上下各 $\sim 10$ kpc 的双泡结构
- 锐边+均匀亮度
- $1$–$100$ GeV：$E^{-2}$ 谱（比银河系弥散发射更硬）
- 与微波 haze 关联 → **轻子场景更自然**
- 起源：（1）AGN 相对论外流（超大质量黑洞过去活动）；（2）恒星爆发/恒星风
- **关键**：CR 被输运/加速到 $\sim 10$ kpc——**超出通常假设的晕高度**（$\sim$ few kpc）

### 3.3.5 [FACT] 局域 ISM 中的 CR 谱

**关键发现**（Gabici 等 2019 引用 Ref. 91）：

> **由 Fermi-LAT 局域 HI 发射度反推的 CR 质子谱，比 AMS02 直接测量高 $1.4 \pm 0.5$ 倍**（$> 1$ GeV）。

**意义**：地球处的 CR 观测**可能不代表**局域 $\sim 1$ kpc 范围内的 CR 性质。

**对 DR 模型的不利证据**：同步辐射 + γ 射线数据共同挑战标准再加速模型，**支持无再加速或弱再加速的纯扩散/对流模型**。
