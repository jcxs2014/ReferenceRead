# 99. Final Summary — 最终总结

## 99.1 一句话总结

Blandford & Eichler (1987) 是对激波处一阶 Fermi 加速（DSA）理论的全面综述——从测试粒子近似到非线性自洽处理，证明 DSA 是宇宙线起源的普适机制，宇宙线已成为激波结构的本质组成部分。

## 99.2 科学问题

**核心问题**：宇宙线起源于何处、如何被加速到观测能量？

在 B&E 1987 写作的时代（1977-1987）：来源基本确定（超新星），但加速机制的争论持续了 30 年。

## 99.3 核心方法

**DSA（Diffusive Shock Acceleration）**：
- 粒子被 Alfvén 波散射反复穿越激波面
- 两侧流体汇聚（$u_- > u_+$）使每次穿越获得动能
- 逃逸时间与加速时间可比，天然给出幂律
- 谱指数 $q = 3r/(r-1)$，只由压缩比决定

## 99.4 最重要结果

| 结果 | 值 | 意义 |
|---|---|---|
| DSA 谱指数 | $q = 3r/(r-1)$ | 普适关系 |
| 强激波谱 | $r = 4 \to q = 4$ | 观测 $4.5$ 需要修正 |
| 单 SNR CR 注入 | $\sim 3 \times 10^{49}$ erg（$3\%$）| 满足能量需求 |
| CR 年龄 | $\sim 20$ Myr | $^{10}{\rm Be}$ + 同步损失一致 |
| SNR 高能截断 | $10^{15}$ eV | Larmor 半径 = SNR |
| 非线性能量效率 | $\eta \sim 10-30\%$ | 自洽可达 |

## 99.5 核心创新

1. **从测试粒子到非线性自洽**——CR 是激波结构的组成部分，而非被动加速者
2. **能量不平等无需选择性**——高能粒子扩散更远，自动吸收更多能量
3. **Alfvén 波自激发回路**——CR streaming → Alfvén 波 → 散射 → CR 加速
4. **统一加速图像**——从地球弓激波到 AGN 喷流，DSA 是普适机制

## 99.6 主要局限

- 注入机制仍是开放问题
- 准线性理论在 $\mu \to 0$ 失效
- 一维平面激波假设限制
- 各向异性散射未完全处理

## 99.7 我应该记住什么

1. **DSA 谱指数：$q = 3r/(r-1)$**——DSA 最核心公式
2. **三阶跃迁**：测试粒子 → 非线性自洽 → 注入机制
3. **CR 是激波结构的组成部分**——这是 B&E 1987 最具原创性的观点
4. **能量不平等无需选择性**——高能粒子自动吸收更多能量
5. **Alfvén 波自激发**——CR 自身提供散射源
6. **SNR 只能到 $10^{15}$ eV**——UHECR 另有来源
7. **注入是 DSA 最大薄弱环节**——至今仍未完全解决
8. **B&E 与 BO 1978 的关系**：BO 是 Letter 级发现，B&E 是 75 页综述——理论从发现到成熟的里程碑
