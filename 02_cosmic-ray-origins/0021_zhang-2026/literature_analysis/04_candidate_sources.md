# 4. Candidate sources of UHECRs

> **UHECR 的候选源（原文逐字标题）**
> **中文翻译**：逐类评估大质量恒星死亡、致密双星并合、潮汐瓦解事件、活动星系核四类候选源。

## 4.1 Massive stellar deaths

> **大质量恒星死亡（原文逐字标题）**
> **中文翻译**：GRB、引擎驱动超新星、脉冲星、磁星驱动暂现源。

[FACT] GRB 是宇宙中最亮、可能最强的高能天体现象[57]。高光度 GRB (HL GRB) 典型各向同性辐射光度 10⁵¹–10⁵³ erg s⁻¹，因加速能力与能学被视为有希望的 UHECR 源[24,25]。

[FACT] 但 GRB 喷流的重子含量受"GRB 与高能中微子无符合探测"强约束[58]；对上千个 GRB 的详细分析显示全宇宙 GRB 的暴发中微子发射限于弥漫天体中微子流的 1%[59]。LL GRB 则可主导 IceCube 探测到的弥漫中微子流[19]。

[FACT] UHECR 核在 prompt 发射区通常无法存活；afterglow 相位中 HL 与 LL GRB 核均可存活[21,23]。LL-GRB 优于 HL-GRB 的三个理由：①LL 允许核存活；②若由外激波加速 CR 可缓解窄刚性问题；③LL-GRB 事件率高于 HL-GRB。

[FACT] Jet-B 模型示例：UHECR 核质量分数 O=0.511、Si=0.364、S=0.108，处于完全存活区。新生脉冲星与磁星由大质量恒星塌缩/低质量中子星并合遗迹形成，重核可源自中子星表面并加速至 UHE[30,60-62]。

[INTERPRETATION] 作者逻辑：HL-GRB 因中微子上限被"否决"为主要 UHECR 源，转而推 LL-GRB 与引擎驱动超新星——这是本文对 GRB 源立场的关键修正，区别于早期"GRB 主导"范式（如 2000 年代 Bhattacharjee-Sigl 综述）。

[CRITIQUE] "GRB 中微子 < 1% 弥漫流"的约束依赖中微子-核相关性的特定模型；若 UHECR 核在 prompt 区不存活（作者也承认），则 prompt 中微子本就少，该约束对"UHECR 是否来自 GRB afterglow"说服力有限——作者用 prompt 中微子上限否定 GRB 源，存在将不同辐射区混谈之嫌。

## 4.2 Compact binary mergers

> **致密双星并合（原文逐字标题）**
> **中文翻译**：NS-NS 与 BH-NS 并合喷流作为超重新 UHECR 源。

[FACT] 致密双星并合包括双中子星 (NS-NS) 与黑洞-中子星 (BH-NS)；短 GRB 常与之关联，喷流是高效 CR 加速场所。

[FACT] 大电荷数 Z 可使超重新 UHECR (UH-UHECR) 核加速至 UHE 能区；UH 核由富中子环境中的 r-process 合成，第三峰物质存在于赤道面（动力学抛射物）。

[FACT] NS-NS/BH-NS 并合激波被提议为 UH-UHECR 核源，可能与 Amaterasu 粒子（240 EeV）起源相关[26,65]。Ref.[26] 用 UH-UHECR 核联合拟合 Auger 与 TA 数据：能量产生率密度 ρ_UH-UHECR ≈ (0.1–15)×10⁴² erg Mpc⁻³ yr⁻¹（Auger）、(1.4–5.6)×10⁴³ erg Mpc⁻³ yr⁻¹（TA），与 NS-NS/NS-BH 事件预言一致。

[INTERPRETATION] §4.2 把 r-process（见库内 03 域核合成文献）与 UHECR 超重新核直接挂钩，是"核合成→宇宙线成分"跨域连接的实例（呼应 background/02_nucleosynthesis §2.5 r-process）。

[CRITIQUE] UH-UHECR 拟合给出的 Auger 与 TA 能量密度相差约一个数量级（10⁴² vs 10⁴³），作者仅说"与并合事件预言一致"而未深挖该分歧，弱化了数据间张力。

## 4.3 Tidal disruption events

> **潮汐瓦解事件（原文逐字标题）**
> **中文翻译**：SMBH 瓦解恒星产生相对论喷流，加速 UHECR。

[FACT] TDE 是恒星被中央 SMBH 瓦解的剧烈过程[66]；TDE 被提议为 UHECR 源[34-36,67-69]。部分 TDE 具相对论喷流（如 Sw J1644、Sw J2058、Sw J1112、AT 2022cmc）；UHECR 可在 TDE 喷流的内/外反向-前向激波中加速[36]。

[FACT] Ref.[68] 显示对偏轴 (off-axis) 喷流考虑侧向逃逸效应，最大加速能在光学发现后数百天达到。喷流 TDE（如偏轴 AT2018hyz）的能量输出与 UHECR 所需能量注入率相当。

[FACT] UHECR 成分与瓦解恒星相关：瓦解主序星不足以解释观测；Ref.[36] 考虑 IMBH 瓦解白矮星 (WD)——常见 CO-WD 拟合谱差但可解释成分，ONeMg-WD 更匹配 Auger 谱与成分（初始质量成分 O=0.12、Ne=0.76、Mg=0.12），但 ONeMg-WD 比 CO-WD 稀有约 1/30。内激波/prompt 区加速的 CR 核无法存活（不同于 LL-TDE）[36]。

[INTERPRETATION] TDE 成分的"星种类依赖"是独特点：源成分由被瓦解恒星的化学组成决定，使 TDE 成为可直接检验成分-源对应的天然实验室。

[CRITIQUE] ONeMg-WD 匹配最佳但稀有度 1/30 使事件率严重不足，作者未量化"稀有度×匹配度"后的总能量预算是否满足 §3.1 的 ρ_inj 约束，留下未闭合的账。

## 4.4 Active galactic nuclei

> **活动星系核（原文逐字标题）**
> **中文翻译**：射电星系大尺度喷流与瓣中的剪切加速是主流候选机制。

[FACT] AGN（射电亮/喷流 AGN）有多个高效电子与离子加速位点：黑洞附近（数 r_g）、内喷流、千秒差距尺度喷流、喷流瓣[70]。

[FACT] Blazar（AGN 子类）是强高能源，CR 核可加速至 UHE[29,71]；BL Lac 中 UHECR 核高效加速，但 FSRQ 中因喷流附近强辐射场核易瓦解[29]。FSRQ 也是 UHE 中微子优源；Blazar 中高能中微子受 Auger 等约束（尤其乐观模型 Γ=2.3），但高度依赖谱指数[71]。

[FACT] 射电星系近年受重点关注。千秒差距喷流/瓣的加速经数值模拟细化；相对论喷流中"单发加速 (one-shot)"可使 CR 在一次相互作用中获 γ² 能量增益（若初末飞行方向夹角 > π/2）[72]。

[FACT] 剪切加速 (shear acceleration) 被提议为喷流-茧系统中加速 UHECR 的可行替代机制，是 Fermi 加速的一类，CR 呈幂律谱；逃逸谱硬，dN/dE ∝ E^(-q)，q = 0–1。

[FACT] 射电星系瓣回流（backflow）的磁流管中流体力学流动（§2.2 内嵌编号 2.2）提供加速 UHECR 的环境[73]：一阶 Fermi（激波驱动）与二阶 Fermi（强湍流）叠加；单磁流管内激波可达 Hillas 能量极限 E_max ∼ ZeβBW（B 磁场、W 流管宽度）。

[FACT] 低能银心 CR 可在射电星系大尺度喷流中进一步加速至 UHE[47,48]；Ref.[47] 考虑 TeV 低能 CR 注入 + 离散剪切加速，假设中/重核分数增强因子 ~3，但若在同刚性注入则难以同时拟合谱与成分[47]。

[INTERPRETATION] §4.4 是本文机制重点：将 AGN 从"笼统源"细化到"千秒差距喷流/瓣的剪切加速 + 单发加速"具体位点，并强调低能 CR 再加速（re-acceleration）解释重核增强——这是区别于传统 DSA（见 `bell-1978`/`blandford-ostriker-1978`）的新机制路线。

[CRITIQUE] 剪切加速逃逸谱 q=0–1（极硬）若成立，则源端谱本身很硬，需与传播能损叠加后才能与观测 ~1.5–2 的观测谱比较；作者未给传播卷积后的净谱预测，机制可观测性论证不完整。

## 4.5 关键定量公式（四类候选源）

> **补充：§4 各源定量关系（[FACT]，原文给出或领域标准）**

### 4.5.1 GRB / 大质量恒星死亡

[FACT] **HL-GRB 各向同性光度**[57]：

$$L_{\rm iso}\sim 10^{51}\text{–}10^{53}\ {\rm erg\ s^{-1}}$$

[FACT] **GRB 与弥漫中微子流上限**[59]：全宇宙 GRB 暴发中微子发射

$$f_{\nu,{\rm GRB}} \lesssim 1\%\ f_{\nu,{\rm diffuse}}$$

[FACT] **Jet-B 模型 UHECR 核质量分数**（完全存活区）[23]：

$${\rm O}=0.511,\quad {\rm Si}=0.364,\quad {\rm S}=0.108$$

### 4.5.2 致密双星并合（UH-UHECR）

[FACT] **UH-UHECR 能量产生率密度**[26]（Auger / TA 联合拟合）：

$$\rho_{\rm UH} \approx (0.1\text{–}15)\times10^{42}\ {\rm erg\ Mpc^{-3}\ yr^{-1}}\ ({\rm Auger}),\quad (1.4\text{–}5.6)\times10^{43}\ {\rm erg\ Mpc^{-3}\ yr^{-1}}\ ({\rm TA})$$

[FACT] **r-process 第三峰物质位**：存在于并合动力学抛射物（赤道面），合成 UH 核（Z 大）。

### 4.5.3 潮汐瓦解事件（TDE）

[FACT] **ONeMg-WD 初始质量成分**（最佳匹配 Auger 谱/成分）[36]：

$${\rm O}=0.12,\quad {\rm Ne}=0.76,\quad {\rm Mg}=0.12$$

[FACT] **稀有度**：ONeMg-WD 比 CO-WD 约稀有

$$N_{\rm ONeMg}/N_{\rm CO}\sim 1/30$$

[FACT] **最大加速时刻**：偏轴喷流考虑侧向逃逸，最大能量在光学发现后数百天达到[68]。

### 4.5.4 活动星系核（AGN）

[FACT] **单发加速（one-shot）能量增益**[72]：若初末飞行方向夹角 > π/2，

$$\Delta E/E \sim \gamma^2$$

[FACT] **剪切加速逃逸谱**（离散剪切 = Fermi 一类）[47]：

$$\frac{dN}{dE}\propto E^{-q},\qquad q=0\text{–}1$$

[FACT] **磁流管激波 Hillas 极限**[73]：

$$E_{\max}\sim Z e\,\beta\, B\, W$$

（β 流管流速，W 流管宽度；一阶+二阶 Fermi 叠加）

[FACT] **低能 CR 再加速重核增强因子**[47]：

$$f_{\rm enh}\sim 3$$

[INTERPRETATION] §4.5 把四类源的"可量化身份"集中呈现：GRB 用光度+中微子上限、并合用 UH 能量密度、TDE 用恒星化学组成、AGN 用加速机制谱指数——这些量是未来多信使观测可逐一检验的旋钮。
