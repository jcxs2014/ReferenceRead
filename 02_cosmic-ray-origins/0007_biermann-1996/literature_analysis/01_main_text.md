# 1. Introduction

## 1.1 核心内容
- **[FACT]** 宇宙线起源问题尚未最终解决；文献引用 [41, 47, 29, 30, 36, 40, 6]。
- **[FACT]** Cocconi (1956, [23]) 论证极高能宇宙线必须起源于银河盘外，因为其 Larmor 回旋无法被束缚（**Cocconi 论证**）。
- **[FACT]** 中等能量宇宙线的起源已形成共识：产生于超新星激波 [4, 74, 34, 35, 48, 24, 16, 5, 44, 37, 38]，无论进入星际介质还是恒星风 [80, 75, 8]。
- **[FACT]** 最高能宇宙线的起源仍有争议；Hillas (1984, [42])、Berezinsky et al. (1990, [6])、Gaisser (1990, [31]) 作了优秀综述。
- **[FACT]** 本文采用超新星激波起源的图像，专注讨论银河系中宇宙线的相互作用。

## 1.2 论文动机与研究问题
- **[FACT]** 需要"把银河系当作宇宙线与热物质相互作用的工具"，首先得理解宇宙线起源（定量理论）。
- **[FACT]** 相互作用可观测后果：$\gamma$ 射线线谱与连续谱、某些元素和同位素的丰度（综述：Reeves [69], Bloemen [18]）。
- **[FACT]** 最近 Boron 同位素比的测量 [28]（Federman, Lambert, Cardelli, Sheffer, 1996 Nature 381, 764–766）。
- **[FACT]** Orion 复合体的 $\gamma$ 射线线探测 [17]（Bloemen et al. 1994, A&A Letters 281, L5–L8）——由核碰撞激发后释放，早在 Meneguzzi & Reeves [50] 与 Ramaty et al. [59] 就已预言。

## 1.3 本文目标
- **[FACT]** 论证：定量宇宙线起源理论已经给出，值得获取更多相互作用的更优截面，使这些相互作用在未来成为**定量工具**。
- **[INTERPRETATION]** 论文本质上是"呼吁改进核碎裂截面"的物理动机说明——把实验核物理的截面测量与天体物理的丰度解释挂钩。

# 2. A quantitative proposal for the origin of galactic cosmic rays

## 2.1 原文要点

- **[FACT]** 宇宙线到达地球能量范围：**几百 MeV/particle 到 $3\times10^{20}$ eV**。
- **[FACT]** 质子谱在 GeV 能段接近 **E^−2.75**；He 及更重元素接近 **E^−2.65**，在 **膝 (knee) ≈ $5\times10^{15}$ eV** 处向下弯曲到约 **E^−3.1**，又在 **踝 (ankle) ≈ $3\times10^{18}$ eV** 处再次变平（引用 [49, 51, 89]）。
- **[FACT]** 化学组成大致类似于星际介质，但**相对 Si 而言，H 和 He 被压低**；与太阳高能粒子 (SEP) 一样有低第一电离势元素 (FIP) 的**增强**。
- **[FACT]** 低能端截止由太阳风相互作用造成；星际空间实际谱延伸得比地球可测能量更低。

## 2.2 三源模型的起源

- **[FACT]** 新理论（始于 [8] Biermann 1993, A&A 271, 649–661）追溯 **< $3\times10^{18}$ eV** 宇宙线到超新星激波，进入 ISM 或前身星风。
- **[FACT]** 新颖元素：**激波区粒子输运的前提**，受超新星遗迹的射电偏振、射电特征运动、X 射线和射电壳层尺寸 [13] 启发。
- **[FACT]** 这些观测数据暗示**强烈湍流的相互作用区**（而非光滑激波），与 Biermann 激波不稳定性的论证 [87, 67] 一致。

## 2.3 "最小主导尺度原理" (Principle of the Smallest Dominant Scale)

- **[FACT]** 基于 Prandtl (1925, [57]) 和 von Kármán & Howarth (1938, [45]) 的工作。
- **[FACT]** 用于确定湍流输运的**长度尺度**和**速度尺度**：
  - 长度尺度：球形激波半径的某个分数 (some fraction of the radius)
  - 速度尺度：激波两侧速度差 (velocity difference across the shock)
  - 关联快对流激波湍流 (fast convective shock turbulence)
- **[FACT]** 由此构造**输运系数 (transport coefficient)**，决定粒子在激波两侧停留的时间，进而决定：
  - 绝热损失 (adiabatic losses)
  - 在移动激波参考系中电场漂移的能量增益
  - 最终粒子谱

## 2.4 对传统平面激波结果的修正

- **[FACT]** 该模型在超新星激波膨胀期间导致**可观的能量损失**，预测的谱比平面平行激波情形**更陡**。
- **[FACT]** 三个预测 i) 膝上下两侧谱；ii) 膝和各个截止的粒子能量；iii) 化学组成。
- **[FACT]** 已在多篇 [7, 8, 58, 78] 中接受检验，最新概述见 [10, 13, 14]。

## 2.5 核的预测 (2.1 Summary of the predictions for nuclei)

- **[FACT]** 三源命名：
  1. **ISM-SN**：超新星入星际介质
  2. **wind-SN**：超新星入前身星恒星风
  3. **射电星系热点**
- **[FACT]** wind-SN 在所有能量到 **$3\times10^{9}$ GeV** 均有重要贡献。

**谱指数 (spectral indices)**：
| 源 | 膝下谱 | 膝上谱 |
|---|---|---|
| ISM-SN | E^(−2.75 ± 0.04) | — |
| wind-SN | E^(−2.67^(+0.02)^(−0.02)) | E^(−3.07^(+0.07)^(−0.07)) |
| 射电星系热点 | E^−2.0 (注入时) | — |
| wind-SN 极冠 | E^−2.33 (允许银河系泄漏) | — |

- **[FACT]** 这些谱指数**对核 (nuclei)** 是**修正了银河系泄漏**之后的值。
- **[FACT]** ISM-SN 的化学丰度接近正常；wind-SN 的贡献**强烈富集 (strongly enriched)**。
- **[FACT]** 在膝处谱在给定**刚度** (rigidity) 向下弯曲，因此更重元素在更高每粒子能量处弯曲。
- **[FACT]** 膝之外，**中等核质量元素** (medium nuclear mass) 一直主导到切换到河外分量，后者主要是 H 和 He（对应射电星系 ISM 与河外混合）。
- **[FACT]** 化学组成在膝处的平滑过渡使得膝"不可避免地相当平滑"；刚度 = **p/Z**（动量/电荷），决定 Larmor 半径。

# 3. Injection of cosmic ray nuclei

## 3.1 原文内容
- **[FACT]** 对 He, ..., C, O, ..., Fe 的**注入规律 (injection law)** 写为动量 p 的幂律：
$$N(p) \sim p^{-2.67}\, dp \tag{1}$$
- **[FACT]** 幂律一直延伸到非相对论能量。
- **[FACT]** 以 p = A m_p c $\gamma$ $\beta$，A = 原子质量数，$\gamma$、$\beta$ 为洛伦兹因子与速度（c 单位）。非相对论谱可写为 ~$\beta$^(−2.67) d$\beta$。

## 3.2 电离能量损失 (Formula 2)

- **[FACT]** 与热物质的电子相互作用（自由电子：密度 n_e；束缚在 H 原子核壳层：密度 n_H），能量损失：
$$\frac{d\beta}{dt} \sim n_e, n_H \cdot \beta^2 \cdot Z^2 \tag{2}$$
  其中 Z 为失能高能核的电荷。
- **[FACT]** 该行为仅对**超热能量 (suprathermal)** 和**亚相对论速度**有效 [52]。

## 3.3 低能截止 (Formulae 3–4)

- **[FACT]** 穿越热物质一段时间 $\tau$ 后，出现低能截止，分布为：
  - 截止以下：~$\beta^{2}$ d$\beta$ （式 3）
  - 截止以上：原律
  - 截止速度：$\beta_{\rm crit}$ ∼ {Z$^{2}$ (n_e, n_H) $\tau$}^(1/3) （式 4）
- **[FACT]** 低于截止的粒子相空间上转移到热粒子库，可改变热粒子化学丰度——对 Li、Be、B 等丰度差异大的元素**尤其重要**。
- **[FACT]** **grammage**（扭曲散射路径上的柱密度）是讨论宇宙线相互作用的关键量。
- **[FACT]** 由 grammage 可得 H 的截止能 ~ 100 MeV，更重核相应更高。

# 4. Spallation of cosmic ray nuclei（核碎裂）

> **本节是论文核心**：把核碎裂位点、时间依赖的云捕获、以及观测到的 B/C ~ E^(−0.6) 统一在 Kolmogorov 湍流下。

## 4.0 总述
- **[FACT]** 宇宙线核与热物质碰撞被"打碎"，称为 **spallation**。
- **[FACT]** 逆过程：高能质子与较重热核 (如 C) 碰撞，剩余核被激发后发射 **$\gamma$ 射线线**。
- **[FACT]** 文献引用 [32, 26, 33, 27, 73]。

## 4.1 Sites of spallation — 三种碎裂位点

### 位点 1：分子云壳层 (Molecular cloud shell)
- **[FACT]** 大质量星演化的强质量损失形成壳层，超新星爆炸时激波穿过风区，撞击壳层 [54]。
- **[FACT]** 激波携带的能量粒子在壳层中碎裂。
- **[FACT]** 次 Fe 元素的丰度估计壳层 grammage **~ 1 g/cm$^{2}$** [85, 86]，与射电和毫米观测一致。
- **[FACT]** 这是**奇 Z 元素、次 Fe 元素、以及部分 Li/Be/B 同位素**的主导过程。
- **[FACT]** 此情况下次级谱 N_s 与主核谱 N_p 相同：
$$N_s \sim N_p \tag{5}$$
  即 N_s/N_p = 常数（§4.3 的 regime 1）。

### 位点 2：星际云内 (Diffusive regime)
- **[FACT]** 粒子在云中扩散时产生的次级满足定态方程：
$$\frac{dN_s}{dt} = \frac{N_p}{\tau_s} - \frac{N_s}{\tau_{L,gal}} \tag{6}$$
  $\tau_{\rm s}$ = spallation 时标，$\tau$_{L,gal} = 从银河盘扩散出去的时标。
- **[FACT]** 扩散输运可由**星际湍流的 Kolmogorov 谱**导出 [70, 39]；ISM 湍流 Kolmogorov 律的证据见 [12, 83]。
- **[FACT]** 定态解：
$$N_s = N_p \frac{\tau_{L,gal}}{\tau_s} \tag{7}$$
  相应地次级/主核比：
$$\frac{N_s}{N_p} \sim E^{-1/3} \tag{8}$$
  （为教学简化，忽略了 spallation 自身的能量依赖。）

### 历史争议：B/C ~ E^(−0.6) 与 Kolmogorov 的矛盾
- **[FACT]** B/C 比观测给出 ~ E^(−0.6) [26, 33, 27]，Kolmogorov 预测的 E^(−1/3) 似乎与之不一致。
- **[FACT]** 上述矛盾"只有云相互作用是定态时才成立"；但星际云**有自身时间演化**（形成、消散、由新生星加热）。
- **[FACT]** Biermann 通过**考虑云的形成过程**解决此矛盾——见 §4.2。

## 4.2 The capture of cosmic rays in clouds — 论文原创核心

### 物理图像
- **[FACT]** 星际介质由小碎块和较热部分**形成大分子云**，**引力不稳定性 (gravitational instability)** 是云/云碎块坍缩的关键过程。
- **[FACT]** 引力坍缩要求自由坍缩时标 **短于任何压力信号穿过云的时标** → 坍缩必须快于 **Alfvén 速度** [76]。
- **[FACT]** 作为结果，当引力束缚系统（如分子云）形成时，宇宙线被**捕获 (trapped)**，因为宇宙线**无法比 Alfvén 速度快地流走** [82]。
- **[FACT]** 捕获的宇宙线可通过**扩散**离开云；扩散近似有效的前提：**磁不规则性散射的平均自由程 ≪ 云尺寸**——这给出扩散近似的能量上限。

### 云内主核演化 (Formulae 9–11)
设 N_{p,1}(E,t) 为云内主核：
$$\frac{dN_{p,1}}{dt} = -\frac{N_{p,1}}{\tau_{L,cl}} \tag{9}$$
$$\tau_{L,cl} = \tau_{L,cl,0}\left(\frac{E}{E_0}\right)^{-1/3} \tag{10}$$
能量依赖来自"磁性和部分/完全电离介质中**小尺度湍流的 Kolmogorov 谱**"。

解：
$$N_{p,1} = N_{p,1,0}(E) \exp\left(-\frac{t}{\tau_{L,cl}}\right) \tag{11}$$

### 云外但来自云内的粒子 (Formulae 12–13)
$$\frac{dN_{p,2}}{dt} = +\frac{N_{p,1}}{\tau_{L,cl}} \tag{12}$$
$$N_{p,2} = N_{p,1,0}(E)\left\{1 - \exp\left(-\frac{t(E/E_0)^{1/3}}{\tau_{L,cl,0}}\right)\right\} \tag{13}$$

### 云内次级核 (Formulae 14–15)
$$\frac{dN_{s,1}}{dt} = \frac{N_{p,1}}{\tau_s} - \frac{N_{s,1}}{\tau_{L,cl}} \tag{14}$$
解：
$$N_{s,1}(E) = N_{p,1,0}(E)\frac{t}{\tau_s}\exp\left(-\frac{t}{\tau_{L,cl}}\right) \tag{15}$$

### 云外次级核 (Formulae 16–18)
$$\frac{dN_{s,2}}{dt} = +\frac{N_{s,1}}{\tau_{L,cl}} \tag{16}$$
解：
$$N_{s,2}(E) = N_{p,1,0}(E)\frac{\tau_s}{\tau_{L,cl}}\int_0^{x} x' e^{-x'}\,dx' \tag{17}$$
其中 x = t/$\tau$_{L,cl}。长时间极限下：
$$N_{s,2}(E) = N_{p,1,0}(E)\frac{\tau_s}{\tau_{L,cl,0}}\left(\frac{E}{E_0}\right)^{-1/3} \tag{18}$$

- **[FACT]** 因此**被注入到原始云外星际介质的次级**的谱，比主核**陡 1/3**。
- **[FACT]** 主核近 E^(−8/3) → 次级注入谱近 **E^−3**。

### 银河系泄漏下的平衡 (Formulae 19–23)
$$\frac{dN_{s,2}}{dt} = +\frac{N_{s,1}}{\tau_{L,cl}} - \frac{N_{s,2}}{\tau_{L,gal}} \tag{19}$$
解：
$$N_{s,2} = N_{p,1,0}(E)\frac{\tau_s}{\tau_{L,cl}}\exp\left(-\frac{t}{\tau_{L,gal}}\right)\left(1 - \frac{\tau_{L,cl}}{\tau_{L,gal}}\right)^{-2}\int_0^{x} x' e^{-x'}\,dx' \tag{20}$$
其中：
$$x = t\left(\frac{1}{\tau_{L,cl}} - \frac{1}{\tau_{L,gal}}\right) \tag{21}$$
- **[FACT]** 假设 $\tau$_{L,cl} < $\tau$_{L,gal}，积分收敛（反方向亦然）。
- **[FACT]** 对所有过去注入时间积分并对多源求和得到 N*_{s,2}：
$$N^*_{s,2} = N_{p,1,0}(E)\frac{\tau_s}{\tau_{L,cl}(E)\,\tau_{L,gal}(E)}\left(1 - \frac{\tau_{L,cl}}{\tau_{L,gal}}\right)^{-2}I(t) \tag{22}$$
$$I(t) = \int_0^{x''} e^{-x'}\,dx' \Bigg/ \int_0^{x} s e^{-s}\,ds \tag{23}$$
$$x'' = t/\tau_{L,gal},\qquad x = x'\,\tau_{L,gal}\left(\frac{1}{\tau_{L,cl}} - \frac{1}{\tau_{L,gal}}\right) \tag{24}$$

### 关键结果 (Formula 25)
- **[FACT]** x/x' 的能量依赖**不存在**（云内扩散和银河泄漏同 E^(-1/3) 依赖）。
- **[FACT]** I(t) 可解析积分，在 x'' ≫ 1 时趋于常数。
- **[FACT]** 次级/主核的能量依赖：
$$\frac{N_{s,2}}{N_{p,1}} \sim E^{-2/3} \tag{25}$$
  在星际与云内湍流均用 Kolmogorov 谱的建模下。
- **[FACT]** 与 Engelmann et al. [27] 观测一致。
- **[FACT]** 这与"定态漏盒 (stationary leaky box) 给出 ~ E^(-1/3)"的经典结论**相反**。

### 与"逃逸长度 vs 逃逸时间"的关系
- **[FACT]** 由于非定态性，**escape length (g/cm$^{2}$)** 与 **escape time** 不能再作为同义词使用。
- **[FACT]** 逃逸时间 $\tau$_{L,gal} ∝ E^(-1/3)（相对论区）。
- **[FACT]** 逃逸长度有三个不同 regime；在 **GeV/nucleon** 能段相关的是约 E^(−0.6)，在本简化模型中 ~ E^(−2/3)。

## 4.3 Energy dependence of secondary/primary ratio（三种 regime 汇总）

- **[FACT]** 对 He 及以上核，注入谱 E^(−7/3)，Kolmogorov 湍流 → 扩散时间 E^(−1/3)。
- **[FACT]** 次级/主核比三个简单能段：

**Regime 1（分子云壳层碎裂）：**
$$N_s/N_p \sim \text{const.} \tag{26}$$

**Regime 2（云捕获、扩散主导）：**
$$N_s/N_p \sim E^{-2/3} \tag{27}$$

**Regime 3（非扩散高能区，经典解）：**
$$N_s/N_p \sim E^{-1/3} \tag{28}$$

- **[FACT]** 数据仅显示 regime 1 和 2；regime 3 **从未成为主导贡献者**。
- **[FACT]** regime 1→2 的切换在 **~ 20 GeV/nucleon** 附近。
- **[FACT]** 逃逸时间在**整个相对论能区都对应 E^(−1/3)**。

## 4.4 作者逻辑
1. 传统"定态漏盒"框架下，Kolmogorov 湍流给出的 E^(−1/3) 与 B/C ~ E^(−0.6) 矛盾。
2. 矛盾的前提是"云相互作用是定态的"。
3. 引入**引力不稳定性导致云形成 → 宇宙线被捕获**的物理图像。
4. 云捕获是**时间依赖的非定态过程**，次级/主核比变为 E^(−2/3)。
5. 这与观测一致，**恢复了 Kolmogorov 湍流的普适性**。

## 4.5 我的理解 (INTERPRETATION)
- 该推导的关键不是改变湍流谱，而是**放弃定态假设**——星际云的生命周期使得次级核有"时间滞后"地离开云并累积在云外。
- 逃逸时间 $\tau$_{L,gal} ~ E^(−1/3) 依然成立；但"逃逸长度"不再是逃逸时间的简单映射，因为次级在云外的**生成**和**泄漏**叠加。
- **[INTERPRETATION]** Biermann 的方法本质是"源函数 + 时变响应"的卷积；这与传统 leaky box 的"稳态率方程"在数学上是两种范式。

## 4.6 潜在问题与值得关注的地方 (CRITIQUE)
- **[CRITIQUE]** 式 (25) E^(−2/3) 的系数 I(t) 依赖云的寿命分布，文献未给出具体的云寿命统计。
- **[CRITIQUE]** 云形成"引力坍缩快于 Alfvén 速度"是一个**理想化的启动条件**，未讨论磁支撑、恒星反馈、云合并等其他物理。
- **[CRITIQUE]** 忽略 spallation 截面自身的能量依赖（文中承认"为教学简化"），这在高能段会引入额外修正。
- **[CRITIQUE]** $\tau$_{L,cl,0}、$\tau$_{L,gal,0} 的绝对值未定；文中所有结论都是**能量依赖的幂律形状**，不涉及绝对丰度拟合。
- **[CRITIQUE]** 式 (15) 长时间近似下 N_{s,1} ∝ t·exp(−t/$\tau$_{L,cl}) 意味着云内次级先累积再泄漏，但作者未讨论在 t ≪ $\tau$_{L,cl} 时的观测后果。

# 5. Chemical abundances

## 5.1 元素与同位素的三源（文献综述，引用 [68, 69]）
- **[FACT]** **大爆炸核合成**：H, $^{4}{\rm He}$, $^{2}{\rm H}$, $^{3}{\rm He}$, $^{7}{\rm Li}$。Deuterium 在类星体吸收线曾引起兴奋，现与邻近星系首次测量 [22] 一致。
- **[FACT]** **恒星内部与包层**：提供大多数重元素，通过超新星抛射入星际空间；氘等同位素在恒星内部被摧毁。
- **[FACT]** **宇宙线与热物质相互作用**：
  - 星际介质与宇宙线中偶 Z-奇 Z 分布不同：spallation 使宇宙线中**奇 Z 元素丰度升高**
  - 次 Fe 元素来自 spallation
  - **Li、Be、B 的大多同位素**均由宇宙线相互作用在 ISM 和宇宙线中提供

## 5.2 一个关键检验 (Formula 52, 53 引用)
- **[FACT]** 低能质子的**电离损失**效应：既在分子云中提供电离与加热源，同时也是对整个概念的**重要检验**。
- **[FACT]** 质子谱中的电离损失截止，与解释 Li、Be、B 在 ISM 中丰度所要求的碎裂产物谱截止**一致**——**"This is the case."**
- **[INTERPRETATION]** 这是把"宇宙线输运—碎裂—丰度"三个环节统一起来的关键自洽性检查。

## 5.3 尚未完成的工作
- **[FACT]** 仍需大量工作验证详细概念，包括：化学丰度的细节、放射性同位素丰度、精确同位素比。
- **[FACT]** 这将对该理论（及任何其他理论）提供严格检验，可能证伪它。
