# 3. Origin of Bulk of the Cosmic Rays: General Considerations (§3, p. 10–16)

## 3.1 本节核心内容

- **能量学论证**：银河系 CR 总光度 L_CR ~ 1.5×10⁴¹ erg/s，约等于银河系超新星总动能输出的 10%，支持 SNR 是膝点以下主要源。
- **银河系 vs 河外起源**：多重证据（SMC γ 射线、各向异性、电子成分）支持至少膝点以下 CR 为银河系起源。
- **加速机制**：两种主要机制——(1) 直接电场加速；(2) 统计 (Fermi) 加速；DSAM (Diffusive Shock Acceleration Mechanism) 是主流。
- **Hillas 限制**：对给定源，最大加速能量受源尺寸或加速时间限制。

## 3.2 §3.1 Energetics

### 3.2.1 银河 CR 能量密度 [FACT]

- CR 能量密度主要集中于 1–10 GeV 能量区间。
- E ≲ 1 GeV 与太阳活动正相关 → 太阳起源。
- E > 1 GeV 与太阳活动**反相关** → 太阳系外起源（屏蔽效率随太阳风增强）。

### 3.2.2 关键公式

**公式 (3) — 银河 CR 穿越星际气体的平均柱密度 [FACT]**
```
X(E) = ρ_g · t_CR(E) ≃ 6.9 · (E / 20Z GeV)^(-0.6)  g cm⁻²
```
- ρ_g：星际气体平均密度
- Z：CR 平均电荷数
- 数据来源：Galactic CR 次级/初级丰度比 [114]

**银河系总 CR 光度** [FACT]
```
L_CR = (4π/c) · ∫dE ∫dV · t_CR(E)⁻¹ · E · j(E)
```

### 3.2.3 数值 [FACT]

| 量 | 值 |
|---|---|
| u_CR (CR 能量密度) | ~1 eV cm⁻³ |
| M_g (银河气体总质量) | ~4.8×10⁹ M⊙ |
| L_CR (CR 总光度) | ~1.5×10⁴¹ erg s⁻¹ |
| L_CR / L_SN (占超新星动能比) | ~10% |

[FACT] 结论：从能量学看，超新星可解释膝点以下 CR 的大部分能量。

### 3.2.4 能量密度等价关系 [FACT]

```
u_CR ~ B²/8π ~ (1/2)·ρ_g·v_t²  (Eq. 5)
```
- B ~ 10⁻⁶ G（银河磁场）
- v_t：气体湍流速度
- 物理解释：相对论性 CR、磁场与气体流动之间的压力平衡
- [INTERPRETATION] 若此关系在河外空间也成立 → 河外 CR 能量密度会明显小于银河系 → 进一步支持银河起源

## 3.3 §3.2 Galactic versus Extragalactic Origin

### 3.3.1 三大支持银河起源的证据 [FACT]

1. **能量学**（§3.1）：L_CR ~ 10% L_SN。
2. **SMC γ 射线上界** [FACT]：
   - CR 与气体相互作用产生 π⁰ 衰变 γ 射线 [118]。
   - SMC 观测上界比"宇宙 CR 密度均匀"假设下的预言低一个量级 [119]。
   - → SMC 处 CR 密度比本地银河低至少几倍 → CR 不是宇宙均匀的。
3. **银河系 CR 梯度**：若银河起源，CR 强度应随银心距离下降 → 反映在次级 γ 射线中 [120–122]。观测结果尚不完全确定 [123]。
4. **各向异性**：
   - <10¹⁴ eV：各向异性 ~10⁻³，统计显著，基本能量无关 → Compton-Getting 效应 [126]。
   - >10¹⁸ eV：无显著与银道面相关的各向异性 → **暗示高能端河外起源**。
5. **电子成分**：>~10¹¹ eV 电子因同步辐射/IC 损失，射程 < t_CR → 无可置疑的银河起源（占强子流的 ~1%）。

### 3.3.2 Leaky Box 模型 [FACT]

- 简化的扩散模型，用 CR 保留时间 t_CR 代替扩散项。
- 拟合得到：t_CR ~ 10⁷ yr（E < 10¹⁶ eV），能量依赖弱。
- 膝点解释：磁去约束效应（磁约束减弱 → 逃逸加速 → 谱变陡）；或最大加速能量 ∝ Z（电荷）→ 谱变陡。
- 另有解释：膝点可能由**单一强源**贡献 [127]。

## 3.4 §3.3 Acceleration Mechanisms

### 3.4.1 两种机制

**(1) 直接加速**（电场）：
- 如旋转磁中子星（脉冲星）、吸积盘磁场。
- 缺点：难以自然产生幂律谱；细节争议多。
- [FACT] Colgate [128] 反驳：幂律谱不必然来自 Fermi 加速，只要"少数粒子的能量份额增加"配合"剩余粒子数份额显著减少"即可。

**(2) 统计 (Fermi) 加速**：
- **二阶 Fermi** (1949)：CR 与随机运动磁云碰撞 → 平均能量增益 ∝ (u/c)²
  - 效率低；加速时间 ≫ 逃逸时间 (~10⁷ yr)；
  - 谱指数依赖云速度 → 多源叠加不再幂律。
- **一阶 Fermi（DSAM, Diffusive Shock Acceleration Mechanism）** [FACT]：
  - 粒子与激波面前后多次穿越。
  - 每次穿越的平均能量增益 ∝ u（激波相对速度的一阶项）。
  - **DSAM 的关键特征**：谱指数只依赖**激波压缩比**，与激波速度无关。
  - 已被太阳系 bow shock 原位观测强力支持 [130–132]。
  - 加速位点处粒子存在最大能量 E_max，受：
    - 源尺寸限制（源 > 粒子回旋半径），或
    - 时间限制（加速时间 < 激波寿命 < 最短能量损失时间）。

### 3.4.2 SNR 加速的旁证 [FACT]

- B/C 比例在恒星大气中随金属丰度不变 → C, N, O 的 CR 必须通过散裂在 SNR 中产生 [133]。
- SNR 中观测到的 X 射线同步辐射，电子能量 ~100 TeV → 支持 SNR 加速 [138]。
- SNR 质子与周围物质作用产生 π⁰ → 次级 γ 射线（预言 [139–144]）。但观测上尚无确凿探测 [145,146]。
- **SNR 情形不能解释 UHECR** [FACT]，UHECR 应作为独立成分存在。

### 3.4.3 替代模型综述 [FACT]

| 模型 | 主张 | 备注 |
|---|---|---|
| Biermann [16] | 全部来自一阶 Fermi：SNR（ISM，10¹⁵ eV）、SNR（恒星风，10¹⁷ eV）、射电星系热斑（最高） | 声称通过所有观测检验 |
| Colgate [128] | 扭曲磁场的重联加速，可作用到最高能 | 谱指数不确定 |
| Plaga [148] | 全部宇宙线河外起源，银河"磁通陷阱"积累 | 称 SMC γ 射线不是合适的检验 |
| Dar et al. [149] | 全部银河系起源，"微类星体"（microblazars） | 同源可产生河外 GRB |
| 真空涨落加速 [150–152] | 极推测 | 预言 E⁻¹ 硬谱 → 高能端通量过度预言 [FACT, Eq. 6] |

### 3.4.4 公式 (6) — 真空涨落加速率 [FACT]

```
Ω ≡ dE/dt ≃ (3/5π) · Γ² · ω₀⁵ / m_N ≲ 10¹³ eV s⁻¹
Γ = 2e²/3m_N（辐射阻尼常数）
ω₀ 小于夸克 Compton 频率
```

## 3.5 [INTERPRETATION] 作者逻辑

本章是**背景铺垫**：为 §5（加速起源）和 §6（衰变起源）做一般性准备。作者的意图是：
- 明确膝点以下 CR 起源已基本解决（SNR + DSAM）；
- 但 UHECR（>~10¹⁷ eV）是完全未解决的独立问题；
- 因此 §5 讨论加速路径（bottom-up），§6 讨论衰变路径（top-down）。

## 3.6 [CRITIQUE] 值得注意的问题

- [CRITIQUE] 1999 年后，**Auger 数据**（2017 起）显示 UHECR 谱在 ~5×10¹⁹ eV 处有明显陡化（与 GZK 一致），且 E > 5.7×10¹⁹ eV 事件的到达方向与**近邻星团（尤其是 Centaurus A）**有显著相关。这些发展部分支持了 §5.2.1 中的射电星系/AGN 类 Bottom-up 模型。
- [CRITIQUE] Top-down 场景（§6–7）对观测约束越来越严格（IceCube 未发现对应中微子，Fermi-LAT 对 diffuse γ-ray 有更强限制）。这是 1999 年时尚未预见的发展。
