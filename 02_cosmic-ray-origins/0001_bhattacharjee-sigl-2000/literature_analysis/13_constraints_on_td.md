# 13. Observational Constraints on the Top-Down Scenario (§7, p. 83–92)

## 13.1 本节核心内容

- Top-down 场景的独特挑战：**能量注入贯穿整个宇宙史**（从 GUT 相变时代到现时代），而不仅是近宇宙学时代。
- 四道核心约束：
  1. **低能弥漫 $\gamma$-ray 背景** (§7.1) — 级联再循环。
  2. **原初核合成 / 光致分解** (§7.2) — 4He 稳定性。
  3. **CMB 谱畸变** (§7.3) — $\mu$ 与 y 型畸变。
  4. **弥漫中微子通量** (§7.4) — 河外 UHE $\nu$ 探测。
- **关键发现**：p < 1 场景（最简单 SCS 模型）被完全排除；p = 1 场景受 m_X 和幂律指数 q 限制；p = 2 场景（MSRP）几乎不受约束。

## 13.2 §7.1 低能弥漫 $\gamma$-ray 背景

### 13.2.1 饱和级联谱 (公式 98) [FACT]

假设仅 CMB 为级联背景：
```
j_$\gamma^{\rm cas}$(E) ≃ $\omega_{\rm cas}$ / [E$^{2}$ x (2 + ln(E_c/E_x))] × {
  (E/E_x)^(−1.5)     E < E_x
  (E/E_x)^(−2)       E_x < E < E_c
  0                   E > E_c
}
```

**红移依赖特征能量**（公式 99）：
```
E_c ≃ m_e$^{2}$ / (2·2 T_CMB) ≃ $4.9\times10^{4}$ GeV / (1+z)
E_x ≃ 0.04 E_c ≃ $2\times10^{3}$ GeV / (1+z)
```
- T_CMB ≃ 2.735(1+z) K。
- E_c ~ 100 TeV 处**谱变陡至 E^(−5)**（光子-光子散射主导 [189]），但仅在 z > ~100 时重要 → **对可行 TD 场景无关**（大多数级联通量产生于更低红shift）。

### 13.2.2 IR/O 背景修正 [FACT]

- 近似乘以 exp[−$\tau$(E)]（$\tau$ 为 E 处对 IR/O 背景的配对光学深度）。
- 对 IR/O 背景模型的细节**不敏感** [487]。

### 13.2.3 100 MeV–100 GeV 约束 [FACT]

- **EGRET 观测** [185]：30 MeV – 100 GeV 弥漫 $\gamma$ 谱 ~ E^(−2.1) → **最严约束在最高能端**。
- 约束：总注入并级联到更低的能量密度 $\omega_{\rm cas}$ ≃ $4.5\times10^{-6}$ eV cm$^{-3}$。

### 13.2.4 对 TD 模型的 p 值约束 [FACT, [430, 437]]

| p 值 | 约束 |
|---|---|
| p = 0（最简单 SCS 模型） | **完全排除** [437] |
| p = 1（普通弦、monopole 湮灭） | 幂律指数必须满足： |

**p = 1 时的 q 约束**（公式 101）：
```
q >~ 2 − 3/2 / (3 + $\log_{10}$(m_X/$10^{23}$ eV))
```
- 例：m_X = $10^{16}$ GeV → q >~ 1.7。

### 13.2.5 详细数值计算（含 IR/O + EGMF） [FACT, [206]]

- 基于新 IR 背景估计 [163] + 最强 URB 版本 [175]。
- **无 EGMF**（Fig. 28）：预言 $\gamma$ 通量在 ~100 TeV 被 CMB 上的 PP 耗竭，100 GeV–100 TeV 被 IR/O 上 PP 耗竭并级联到低能。
- **EGMF ~ $10^{-9}$ G**（Fig. 29）：
  - 强同步冷却快速移走低能级联对 → UHE $\gamma$ 通量大幅降低。
  - 但对 m_X >~ $10^{25}$ eV，pair 同步辐射可能 > $10^{20}$ eV → UHE 通量不一定低。
  - EGRET 约束对 EGMF 强弱**不敏感**（只要核子通量与 $\gamma$ 通量量级相当）。

### 13.2.6 UHE 能区预言 [FACT]

- **无 EGMF**：$\gamma$/CR 通量比 @ $10^{19}$ eV ≃ 0.1。
- **EGMF > $10^{-11}$ G**：抑制级联 → $\gamma$ 谱降低。
- **EGMF = $10^{-9}$ G**：$\gamma$/CR ≃ 0.02。
- **探测需求**：E$^{2}$j ~ 0.1 × EHECR 在 $10^{19}$ eV → 需要 $~4\times10^{19}$ cm$^{2}$ s sr 曝光 → **Auger 可达**（可探测中性组分至 ~1% 通量）。

### 13.2.7 河外 vs 银河贡献 [FACT]

- **弥漫 $\gamma$ 中可能大量来自银河 halo** [488]（尤其 ~1 GeV）→ 河外真实贡献可能显著更小 → **约束更严 ~ 2–3×**。
- 河外 $\gamma$ 可能主要来自**未分辨 blazars** [489]（部分争议 [490]，分析仅 ~25% 来自未分辨 blazar [491]）。
- > 10 GeV 可能有额外未解释成分 → **~100 GeV 以上重粒子衰变级联**可拟合 [418]。

### 13.2.8 **Clustered TD 绕过 $\gamma$ 约束** [FACT, [389]]

- 若 TD 或长寿命 X **在星系内聚类**（非均匀分布）→ **无级联** → 绕过弥漫 $\gamma$ 约束。
- 例见 §6.13 MSRP GHXPD 场景。

### 13.2.9 Synchrotron 附加成分 [FACT, [492]]

- **Dubovsky-Tinyakov**：银河磁场中的 cascade 电子同步辐射 → 在 ~$10^{15}$ eV 附近产生额外 $\gamma$ 通量。
- 对 TD 模型：预言接近 **CASA-MIA 上界** [258]。
- **注意**：此成分非 TD 独有信号（任何 >100 TeV 源都产生类似成分）。

### 13.2.10 **$Q_{0}$ 总注入率上限** [FACT]

- 归一化到 EHECR 通量 → $Q_{0}^{\rm EHECR}$ ≲ $10^{-22}$ eV cm$^{-3}$ s$^{-1}$（在 few 因子内）。
- EGRET 对 $\omega_{\rm cas}$ 给出 **$Q_{0}^{\rm EM}$ ≲ $2.2\times10^{-23}$ h(3p−1) eV cm$^{-3}$ s$^{-1}$**。
- 对宇宙弦（若能量主要以 X 发射损失）：$\eta$ ~ m_X ≲ $10^{13}$ GeV [418, 298]。
- **SUSY GUT 中 X 质量 < $10^{16}$ GeV 不受欢迎**（质子衰变约束）[494, 495] — 但若 TD 在 GUT 后相变中形成，则不受质子衰变约束 → m_X < $10^{16}$ GeV 可行。

## 13.3 §7.2 原初核合成约束

### 13.3.1 机制 [FACT, [485]]

- **z > ~$10^{3}$** 时宇宙对级联光子**不透明** [485]。
- 级联光子存活 ~l_E(E) 时间 → 有一定概率**光致分解 $^{4}{\rm He}$**。
- 阈值：E_4He^th = 19.8 MeV → z < $~3\times10^{6}$ 时级联光子可分解 $^{4}{\rm He}$。

### 13.3.2 产生率 [FACT, 公式 102]

```
n_D/3He ≃ (Y/4) n_B ∫ dE l_E(E) 4$\pi$ j_$\gamma^{\rm cas}$(E) $\sigma_{\rm eff}^{\rm D}$/3He(E)
```

### 13.3.3 关键不等式 [FACT]

- 观测光致分解截面立即给出：
```
($^{3}{\rm He}$/D)_photo > ~ 8            (103)
```
- **级联核合成预言 $^{3}{\rm He}$ >> D** → 与观测 ($^{3}{\rm He}$/D)_☉ < ~1.13 [496] 矛盾。
- **$^{4}{\rm He}$ 光致分解不可能成为 D 和 $^{3}{\rm He}$ 的主要来源** [437]：
```
($^{3}{\rm He}$ + D)/H)_photo < ~ $5\times10^{-5}$        (104)
```

### 13.3.4 转化为 TD 约束 [FACT]

- 约束 $3\times10^{6}$ ≳ z ≳ $10^{3}$ 时**最大瞬时 EM 能量释放**。
- Fig. 27 显示允许的 $\omega_{\rm cas}$(z) 上限。
- **结论**：原初核合成对 TD 的约束与 §7.1 $\gamma$ 背景约束**可比但独立** [437]。

## 13.4 §7.3 CMB 谱畸变

### 13.4.1 两个红移区间 [FACT, [497]]

**区间 1：z_th ≃ $3\times10^{6}$ > z > z_$\gamma$ ≃ $10^{5}$**
- 分数能量释放 $\Delta$u/u → **Bose-Einstein 谱**，化学势：
```
$\mu$ ≃ 0.71 $\Delta$u/u
```
- 适用于 Klein-Nishina cascade（GUT 粒子衰变产生的光子谱近似），光子数变化可忽略。

**区间 2：z_$\gamma$ > z > z_rec ≃ $10^{3}$**
- **Sunyaev-Zel'dovich 型畸变**：
```
4y = $\Delta$u/u
```

### 13.4.2 观测限制 [FACT, [499, 500]]

- COBE-FIRAS 给出 $\mu$ 与 y 的上限。
- 转化为**瞬时能量释放**上限 (图 27 虚线)。

### 13.4.3 对 TD 的约束 [FACT]

- 比级联核合成和 $\gamma$ 背景约束**更弱**。
- 但仍足以**排除最简单 SCS 模型**（p = 0）。

## 13.5 §7.4 中微子通量约束

### 13.5.1 TD 中微子通量特征 [FACT]

- X 衰变为夸克+轻子 → 夸克强子化主要为 $\pi$ → **$\nu$ vs EM 能量比 r ≃ 0.3**。
- **$\nu$ 通量计算**：[195] 形状；[394] 绝对通量（cusp evaporation）；[200] 所有场景（含 $\nu$ 级联）；[196] 改进（含 RNB 上 $\nu$ 级联）。
- **重要**：早期计算 [200, 196] 未包含 §7.1–7.3 宇宙学约束。

### 13.5.2 与 AGASA 数据的关联 [FACT]

- **AGASA 数据显示无 GZK cutoff** [82] → 可能支持 MSRP halo 场景。
- 但 AGASA 数据也兼容 p=1 的**均匀河外 TD 场景**。

### 13.5.3 BHS0、BHS1 与 SLBY98 对比 [FACT, Fig. 31]

| 模型 | p | 特点 |
|---|---|---|
| BHS0 | 0 | 已被 §7.1–7.3 排除，也被 UHE $\nu$ 实验排除 |
| BHS1 | 1 | 归一化到 E ≈ $4\times10^{19}$ eV 质子通量 |
| SLBY98 | 1 | 归一化到可见（核子+$\gamma$）总通量 |

- SLBY98 的 UHE $\nu$ (> $10^{20}$ eV) 比 BHS1 **小 ~100×**：
  1. BHS1 归一化到质子；SLBY98 归一化到核子+$\gamma$。
  2. BHS1 f_N 小 ~3×。
  3. BHS1 用旧 fragmentation 函数 (61)（更高能端更多能量）。

### 13.5.4 实验限制 [FACT]

| 实验 | 限制 |
|---|---|
| Frejus [501] | E > $10^{12}$ eV 水平 $\mu$ (能量损失 > 140 MeV/辐射长度) |

### 13.5.5 SLBY98 可探测性 [FACT]

- 1 km$^{3}$ × 2$\pi$ sr 探测器：
  - $\nu_\mu$ > $10^{19}$ eV：**~0.15 yr$^{-1}$**
  - $\nu_{\rm e}$ > $10^{19}$ eV：~0.089 yr$^{-1}$
  - $\nu_\mu$ > 1 PeV：~1.2 yr$^{-1}$
- **$\tau$ 中微子再生** [223] 消除地球遮挡 → 向上通量增加 [221]。

### 13.5.6 探测器灵敏度 [FACT]

| 探测器 | 接受度 A(E) |
|---|---|
| HiRes ($\mu$$\nu$, >$10^{19}$ eV) | ~3 km$^{3}$ × 2$\pi$ sr [84] |
| Auger ground array ($10^{19}$ eV) | ~20 km$^{3}$ sr |
| Auger ground array ($10^{23}$ eV) | ~200 km$^{3}$ sr |

| Goldstone 100 天搜索 | > $10^{19}$ eV 达到 Auger 灵敏度 [109] |

- **探测 TD $\nu$ 通量需要**：A > ~10 km$^{3}$ × 2$\pi$ sr 运行数年。
- **Auger 与 OWL 应能探测典型 TD $\nu$ 通量**。

### 13.5.7 模型无关上限 [FACT, 公式 105]

设 $\nu$/EM 能量比 r 为常数：
- Cascade 效应将大部分 EM 注入能量再循环为 ~10 GeV 峰值光子。
- 要求：**max_E [E$^{2}$ j_$\nu_\mu$(E)] ≃ r · max_E [E$^{2}$ j_$\gamma$(E)]**
- 用 10 GeV $\gamma$ 通量上界 →：
```
R(E) <~ 0.34 r · [A(E)/(1 km$^{3}$ × 2$\pi$ sr)] · (E/$10^{19}$ eV)^(−0.6)  yr$^{-1}$        (105)
```
- 对 r ≲ 20 (E/$10^{19}$ eV)^0.1 与现有 $\nu$ 通量限制一致。
- **TD 不受 Waxman-Bahcall bound 约束**（核子不是 $\gamma$/$\nu$ 的初级产物）。

### 13.5.8 r ≫ 1 情形 [FACT]

- 如 X 只衰变为 $\nu$ [206]（多数模型不自然）。
- 或**镜像 sector (mirror) TD** 辐射 hidden neutrino [507] → 中微子可最大振荡为普通 $\nu$ → 产生可观事件率。
- **探测** → 建立 r 的**实验下限**。

### 13.5.9 瞬态信号 [FACT, [81, 508]]

- AGASA > $4\times10^{19}$ eV 观测到的可能**关联** [81] 暗示 tb ≪ 1 yr 的**爆发源**。
- 脉冲 fluence：~r [A(E)/(1 km$^{3}$ × 2$\pi$ sr)] (E/$10^{19}$ eV)^(−0.6) $\nu$ 在 tb 时间内。
- 若 EGMF ≲ $10^{-15}$ G → GeV–TeV $\gamma$ 通量也有关联脉冲 [508]。

### 13.5.10 MSRP 的中微子特征 [FACT]

- MSRP 场景中 $\nu$ 通量与 UHE photon + nucleon 通量**量级相当**（不是更大）— $\nu$ 通量主导于河外（因 halo 不增强 $\nu$）。
- → **极难探测**，即使下一代实验。

## 13.7 [CRITIQUE] 与 1999 年后对照

- [FACT] **Fermi-LAT (2008+)**：弥漫 $\gamma$ 谱在 10 MeV–100 GeV 显著**高于 EGRET 估计** → TD 约束**更严**。
- [FACT] **Pierre Auger 组成测量** (2010–2020)：EHECR 组成为**核子/重核混合**（非光子主导）→ 对纯 TD 光子主导场景不利，但兼容 §13.2 中"核子占 ~10%"的混合 TD 场景。
- [FACT] **IceCube 弥漫 $\nu$ 通量** (2013+)：PeV $\nu$ 通量在 Auger/TD 预言附近 → 与本文 §13.5.5 估计的 SLBY98 通量量级一致。
- [FACT] **CMB 各向异性 Planck 2018**：$\mu$ 畸变上限 |$\mu$| < $9\times10^{-5}$（比 FIRAS 严 2 倍）→ 进一步约束早期注入。
