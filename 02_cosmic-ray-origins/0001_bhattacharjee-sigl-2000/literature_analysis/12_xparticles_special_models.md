# 12. General Parametrization, MSRP, PBH & Exotic Candidates (§6.9–6.14, p. 76–84)

## 12.1 本节核心内容

- **§6.9** 所有 TD 过程的 X 产率统一参数化（公式 92–93）。
- **§6.10** TD + EHECR 与**重子不对称**（BAU）的潜在联系。
- **§6.11** SUSY GUT 中的 TeV-scale Higgs X 粒子。
- **§6.12** 单极子/vortons **自身**被加速为 EHECR 粒子。
- **§6.13** 亚稳超重 relic 粒子 (MSRP) 衰变 + 银河 halo 聚类（GHXPD 场景）。
- **§6.14** Primordial Black Hole (PBH) 蒸发场景。

## 12.2 §6.9 General Parametrization

### 12.2.1 公式 (92–93) [FACT]

**维度分析**：只要系统中除 Hubble 时间 t 和质量标度 m_X 外无其他内在标度，
```
ṅ_X(t) = κ · m_X^p · t^(−4+p)          (92)
```
或等效地：
```
ṅ_X(t) = (Q₀/m_X) · (t/t₀)^(−4+p)      (93)
```
- Q₀：当代单位体积能量注入率。
- **p 决定了演化时间依赖**，是 TD 过程的关键参数。

### 12.2.2 各 TD 过程的 p 值 [FACT]

| TD 过程 | p |
|---|---|
| 弦环 collapse/自相交 (Sect 6.4.5) | 1 |
| Monopolonium (Sect 6.7) | 1 |
| Necklaces (Sect 6.8) | 1 |
| 衰变 vortons (Sect 6.6) | 2 |
| SCS (Sect 6.5) | < 1 |
| Cusp evaporation (Sect 6.4.3) | 例外 |

### 12.2.3 关键物理含义 [FACT]

- **p = 1**：X 产率 ∝ t⁻³ → 早期注入略快于当代。
- **p = 2**（MSRP / 常数共动注入）：ṅ_X ~ 常数 → 整个宇宙历史均匀注入。
- **p < 1**：早期注入**远大于**当代 → **违反 CMB 畸变 + BBN 4He 光致分解约束** [437] → **已排除**。

## 12.3 §6.10 TD, EHECR 与重子不对称 (BAU)

### 12.3.1 基本思想 [FACT, [419]]

- TD 释放的 X 粒子属于 GUT → **衰变可违反重子数**。
- TD 中 X 的产生是**不可逆过程** → 自动满足 Sakharov 三条件（**出热平衡**条件自然成立）。
- **双重起源假说**：BAU（早期 X 衰变）与 EHECR（现时代 X 衰变）同源。

### 12.3.2 定量要求 [FACT]

- 将当代 X 产率归一化到解释 EHECR → 计算历史累计 baryon asymmetry。
- 每个 X 衰变的重子数违反程度 → 模型依赖。
- 部分参数空间下，预测的 baryon asymmetry 可占观测值的**显著分数**。

### 12.3.3 意义 [FACT]

- 若正确：**"整个宇宙的低能重子含量"可能都源自 TD 中 X 衰变** → EHECR 是"重子生成过程今天仍在进行"的直接证据。
- **检验难度极大**：BAU 在 EHECR 中的体现几乎不可观测（EHECR 中 baryon 不对称的印记极微弱）。
- 需具体 GUT 模型完整计算。

## 12.4 §6.11 SUSY GUT 中 TeV-scale Higgs X 粒子

### 12.4.1 基本设定 [FACT, [418]]

- 一类 SUSY gauge 理论中：Higgs 玻色子质量 m_H ~ TeV（SUSY 软破缺标度），而 gauge 玻色子质量 m_V < 10¹⁶ GeV（GUT 标度）。
- → TD 同时是 **TeV Higgs** 与 **GUT-scale gauge bosons** 的来源。
- **X 粒子** = 超重 gauge bosons → 产生 EHECR。
- **额外效应**：TeV Higgs 衰变在 ~10 GeV 以上河外**弥漫 γ-ray** 背景有贡献 → 可解释部分 EGRET 观测 [185]。

### 12.4.2 意义 [FACT]

- 如果正确，SUSY TD 模型提供了**额外 γ 射线信号** → 可由 GLAST（后来的 Fermi-LAT）检验。
- 部分详细讨论在 §7 中。

## 12.5 §6.12 TD 自身作为 EHECR 粒子

### 12.5.1 §6.12.1 Monopoles 作为 EHECR 粒子 [FACT, [454,455,456,457]]

**Kephart-Weiler 场景**：m_M ~ 10⁹ – 10¹⁰ GeV 的磁单极子，被**银河磁场加速**至 EHE。

**加速机制**：穿越银河磁场区域（R ~ 30 kpc, B ~ 3×10⁻⁶ G, L_c ~ 300 pc）获得的动能：
```
E_K ≃ q_M B L_c √N ≃ 5.7×10²⁰ · (B/3×10⁻⁶ G) · (L_c/300 pc)^(1/2) · (R/30 kpc)^(1/2) eV      (94)
```
- N ~ R/L_c 是相干畴数量；√N 因子反映畴间磁取向随机差异。
- **最小 Dirac 磁荷**：q_M = e/(2α)（α = 1/137）。

**要求**：
- 单极子必须**相对论性** → 产生相对论性空气簇射 → m_M ≲ 10¹⁰ GeV（要求相变标度 <~ 10⁹ GeV）。
- 这类低质量 monopoles 没有 GUT 尺度 monopole 的过丰问题。
- **巧合**：观测 EHECR 通量恰在 Parker 界下 3–4 个量级 [454,455]。

**主要问题**：
- **空气簇射机制**不明：
  - Monopole 有强相互作用 hadronic "cloud" (~Λ_QCD⁻¹ ~ few fm) → 有类似质子的强相互作用截面。
  - 还有 monopole-catalyzed baryon-number violating 反应（~10⁻²⁷ cm²）[459]。
  - **大的非弹性度**对大质量粒子（如 monopole）**难以实现** → 空气簇射中能量传输困难 [401]。
- **到达方向**：应偏向本地银河磁场方向 [462]，但观测 EHECR 各向同性。
- **谱**：Monte Carlo 计算的加速 monopole 谱与观测 UHECR 差异显著 [462]。

**结论**：**当前不太可能，但尚未完全排除** [401]。

**Bound-state 变体** [461]：带电粒子-monopole 束缚态作为 EHECR 初级粒子 → 预言 EAS 有**线谱成分**。

### 12.5.2 §6.12.2 Vortons 作为 EHECR 粒子 [FACT, [446]]

- Vortons 高度带电 → 可在 AGN/radio-galaxy hot spots 加速。
- 模型：m_V ~ Zm, Z ~ 100, m ~ 10⁹ GeV。
- 加速本身无问题。
- 但**与普通物质相互作用未知** → 难以预言空气簇射。
- 部分模型预言 EAS 有**线谱成分** [446, 461]。

## 12.6 §6.13 MSRP (Metastable Superheavy Relic Particles)

### 12.6.1 基本设定 [FACT, [463, 389, 464]]

- Kuzmin-Rubakov [463] & Berezinsky-Kachelriess-Vilenkin [389]：**MSRP** m_X ≥ 10¹² GeV，寿命 ≥ 宇宙年龄。
- **长寿命来源**：
  - **Instanton 效应**（非微扰）[463]。
  - **量子引力 wormhole 效应** [389]。
  - 均通过微小违反"保护对称性"（如全局离散对称性）实现衰变。

### 12.6.2 产生机制 [FACT]

**非热产生**（在暴胀后时代）：
1. **引力产生**：背景度规膨胀对真空涨落的影响 [469]。
2. **Reheating 过程**（inflaton 耦合）[463, 470]：
   - "Incoherent" 产生（∝ 湮灭截面）。
   - **宽参数共振**（preheating）。
   - 一阶相变 bubble wall collision [471]。
- 综述 [413]。
- 另一种：**热产生 + 后续熵增**（如 thermal inflation [474]）。

### 12.6.3 MSRP 作为暗物质 [FACT]

- **Thermal equilibrium 上限**：unitarity 限制自湮灭截面 → 热产生暗物质质量 <~ **500 TeV** [473]。
- MSRP (m ≥ 10¹² GeV) 必须**非热产生**。
- 若 Ω_X h² ~ 1 → MSRP 是 CDM（或重要组分）。

### 12.6.4 GHXPD 场景 (Galactic Halo X-Particle Decay) [FACT, [389, 406]]

**核心洞察**：无论宇宙平均 Ω_X 值如何，**X 粒子与 CDM 在银河 halo 内按相同比例聚类**（都只受引力影响）。

**银河 halo 平均 X 数密度**（公式 96）：
```
n_X^H ≃ 3×10⁻¹³ · (Ω_X/Ω_CDM) · (10¹² GeV/m_X) · (ρ_CDM^H / 0.3 GeV cm⁻³)  cm⁻³
```

**Halo 与河外贡献的比值 f**（公式 97）：
```
f ≡ j_H/j_ex = ζ · (n_X^H/n_X^cos) · (R_H/l_E)
         ≃ 15 ζ · (0.2/Ω_CDM h²) · (R_H/100 kpc) · (100 Mpc/l_E)
```
- ζ = halo 空间分布几何因子（~1）。
- 等温分布：ζ ≃ 6.7 [479]。
- 另一模型：ζ ≃ 2 [480]。

**f ~ 10–100** → **银河 halo 贡献占主导**（除 ν 通量外，ν 不受 halo 增强，l_ν ≫ 100 Mpc）。

### 12.6.5 GHXPD 关键预言 [FACT]

1. **光子主导** UHECR 谱 → **几乎无 GZK 抑制**（R_H ≪ l_γ ~ 10+ Mpc）。
2. **通量**不受 EGRET γ 背景约束（银河 halo 尺度内**无 cascade**）。
3. **强各向异性**（§6.13.2）→ 可检验信号。
4. **观测谱 ≈ 注入谱**（未修改）→ EHECR 谱可直接探测 QCD。

### 12.6.6 寿命-丰度关系 (公式 95) [FACT]

假设均匀分布（未考虑 halo 聚类）：
```
τ_X ≃ 2.8×10²¹ · (Ω_X h²) · (l_E/100 Mpc) · (10¹² GeV/m_X)^(1/2)  yr      (95)
```
- Ω_X h² ~ 1 → τ_X ~ 3×10²¹ yr (m_X = 10¹² GeV, l_E = 100 Mpc)。
- 若要解释 EHECR：**τ_X 不能 ≪ 10¹⁰ yr**（否则全部已衰变）→ 但**τ_X ≫ t₀ 时仍有衰变**。
- τ_X ~ t₀ ~ 10¹⁰ yr → 仅需 Ω_X h² ~ 3×10⁻¹²（m_X = 10¹² GeV）。
- **τ_X 上限** ~ 10²² yr（因 m_X >~ 10¹² GeV）。

### 12.6.7 Instanton 衰变 vs 微扰衰变 [FACT, [463]]

- **Instanton 介导衰变**：典型产生**多体末态**（~10 夸克，能量平坦分布）。
- **微扰衰变**（TD 场景隐含）：~1–2 夸克。
- → 可能留下**可区分特征**（`Ñ` 与 N_q 不同）→ 区分 TD 与 MSRP 场景。

### 12.6.8 §6.13.2 各向异性 [FACT, [475, 406, 476, 477]]

**信号**：太阳**偏离 halo 中心** → EHECR 通量各向异性。
- 预测各向异性幅度：10% – 40%（取决于 halo 模型参数）。
- **最强信号**：银河中心 (GC) vs 反银心 (GA) 通量比。
- **检验困难**：所有主要阵列（AGASA、Fly's Eye、Haverah Park、Yakutsk）均在**北半球**，看不到 GC。需南半球 Auger 探测器。
- 北半球大阵列可看到 GA 方向的**通量凹陷** [406]。

**强信号**：邻近 EG 暗物质团（Andromeda、Virgo）在 halo 增强因子 f 中造成 **"dips"** [389, 406, 475, 476]。

**现状 (1999)**：
- AGASA 数据显示 > ~10²⁰ eV **无明显 GZK cutoff** → 可能支持 GHXPD [82]，但 AGASA 数据也兼容 p=1 的河外 TD 场景（EHECR 由 topological defects 主导）。
- 若 GH 贡献在 E >~ 10¹⁹ eV 主导 → 最新 AGASA 数据已排除 GHXPD [477]。
- 若 GH 贡献仅在 E > ~10²⁰ eV 主导 → 事件数 (~6) 太少，尚不能排除。
- BSW [476] 纳入 SUGAR 数组数据 → 声称 GHXPD 被排除（预测各向异性远大于观测）。
- Berezinsky-Mikhailov [477] 反驳：SUGAR 在 > 10²⁰ eV 可能无事件，纳入数据有偏。
- **此重要问题未解决** → 有待 Auger 南半球阵列解决。
- AGASA 观测到**小尺度聚类** [83] → 可能要求 X 粒子暗物质组分在银河 halo 尺度聚类。

**Z-burst 各向异性**：若 eV 质量中微子 + Z-burst 机制（§5.2.4）→ 各向异性与红移区间大尺度结构相关（非 halo）[207]。

## 12.7 §6.14 Primordial Black Holes (PBH)

### 12.7.1 基本设定 [FACT, [482]]

- **机制**：PBH 蒸发期间产生 UHECR。
- 声明：所需黑洞丰度与观测对**本地黑洞蒸发率**的约束兼容。
- **关键反驳 [483]**：黑洞周围形成**温度 ~QCD 标度的 photosphere** → 高能粒子在 photosphere 中被**再循环**到低能 → **可能不贡献 UHECR**。

### 12.7.2 可观测贡献 [FACT]

- PBH 可能显著贡献**银河内**质子/电子/反物质/γ 射线通量（~100 MeV 能区）[484] → 已用于约束 PBH 数量。
- 对 UHECR 的贡献**高度不确定**。

## 12.9 [CRITIQUE] 与 1999 年后对照

- [FACT] **MSRP (GHXPD) 场景**：Auger 数据显示 **UHECR 各向异性**（~40 Mpc 尺度的聚团与 star-forming galaxies 相关）→ **排除 MSRP halo 主导场景**（后者预言 ~halo 尺度各向异性，且与已知源无关）。
- [FACT] **Auger+IceCube 2018**：E > 4×10¹⁹ eV UHECR 与 AGN/starburst galaxies **显著相关** [Auger Collaboration, PRD 2018] → 支持**河外离散源**，否定 GHXPD 与 MSRP 主导场景。
- [FACT] **Instanton 衰变多重性**（Kuzmin-Rubakov 预言 ~10 夸克末态）：尚未有直接观测验证，但其预言的硬光强子化谱（flat 分布）与 TD 场景的 MLLA 谱可区分。
