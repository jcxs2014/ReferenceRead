# 1. Introduction and Scope of This Review (§1, p. 3–5)

## 1.1 本节核心内容

- EHECR (E ≳ 10²⁰ eV) 已被多个实验探测到 [FACT]，其起源是粒子物理与天体物理的重大难题。
- 作者把 EHECR 起源理论分为两大场景：**Bottom-up**（加速）与 **Top-down**（衰变），并明确本文以 Top-down 为主。
- 简述了 Bottom-up 面临的核心问题：即使加速能量可行，粒子也难从致密源区"逃出"（energy loss）；且本地宇宙 (<100 Mpc) 中缺乏足够强、足够近的源 [FACT]。
- Top-down 场景天然解决能量学问题：超级质量 "X" 粒子衰变产生次级粒子，无需加速机制。

## 1.2 原文核心论述

### 1.2.1 EHECR 的存在

[FACT] 作者在开篇引用多组实验数据：Vela [1]、Akeno/SUGAR [2,6]、Fly's Eye [7]、AGASA [8] 等，指出 **能量超过 10²⁰ eV 的宇宙线已被探测到**。这些观测对传统加速理论构成严重挑战。

### 1.2.2 Bottom-up 与 Top-down 二分法

[FACT] 作者将理论分为两类：

**Bottom-up 加速场景**：带电粒子在天体环境中被加速到目标能量。
- 例子：超新星遗迹激波、AGN、强射电星系、高能中子星表面强电场等。
- 主要困难 [FACT]：
  1. 加速能量学虽可行，但粒子"逃出"源区时能量损失巨大。
  2. GZK 效应（§4.1）把源距离限制在 ≲100 Mpc 内。
  3. 本地宇宙中缺乏足够强的 AGN/射电星系候选源 [FACT]。
- 最有利的候选源：**强射电星系**（refs [15–20]），但所需参数极端。

**Top-down 衰变场景**：EHECR 来自早期宇宙产生的超重粒子（质量 m_X ≫ 10²⁰ eV）的衰变。
- 源可以是**拓扑缺陷**（宇宙弦、磁单极子），产生于 GUT 相变；也可以是**超重亚稳态粒子**（寿命 ≥ 宇宙年龄），产生于暴胀过程。
- 若 X 粒子聚集在银河晕中，GZK 距离限制不再适用。

### 1.2.3 Boldt–Ghosh 建议（注脚 4）

[FACT] Boldt 和 Ghosh [27] 最近提出：旋转超大质量黑洞（不活跃类星体遗迹）的事件视界附近可将粒子加速到 ~10²¹ eV；本地 GZK 距离内的此类天体数量足以解释观测到的 EHECR 通量。

[INTERPRETATION] 这是一个试图绕过"本地缺乏活动源"难题的 Bottom-up 变种。1999 年时仍是新提议，作者未深入展开。

## 1.3 关键术语界定 [FACT]

| 术语 | 定义 |
|---|---|
| **EHE** (Extremely High Energy) | E ≳ 10²⁰ eV（本文专有用法） |
| **UHE** (Ultra-High Energy) | E ≳ 1 EeV = 10¹⁸ eV（含 EHE，反之不然） |
| Bottom-up | 通过加速机制产生 |
| Top-down | 通过大质量粒子衰变产生 |
| GZK effect | 质子与 CMB 光子的 photo-pion 产生 |

## 1.4 作者逻辑链

```
观测事实：>10^20 eV 事件已被探测
    →
传统加速模型遇到三个困难：
  (a) 粒子从致密源区逃出时能量损失；
  (b) GZK 效应限制源距离 ≲100 Mpc；
  (c) 本地宇宙缺乏足够强、近的源
    →
因此需要两个视角：
  Bottom-up：改进加速/源模型（射电星系、AGN）
  Top-down：引入新物理（GUT 拓扑缺陷、超重粒子衰变）
    →
本文以 Top-down 为主（已有大量 Bottom-up 综述）
```

## 1.5 [CRITIQUE] 作者立场分析

- 作者明确偏向 Top-down，理由是已有大量优秀的 Bottom-up 综述。但这意味着**本文对 Bottom-up 的讨论较简略**（§5 仅 ~7 页），读者若只读本文会低估 Bottom-up 的进展。
- 作者承认实验非专长，实验综述部分相对简略 [FACT]。
- [CRITIQUE] 事实上，2000 年后 AGASA 数据、Auger 观测、以及 UHE 中微子探测（IceCube-170922A 等）深刻重塑了这个领域，Top-down 场景因缺乏对应信号而受到严格约束（见 §7）。这是 1999 年时无法预见的发展。
