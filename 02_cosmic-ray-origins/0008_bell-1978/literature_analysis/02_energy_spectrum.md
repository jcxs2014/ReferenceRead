## 2.1 几何与符号（[FACT]）

参考 §1 引入的平行激波几何（图 1，p.149）：

```
上游 ─────────│ 激波 │───────── 下游
              x=0    x→
   <── $u_{1}$ ─── 反向流 ─── $u_{2}$ ──→ (运动方向)
```

- $u_1$: 上游散射中心平均速度（在激波静止参考系中）
- $u_2$: 下游散射中心平均速度
- $u_1 > u_2$（压缩结果：$u_1/u_2 = \chi$，压缩比）
- 散射中心在激波静止参考系中处理为非相对论流体

## 2.2 扩散-对流方程（[FACT]）

**方程 (1)**: 描述下游散射中心粒子数密度演化

$$\frac{\partial n}{\partial t} + u_2 \frac{\partial n}{\partial x} = \frac{\partial}{\partial x}\left(D(x)\frac{\partial n}{\partial x}\right) \tag{1}$$

**条件**：连续地向下游注入粒子，速率同粒子在远处被对流去除——时间无关问题。

## 2.3 稳态解与逃逸概率（[FACT]）

**方程 (2)**: 方程 (1) 的稳态解

$$n(x,t) = A + B \exp\left[\int^0 \frac{u_2}{D(x')}dx'\right] \tag{2}$$

**边界条件**：
- 设散射区延伸无穷（实际上 $v \gg u_2$ 时成立）
- $n(x,t)$ 对 $x>0$ 有限 → $B=0$ → 必须 $A$ 为零
- 推论：$n(0,t)$ 为常数

**方程 (3) — 关键**：逃逸概率

$$\eta = \frac{4u_2}{v} \tag{3}$$

**推导**：单位时间内从上游穿到下游的粒子数 = $u_2 n(0,t)$，这部分从下游逃逸=[$v n(0,t)$] 的概率 $\eta = 4u_2/v$。

**重要极限**：高能粒子 $v \to c$ 时，$\eta$ 与能量无关。

## 2.4 粒子的能量增长（[FACT]）

### 2.4.1 单次穿越

**几何**：粒子从一侧散射中心系穿越到另一侧，速度 $v$、入射角 $\theta_{k1}$，出射角 $\theta_{k2}$。

**方程 (4)**: 单次穿越后能量增长

$$E_{k+1} = E_k \left[\frac{1 + v_{k1}(u_1-u_2)\cos\theta_{k1}/c^2}{1 + v_{k2}(u_1-u_2)\cos\theta_{k2}/c^2}\right] \tag{4}$$

其中 $v_{k1}, v_{k2}$ 为粒子在各自散射中心的相对论性速率。

> **批注**：保持 Lorentz 不变——这是论文的数学严谨性体现。

### 2.4.2 多循环

**方程 (5)**: $l$ 次循环后

$$\ln\frac{E_l}{E_0} = \sum_{k=0}^{l-1}\ln\left[\frac{1 + (u_1-u_2)\cos\theta_{k1}/c}{1 + (u_1-u_2)\cos\theta_{k2}/c}\right] \tag{5}$$

**中心极限定理适用**：$l$ 大时，$\ln(E_l/E_0)$ 分布聚集于均值。

**方程 (6)**: $l$ 次循环后对数能量增长均值

$$\left[\ln\frac{E_l}{E_0}\right] = l \left\langle \ln\left[\frac{1 + (u_1-u_2)\cos\theta_{k1}/c}{1 + (u_1-u_2)\cos\theta_{k2}/c}\right] \right\rangle \tag{6}$$

**简化**：散射是各向同性的，穿越激波的角度在 $\theta \to \theta+d\theta$ 范围与 $(2\pi\sin\theta\, d\theta)\cos\theta$ 成正比；对 $\theta$ 求平均。

**方程 (7)**: 对数能量增长（极限形）

$$\ln\frac{E_l}{E_0} = \frac{4}{3}\frac{u_1-u_2}{c} \cdot l \tag{7}$$

> **[INTERPRETATION]**：这是**最关键的一步**——每循环对数能量增长与 $l$ 成正比，**系数是几何常数**（与激波强度有关），与粒子能量无关。

## 2.5 能量谱推导（[FACT]）

### 2.5.1 循环 $l$ 次的概率

粒子在下游的几何下，至少完成 $l$ 次循环的能量 $E_l$ 与初始 $E_0$ 的关系：

**方程 (8)**: 

$$\ln P_l = l \ln\left(1 - \frac{4u_2}{c}\right) = -\left(\frac{3u_2}{u_1-u_2} + \frac{u_1-u_2}{c}\right) \ln\frac{E_l}{E_0} \tag{8}$$

利用 $P_l = (1-\eta)^l = (1 - 4u_2/c)^l$

### 2.5.2 幂律谱

**方程 (9) — 论文核心结果**：

$$N(E) dE = \frac{\mu-1}{E_0}\left(\frac{E}{E_0}\right)^{-\mu} dE \tag{9}$$

其中 $\mu$ 是**谱指数**。

### 2.5.3 谱指数公式

**方程 (10) — 物理核心**：

$$\mu = \frac{2u_2 + u_1}{u_1 - u_2} \tag{10}$$

**强激波极限**：$u_1/u_2 = 4$（压缩比 $\chi=4$），$\mu = (2u_2+4u_2)/(4u_2-u_2) = 6u_2/3u_2 = 2$

**注**：上面是 test-particle 极限，**未考虑 CR 对激波结构的反馈**。

## 2.6 含 Alfvén 波速修正（[FACT]）

**方程 (11)**: 考虑 Alfvén 波速 $v_A$ 后的等效速度

$$u_1 = v_s - v_A, \quad u_2 = \frac{v_s}{\chi} - v_w \approx \frac{v_s}{\chi} - v_A \tag{11}$$

**逻辑**：
- 上游 Alfvén 波主要由粒子向外流（super-Alfvénic）激发，波速度 ≈ Alfvén 速度
- 下游散射中心在激波静止参考系中的平均速度含类似项
- 假设 $v_A \approx v_w$（Skilling 私人通信）

**修正结果**：当 $v_A = v_s/12$ 时，强激波 $\chi=4$ 给出 $\mu = 2.5$，与宇宙线观测吻合。

## 2.9 [INTERPRETATION] 谱指数为什么与能量无关

**关键洞察**：$\mu$ 不依赖 $E$ 因为：
1. 逃逸概率 $\eta = 4u_2/v$ 在 $v \to c$ 时与能量无关
2. 单次循环能量增长 $\Delta E/E \sim (u_1-u_2)/c$ 在 $v \to c$ 时与能量无关
3. → 整个机制是**scale-invariant** → 幂律

**批注**：scale invariance 是分形/自相似的物理体现——激波机制在不同能量尺度上重复。
