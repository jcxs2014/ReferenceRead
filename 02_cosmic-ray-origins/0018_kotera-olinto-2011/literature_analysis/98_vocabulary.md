# 98 Vocabulary (术语表)

| 中文 | 英文 | 含义 |
|------|------|------|
| 超高能宇宙线 | Ultrahigh Energy Cosmic Rays (UHECR) | 能量 ≥10¹⁸ eV (通常 ≥10²⁰ eV) 的带电粒子 |
| 膝点 | Knee | 宇宙线谱在 ~1 PeV 处的第一次变陡 |
| 踝点 | Ankle | ~3 EeV 处的谱硬化，银河-河外转换或传播 dip |
| 第二膝 | Second knee | ~0.5 EeV 处预测的次级变陡 |
| GZK 截断 | Greisen-Zatsepin-Kuzmin cutoff | >50 EeV 处 UHECR 与 CMB 作用导致的通量抑制 (Greisen 1966; Zatsepin & Kuzmin 1966) |
| Trans-GZK | Trans-GZK | >60 EeV 能量段，源须在 GZK 视界 (~100 Mpc) 内 |
| GZK 视界 | GZK horizon | ~100 Mpc 内可观测 UHECR 源的距离 |
| 踝点转换模型 | Ankle transition model | 银河-河外转换发生在踝点的模型 |
| Dip 模型 | Dip model | 踝点是质子对产生传播 dip 的模型 (Berezinsky et al. 2006) |
| 光致π产生 | Photo-pion production | p + γ → N + πⁿ，GZK 主要能量损失机制 |
| 对产生 / Bethe-Heitler | Pair production | p + γ → p + e⁺ + e⁻ |
| 光致离解 | Photodisintegration | 核在 CMB/IR-UV 光子上碎裂 |
| 巨偶极共振 | Giant Dipole Resonance (GDR) | 光致离解机制之一，ε ≈ 8–30 MeV |
| 准氘核过程 | Quasi-Deuteron (QD) | 光致离解，ε ≈ 20–150 MeV |
| 重子共振 | Baryonic Resonance | 光致离解，ε ≳ 150 MeV |
| 磁场偏转 | Magnetic deflection | 银河/星系际磁场引起的 UHECR 方向偏离 |
| 磁视界 | Magnetic horizon | 粒子传播路径 > cH₀⁻¹ 时源不可见 |
| 扩散时标 | Scattering time t_scatt | 粒子二次偏转角 ~1 的时间尺度 |
| 磁化 filament | Magnetized filament | 星系团之间磁化的宇宙网 filament |
| 宇宙背景辐射 | Cosmic background radiation | CMB + IR-UV 光子背景 |
| Hillas 判据 | Hillas criterion | r_L ≤ R → E_max = ZeBRc，候选源必要条件 |
| Hillas 图 | Hillas diagram | B-R 相空间中候选源分布 (Fig 11) |
| 刚性 | Rigidity | R = p/Z ≈ E/Z |
| 1st order Fermi | First order Fermi | 相干激波加速，ΔE/E ~ β |
| 2nd order Fermi | Second order Fermi | 随机散射加速，ΔE/E ~ β² |
| 剪切加速 | Shear acceleration | 沿流速梯度的加速 (jet 侧壁) |
| 单极感应器 | Unipolar inductor | 旋转磁星/黑盘的感应电场加速 |
| 磁星 | Magnetar | 表面磁场 ~10¹⁵ G 的中子星 |
| 吸积激波 | Accretion shock | 星系团/ filament 吸积时的激波 |
| 有源星系核 | Active Galactic Nucleus (AGN) | 大质量黑洞 + 吸积盘 + 可能 jet |
| FRI / FRII | Fanaroff-Riley class | 射电星系分类，FRII/FSRQ 磁光度高 |
| 伽马射线暴 | Gamma-ray burst (GRB) | 瞬发高能爆发，可能加速 UHECR |
| 热斑 / bow shock | Hot spot / bow shock | AGN jet 终止处的激波 |
| 宇宙线天文学 | Cosmic ray astronomy | 利用 UHECR 方向指认源 |
| 多信使 | Multi-messenger | 联合 UHECR + ν + γ 约束源 |
| 宇宙基因中微子 | Cosmogenic neutrino | UHECR 与 CMB 作用产生的中微子 (GZK 产物) |
| Waxman-Bahcall 上限 | Waxman-Bahcall bound | τ_pγ = 1 时的 ν flux 上限 |
| 光子视界 | Gamma-ray horizon | >100 TeV γ 视界 ~几 Mpc |
| 荧光望远镜 | Fluorescence telescope | 通过宇宙线空气簇射的 N₂ 荧光探测 (HiRes, Auger, TA) |
| 水切伦科夫阵列 | Water Cherenkov array | 通过切伦科夫光探测簇射次级 (Auger) |
| 曝光量 L | Exposure L | 1 km²·sr·yr (致敬 Linsley) |
| CRPropa | CRPropa | UHECR 传播蒙特卡洛公开代码 |
| SOPHIA | SOPHIA | UHECR 传播解析工具 |
