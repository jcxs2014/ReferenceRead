## [FACT] 论文 5 条结论

1. **[FACT]** **高 $M$ 激波（$M \gtrsim 50$）**可产生**极强 CR 诱导 precursor**（图 3）——入射等离子体被剧烈减速与加热（见 Part I）
2. **[FACT]** 激波前**磁场放大**对强激波更有效；在**可比于 CR 扩散长度的区域平均**，$M_A=100$ 时放大 $\sim 10$；标度律 $(B_{\rm tot}/B_0)^2 \propto M_A$（图 5）。向年轻 SNR 相关数百 $M$ 外推可解释**数百高斯推断磁场**
3. **[FACT]** 激波 $M \lesssim 30$ 上游**磁湍流谱**（图 6）与**共振流不稳定性**预言一致（Bell 1978；Achterberg 1983）；波中能量分布由**加速粒子能量分布决定**（式 8）；**准垂直激波**放大消失——因加速无效、CR 电流弱或不存在
4. **[FACT]** **$M_A \gtrsim 30$** 激波表现不同：由**NRH 不稳定性**（Bell 2004, 2005）激发的短波长模式**增长快于共振**；NRH 模式由**逃逸离子**（$E \sim E_{\max}$）激发，其波长**随放大按 $(B/B_0)^{-2}$ 增长**，直至与 $E_{\max}$ 离子回旋半径相当
5. **[FACT]** 对这类高 $M_A$ 激波可区分**两个区域**：**远上游**（电流由逃逸 CR 提供）与 **precursor**（电流由扩散/磁化 CR 的梯度提供）。**NRH 主导远上游**，**共振与 NRH 在 precursor 以相当速率增长**。两区域界面即所谓**自由逃逸边界**

## [FACT] 后续工作与展望

- 上述结果可用于**将自洽微物理纳入激波粒子加速模型**，特别是**非线性 DSA**（Caprioli et al. 2010）——通常需对自由逃逸边界位置与主导 MFA 通道做预设
- 磁场总放大水平及与 $M_A$ 的标度律对**非热电子同步辐射**建模也关键（SNR、AGN 叶、星系团）
- 后续工作将覆盖**自生磁湍流中的粒子扩散与 $E_{\max}$ 时间演化**（Caprioli & Spitkovsky 2014b, Paper III），以及**注入 DSA 的机制**（为本系列提供闭合）

## 附录 [FACT]：横向盒子尺寸的依赖（图 9）

- **[FACT]** Run A ($L_y = 1000\,c/\omega_p$) 与 Run B ($L_y = 200\,c/\omega_p$) $M=20$ 平行激波对比
- **[FACT]** 左方面板：$B_{\rm tot}$ 与 $\max_x B_{\rm tot}(x,y)$ 剖线——Run B 中两者几乎重合；Run A 中横向平均 $\langle B_{\rm tot}\rangle$ **几乎与横向尺寸无关**（只要足够包含多数离子回旋半径）
- **[FACT]** 右方面板：非热离子谱 $t \lesssim 800\omega_c^{-1}$ 时两 Run 非常相似；之后 Run A 中 $E_{\max}$ 扩散长度与纵向盒子相当 → $E_{\max}$ 停止增长
- **[FACT]** DSA 谱指数仅由激波压缩比决定；$E_{\max}(t)$ 由磁不规整强度与拓扑决定
- **[FACT]** 结论：**大横向尺寸对捕捉电磁场拓扑与激波波纹（有观测意义）是必要的**（CS13），但**中等 2D 模拟对平均磁场放大水平等量足够充分**

## 我的理解 / Interpretation

**[INTERPRETATION]** §6 精炼地总结了系列的物理图景：**中等激波（$M \lesssim 30$）→ 共振流不稳定性（Alfvén 波）主导 MFA；强激波（$M \gtrsim 30$）→ NRH 主导远上游 + 共振在 precursor 内补充**。标度律 $(B_{\rm tot}/B_0)^2 \propto M_A$ 与自由逃逸边界自洽定义为后续唯象/非线性 DSA 模型提供了**闭合的关键输入**。系列三篇论文共同构成 **DSA 微物理的完整自洽链条**：注入（未完结）→ 加速（Part I）→ 放大（Part II）→ 散射（Part III）。
