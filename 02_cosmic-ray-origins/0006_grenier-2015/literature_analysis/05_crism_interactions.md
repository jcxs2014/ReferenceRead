# 5. Cosmic-Ray / Interstellar Medium Interaction Processes

## 5.1 本节核心内容

**[FACT]** CR 与星际物质相互作用有两类：
1. **集体行为**（与磁场和波），平均自由程 << 特征尺度时 → 流体力学描述（Zweibel 2013）。
2. **微观**（原子、分子、核过程），粒子一个个撞击原子、分子、尘埃和辐射场。

**[FACT]** 需要跨越巨大能量范围理解这些过程。

## 5.2 §5.1 Atomic and Molecular Processes

**[FACT]** 银河系星际质量大部分在中性相，大部分是 H（原子或分子）。

**[FACT]** 中性气体柱密度 N_H ~$10^{18}$–$10^{21}$ cm⁻² → 对最热最强热源的**电离辐射不透明**。

**[FACT]** 电离光子限制在电离源近邻（电离界定光致电离星云）。外部 UV 星光 (hν <13.6 eV) 可穿透气体，电离 C、S、Si、Mg、Fe 等低电离势元素，直到尘埃屏蔽。

**[FACT]** 中性 ISM 的电离分数随屏蔽列深度下降：x(e) = n(e)/n_H ~$10^{-4}$（C 仍电离）→ x(e) <$10^{-7}$。

**[FACT]** 热 UV 主导离子化、化学、热状态的中性区域称为 **PDR**（photon-dominated region），包括弥漫与半透明分子云（Snow & McCall 2006）。

**[FACT]** PDR 之外（暗云 + GMC）：CR 控制电离、化学、热平衡。即使残余电离也足够让磁场在云动力学年龄上耦合 → 影响恒星形成坍缩。

**[FACT]** 热状态与电离机制直接关联：释放电子将原子结合能转化为气体动能。PDR 中尘埃/VL分子光电发射是重要加热。

### CR 电离过程（关键公式）

**[FACT]** CR 核与电子与原子/分子碰撞电离。对 CR 质子 + H：
```
CR + H  →  H⁺ + e⁻ + CR
CR + $H_{2}$ →  $H_{2}$⁺ + e⁻ + CR
```
- CR 损失可忽略能量份额，继续飞行。
- 释放电子典型动能 **35 eV**，几乎与 CR 能量无关。
- 电子**至少再电离 1 个原子/分子**，产生更多次级电子。

**[FACT]** 电子级联：35 eV → 平均热能 ~kT ~ 8.6(T/100 K) meV。从 100 K 气体原子视角，35 eV 电子超热 **>$10^{3}$ 倍**。

**[FACT]** 初始电子能量转为加热的比例：
- 完全电离气体：**~100%**
- 中性气体：**~20%**（次级电离 + 束缚态激发占主导）

**[FACT]** CR 在中性气体中的加热率：~$10^{-27}$ (ζ_H^CR / $10^{-16}$) erg s⁻¹ 每 H。

**[FACT]** CR 可穿透大气体柱 → 在 UV/X 屏蔽区域电离 H、He → 提供足够加热，使气体温度最低值 ~8 K（高于 CMB 2.7 K）；提供足够离子驱动可观测化学。

**[FACT]** CR He 与重核也电离，但速率按其在 CR 谱中的较低丰度比例降低。

## 5.3 §5.2 Cosmic Ray–Induced Ultraviolet Radiation

**[FACT]** $H_{2}$ 气体放电产生特征 UV 发射谱 λ <200 nm。CR 电离 $H_{2}$ 的次级电子可在分子云深处产生**内部 UV 源**（星光不穿透的区域）。

**[FACT]** 首次分析：Prasad & Tarafdar (1983)。之后建模 $H_{2}$ 电子碰撞激发 UV 谱 + 星际尘埃散射（Sternberg 1987; Gredel 1989; Cecchi-Pestellini 1992）。

**[FACT]** 光化学速率被纳入广泛使用的化学反应网络：**UMIST** 数据库（McElroy 2013）、**KIDA** 数据库（Wakelam 2012）。

**[FACT]** $H_{2}$ 电子碰撞 UV 发射谱现已可在某些星周盘中直接识别（Ingleby 2009）。

**[FACT]** 多数星际分子由**连续吸收过程**光解 → CR 诱导 UV 光解速率与 ζ_$H_{2}$^CR 线性相关，依赖尘埃散射/吸收的平均概率。

**[FACT]** 三个分子例外：**$H_{2}$、CO、$N_{2}$** — 仅在 >91.2 nm 窄线吸收光解 → CR 诱导光解速率对**线波长偶然巧合**极敏感。需要详细实验室数据与计算。

**[FACT]** 例如 ζ_$H_{2}$^CR = $10^{-16}$ s⁻¹ 时 $N_{2}$ 光解速率 ~$10^{-15}$ s⁻¹，而 ¹⁴N¹⁵N 同位素不同（Heays 2014）。这是星际空间 $N_{2}$ 重同位素富集的过程之一。

## 5.4 §5.3 Interaction with Solid Particles — 尘埃与冰壳

**[FACT]** 尘埃颗粒 ~占总星际物质的 **1%**。星际尘埃典型直径 ~0.1 μm，几何截面 ~$10^{-21}$ cm² 每 H。

**[FACT]** 冷颗粒 T_dust <20 K → 挥发种（C、N、O、$H_{2}$O、$NH_{3}$、CO）冻结到表面 → 冰壳化学反应。

**[FACT]** ≥1 MeV 的 CR 质子在非晶碳中的射程 ≥ 2.8×$10^{-3}$ g cm⁻² → **全部此类 CR 穿越典型尘埃颗粒而能量损失可忽略**。但单次 CR 事件沉积能量显著。

**[FACT]** 1–100 MeV 核的直接 CR 与冰壳作用 < CR 诱导 UV 的光解吸附与光处理（Shen 2004）。

**[FACT]** 粒子轰击预计降低水冰孔隙度，与 IR 光谱示意的星际冰普遍不具高孔隙一致（Dartois 2013）。

## 5.5 §5.4 Spallation and Synthesis of Light Elements

**[FACT]** Li、Be、B 同位素丰度是 CR-ISM 相互作用的重要体现：
- 这些核素在恒星核合成中被破坏（而非形成），因为其低温度聚变阈值。
- 丰度由**散裂**控制：银河系 CR p 与 α 粒子在 C、N、O 上产生 ⁶Li、⁷Li、⁹Be、¹⁰B、¹¹B。

**[FACT]** 竞争过程：
- 逆散裂：CR 中 C/N/O 核 + 环境 H/He
- 中微子诱导散裂：II 型超新星（Woosley 1990）及可能 Ic 型（Nakamura 2010）

**[FACT]** 同位素来源分解：
- **⁶Li、⁹Be、¹⁰B**：主要由 ISM CR 散裂产生。
- **⁷Li**：散裂 + (ν,He) 超新星 + Big Bang + AGB + novae。
- **¹¹B**：散裂 + (ν,C) 超新星 + AGB + novae。

**[FACT]** Li、B 同位素比不仅受散裂率影响，还受银河系恒星演化、质量损失、混合的积分历史影响。

**[FACT]** ⁷Li/⁶Li 在星际介质可直接测量：
- Knauth (2000,2003) 在几个弥漫云测得 **~2**（不同太阳系 12.3）→ **最近散裂产生 Li** 的证据。
- 在 IC 443 附近观测到的低 ⁷Li/⁶Li 提供最近 CR 散裂产生 Li 的进一步证据，并表明**超新星事件中微子诱导散裂在 Li 产生中次要**（Taylor 2012）。

**[FACT]** 其他 Li 同位素比测量被用作星际气体均匀混合与快速循环的证据（Kawanomoto 2009）。

**[FACT]** B 与 ¹⁰B/¹¹B 在星际气体中的丰度已有研究（Lambert 1998; Howk 2000; Ritchey 2011）。

**[FACT]** SMC（小麦哲伦云）有低 C/N/O 星际丰度（Korn 2000; Salmon 2012）与低 CR 流（Abdo 2010e）。若正向散裂主导 B 产生，SMC 产生率应为银河系的 ~5%（Brooks 2002）。SMC 的 Li 丰度与 Big Bang 预期一致（Howk 2012）。

**[FACT]** 高红移星系（z = 2.0–2.6）damped Lα 系统吸收光谱已检测到 B（Prochaska 2003; Berg 2013）。**逆散裂**（星际 H、He 作靶）在贫金属 ISM 中可能主导 → 应随红移增强。

**[FACT]** 星际 Be 迄今未检出（Hebrard 1997）。

## 5.6 Figure 8 — CR 诱导化学反应流图

### 目的
展示 CR 电离 H、$H_{2}$ 触发的化学反应流图，说明 O 含离子与 $H_{3}$⁺ 丰度如何与电离率及 $H_{2}$ 分数、电子分数相关。

### 元素
```
CR + $H_{2}$ → $H_{2}$⁺ + e⁻ → (与 $H_{2}$) → $H_{3}$⁺
CR + H  → H⁺
CR + He → He⁺ → (与 $H_{2}$) → HeH⁺
```
O 离子序列：
```
H⁺/$H_{3}$⁺ + O → O⁺ → (与 $H_{2}$) → OH⁺ → (与 $H_{2}$) → $H_{2}$O⁺ → (与 $H_{2}$) → H3O⁺
→ 离解复合 e⁻ → OH, $H_{2}$O
```

### 关键观察
- **[FACT]** 电荷从 CR 产生的 H⁺、$H_{3}$⁺ 轻易转移到 OH⁺、$H_{2}$O⁺、$H_{3}$O⁺。
- **[FACT]** O 离子序列进行到 $H_{3}$O⁺ 的效率主要由气体分子分数 f($H_{2}$) 限制：
  - f($H_{2}$) <<1 → 有利于 OH⁺
  - f($H_{2}$) ~1 → OH⁺、$H_{2}$O⁺ 高效 → $H_{3}$O⁺
- **[FACT]** $H_{2}$O⁺/OH⁺ 比**对 f($H_{2}$) 敏感** → 可作为分子分数探针。
- **[FACT]** 分子区中 OH、$H_{2}$O 中性分子丰度依赖自由电子丰度。

### 与化学示踪的关系
- 弥漫/半透明气体（PDR，A_V ≤1 mag）：C 光致电离主导 → C⁺、$CH_{2}$⁺、$CH_{3}$⁺ → 与 CR 产物反应 → HCO⁺、CO 的主要源。
- 稠密暗区（f($H_{2}$)~1）：$H_{3}$⁺ + CO → HCO⁺ + $H_{2}$ 可能既是 HCO⁺ 主源又是 $H_{3}$⁺ 主沉。

## 5.8 潜在问题
- **[CRITIQUE]** 散裂同位素产生率的定量分离（正向 vs 逆散裂、宇宙线 vs 中微子 vs Big Bang）高度依赖成分与截面模型，且涉及银河系演化历史积分。
- **[CRITIQUE]** CR 诱导 UV 对线吸收过程（$H_{2}$, CO, $N_{2}$）的**巧合共振敏感性**使得光化学速率估计不确定性大。
- **[CRITIQUE]** DNM（§7.1）和 CR 对尘埃/冰壳的累积效应，观测仍难以分离 CR 作用与 UV 光化学的叠加。
