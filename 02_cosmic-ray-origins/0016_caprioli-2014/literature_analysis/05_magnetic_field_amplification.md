#### 5.1 [FACT] 磁场放大与加速的强相关性

- **[FACT]** 准平行强激波：磁场显著放大。放大因子 $B_{\max}/B_0 \sim$ 数倍至 10 倍量级，随 Mach 与时间增大。
- **[FACT]** 准垂直激波：磁场**不放大**——与加速效率骤降同步。
- **[FACT]** 关键物理机制：加速离子注入**自激波**（上游离子流不稳定）$\to$ 湍流增强 $\to$ 更大粒子扩散 $\to$ 更强 DSA；磁场放大与加速互为因果。
- **[FACT]** 上游 $\vartheta \gtrsim 45°$ 激波：离子流不注入超出一个 gyroradius 的波 $\to$ 磁场保持基本不变 $\to$ DSA 失效。

#### 5.2 [FACT] §5.1 观测后果：SN 1006

- **[FACT]** SN 1006 是著名的**几何测试案例**——其激波几何同时包含平行区与极斜区。
- **[FACT]** **平行区**（"wings"）：射电偏振 + X 射线观测显示粒子加速迹象；与模拟预测的强加速 + 磁场放大一致。
- **[FACT]** **极斜区**（"eastern rim"）：强同步辐射表明**磁场放大**，但粒子加速弱——与模拟预测吻合。
- **[FACT]** 偏振度：模拟给出**平行区高偏振 + 极斜区低偏振**的形态，与 SN 1006 观测定性一致。

#### 5.3 [FACT] 磁场放大的能量来源

- **[FACT]** 磁场放大所需能量**来自下游流**（流被减速）而非直接来自加速粒子本身。
- **[FACT]** 但放大**由加速离子驱动的湍流触发**——自激 Alfvén 波 + 镜像不稳定性共同作用。

## 我的理解 / Interpretation

**[INTERPRETATION]** §5 是**把模拟联系到观测**的关键节。磁场放大与加速效率的同步"开启/关闭"是 DSA 自洽理论的强证据——Bell 1978 等解析理论把磁场放大作为额外输入，本文证明**加速本身就是放大机制**（通过自激湍流）。SN 1006 观测形态与模拟的一致性使这篇论文在观测天体物理界获得广泛引用（如 Giuffrida 2022, Giacalone 2017）。
