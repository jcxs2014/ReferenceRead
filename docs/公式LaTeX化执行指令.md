## 1. 任务分解

### 第一轮：方案 B（科学记数法/参数下标 → LaTeX；核素/单位/标记保留）

| 形态 | 示例 | 处理 |
|---|---|---|
| 科学记数法（纯数值） | `10⁷ yr`、`10⁸ K` | `$10^{7}$ yr`、`$10^{8}$ K` |
| 科学记数法（×10ⁿ） | `2×10⁶ yr`、`8.2×10⁻¹⁷ s` | `$2\times10^{6}$ yr`、`$8.2\times10^{-17}$ s` |
| 参数下标 | `T₉`、`t₁/₂`、`T₈` | `$T_9$`、`$t_{1/2}$`、`$T_8$` |
| 已有 `$...$` | 任何 | 保护，不碰 |
| **核素/同位素** | `¹²C`、`⁸Be`、`Zr⁹⁰`、`¹³N(p,γ)¹⁴O` | **保留 Unicode**（本轮） |
| **单位带指数** | `g cm⁻³`、`cm⁻² s⁻¹` | **保留 Unicode**（本轮） |
| **衰变/电荷标记** | `β⁺`、`β⁻` | **保留 Unicode**（本轮） |
| **不确定度** | `±²/₋₄` | **保留**（本轮；形态特殊，全程人工核对） |

### 第二轮：全转（把第一轮保留的全部转 LaTeX）

| 形态 | 示例 | 处理 |
|---|---|---|
| 核素/同位素 | `¹²C`、`⁸Be`、`Zr⁹⁰` | `$^{12}{\rm C}$`、`$^{8}{\rm Be}$`、`$^{90}{\rm Zr}$`（元素符号正体，质量数上标前缀） |
| 核反应 | `¹³N(p,γ)¹⁴O` | `$^{13}{\rm N}(p,\gamma)^{14}{\rm O}$` |
| 单位带指数 | `g cm⁻³`、`cm⁻² s⁻¹` | `${\rm g\,cm^{-3}}$`、`${\rm cm^{-2}\,s^{-1}}$`（正体 + `\,` 细空格） |
| 衰变/电荷标记 | `β⁺`、`β⁻` | `$\beta^{+}$`、`$\beta^{-}$` |
| 太阳质量 | `M☉` | `$M_\odot$` |
| 希腊字母（纯符号语境） | `τ ∝ ρ⁻¹`、`π`、`μ` | `$\tau \propto \rho^{-1}$`、`$\pi$`、`$\mu$` |
| 数学符号（关系式整体） | `A ≈ B`、`ρ ≤ ρ_c`、`x → ∞` | `$A \approx B$`、`$\rho \le \rho_c$`、`$x \rightarrow \infty$` |
| 乘号 | `×`（等式内） | `\times`（包入 `$...$`） |
| **中文术语内希腊字母** | `μ子`、`α粒子`、`β衰变` | **保留 Unicode**（是中文词，不是公式） |
| **孤立符号/叙述箭头** | 正文 "→ 详见"、列表符号 | **保留**（非公式） |
| **不确定度** | `±²/₋₄` | 逐处人工核对（`$^{+2}/_{-4}$` 或按原文语境），不机械处理 |

> 第二轮执行原则：**智能判断为主、脚本辅助**。脚本负责可安全机械化的固定模式（核素、单位、β⁺、M☉）；等式/关系式（含 ≈/≤/∝/→/× 等符号）需按上下文判断后整体包 `$...$`，禁止无脑把孤立符号塞进公式。

## 2. 转换脚本（自建，放 `webapp/convert_unicode_math.py`）

脚本要点（已在前一轮试点验证过）：
1. **frontmatter 状态机**：文件开头 `---` 进入、遇 `---` 退出，frontmatter 内不转换
2. **已有 `$..$` 占位保护**：先替换为占位符，转换完还原
3. **复合下标一次转**：`t₁/₂` 必须一次转成 `$t_{1/2}$`，禁止先转一半再补（试点教训：碎成 `$t_{1}$/₂`）
4. **审计清单输出**：每次转换记录 `文件\t行号\t原文\t转换后\t类别` → `conversion_audit.tsv`（每批一份，随批提交）——**这是对照验证的凭据**
5. **Unicode 残留自检**：转换后统计残留上标/下标，人工核对是否全部属于"本轮应保留"类别
6. 幂等保护：已含 `$` 或已转换的行不重复处理

## 3. 对照原文验证（每篇必做，最重环节）

### 3.1 从审计清单抽样对照原文 PDF

| 类别 | 抽查强度 | 核对内容 |
|---|---|---|
| 科学记数法数值（含小数/多位数，如 `8.2×10⁻¹⁷`） | **全覆盖** | 数值/指数与原文一致 |
| 参数下标（`T₉`/`t₁/₂`） | 每篇 ≥5 处 | 符号与原文一致 |
| ×10ⁿ 表达式 | 每篇 ≥5 处 | 数值+结构 |
| 保留类（第一轮：核素/单位） | 抽查 3 处 | 确认确实未误转 |
| 全转类（第二轮：核素/单位 LaTeX 写法） | 每类 ≥3 处 | `^{12}{\rm C}` 写法、正体、间距正确 |

### 3.2 对照方法

- **文本型 PDF**：`pdftotext <pdf> - | grep -n "<关键词/数值>"` → 核对原文段落
- **扫描型 PDF**：`pdftoppm -png -r 150 <pdf> /tmp/pg` → 读图核对
- **background 汇总文档**：数值溯源到对应文献 PDF（如 `T₉` 来自哪篇综述，对照该篇）

### 3.3 完成判定

抽查 100% 通过（数值零差异、语境正确、写法规范）→ 该篇合格；任一不符 → 退回修正该处，并**连带检查同类形态是否同样出错**。
