## 1. 转换规则（全转上下标）

> 基底（上下标前的字符）留在数学模式外作文本；上下标进 `^{..}`/`_{..}`。已处于 `$...$` 内（奇偶 `$` 计数为奇）时只插 `^{..}`/`_{..}`，不包外层 `$`（防双 `$`）。

| 类别 | 原文 | 转后 | 说明 |
|---|---|---|---|
| 同位素（前置上标+元素） | `²²Ne`、`¹²C`、`⁸Be` | `$^{22}{\rm Ne}$`、`$^{12}{\rm C}$`、`$^{8}{\rm Be}$` | 元素白名单识别，元素正体 `\rm`；质量数上标前缀 |
| 同位素（后置上标） | `Zr⁹⁰` | `Zr$^{90}$` | 基底为元素尾字母，正常包裹 |
| 单位指数 | `cm⁻²`、`s⁻¹`、`g cm⁻³` | `cm$^{-2}$`、`s$^{-1}$`、`g cm$^{-3}$` | 整体进数学模式（基底单位作文本） |
| 变量/量纲幂 | `GeV²`、`E²`、`10²` | `GeV$^{2}$`、`E$^{2}$`、`10$^{2}$` | 基底为字母/数字 |
| 化学下标 | `CO₂`、`H₂O`、`H₃⁺` | `CO$_{2}$`、`H$_{2}$O`、`H$_{3}$$^{+}$` | 基底为元素符号；上下标相邻自动合并 `$_{3}^{+}$` |
| 电荷/粒子标记 | `e⁺`、`p⁻` | `e$^{+}$`、`p$^{-}$` | 基底为字母 |
| 衰变标记（希腊基底） | `β⁺`、`β⁻` | `$\beta^{+}$`、`$\beta^{-}$` | 基底希腊字母一并转 `\beta`，整块包 `$` |
| 作者脚注/序号 | `Strong¹` | `Strong$^{1}$` | 视觉一致，仅源码形态变 |
| 词内上标 | `B²FH` | `B$^{2}$FH` | 用户拍板全转；渲染与原文一致 |

### 1.1 显式排除（不转，列入审计「跳过」项，需人工确认）

- **不确定度记法** `±²/₋₄` 之类：上下标紧跟 `±` 或同一行 `±` 后 `/` 前的下标——跳过，不机械处理（语义特殊，逐处人工核对）。
- **`$$` 显示公式内部**：一律跳过。
