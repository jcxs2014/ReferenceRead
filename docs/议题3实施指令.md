## Part 1：quality_matrix.py 新增"子节镜像"统计

### 1.1 新增逻辑（插入脚本，保持现有 8 列主表与 --check 行为不变）

```python
# ---- 子节镜像统计（议题 3，仅警告不 fail）----
SUBSEC_RE = re.compile(r"^### \d+\.\d+\.\d+", re.M)

def score_subsections(text: str) -> int:
    """分章 ### N.n.n 三级子节数（路径 A 镜像指标）。"""
    return len(SUBSEC_RE.findall(text))

def parse_97_subsections(quality_text: str) -> tuple:
    """从 97「子节级覆盖」块解析 (已覆盖数, 原文子节总数)；无块返回 (None, None)。"""
    m = re.search(r"## 子节级覆盖.*?\n((?:\|.*\n)+)", quality_text, re.S)
    if not m:
        return (None, None)
    rows = [r for r in m.group(1).splitlines()
            if r.startswith("|") and "原文子节" not in r and set(r.replace("|", "").strip()) != {"-"}]
    covered = sum(1 for r in rows if "✅" in r)
    return (covered, len(rows))
```

### 1.2 输出（单独一行，位于现有"章节子节"行之后）

```
子节镜像: 4 篇有 97 块 | ruszkowski 65/65 (100%) | blasi 4/16 (25%) | grenier 7/19 (37%) | bhattacharjee 47/50 (94%) | 全库 ### N.n.n = 315
```

- 每篇格式：`<篇名> 镜像子节数/97名单数 (覆盖率%)`；97 无块 → 不列出
- 末尾汇总：`全库 ### N.n.n = <总数>`（所有篇分章三级标题合计）
- **仅 print 输出，不参与 --check 判定**（--check 仍只对 8 项硬指标）

### 1.3 数据装配

- 每篇：遍历 `literature_analysis/0*.md` 分章文件拼接文本 → `score_subsections` 得镜像数
- 97：读该篇 `97_quality_check.md` → `parse_97_subsections` 得 (覆盖数, 名单数)
- 覆盖率：有 97 块时 `镜像数/名单数`（镜像数用 97 块覆盖数口径一致化：**覆盖率 = 97 块覆盖数 / 97 名单数**，镜像数单独显示）

> 注意口径：覆盖率用 **97 块内 ✅ 数 / 名单总数**（人工确认口径）；`### N.n.n` 总数仅作旁证显示
