## 1. 每篇执行步骤

### 步骤 1：提取原文子节名单（§4.1）

```bash
# 通用：先试 fulltext 目录页（点线页码行）
grep -nE '^[[:space:]]*[0-9]+(\.[0-9]+)+[[:space:]]+[A-Z].*\.\.\.\.' <篇>/fulltext.txt
# 无目录 → 正文标题行
grep -nE '^[[:space:]]*[0-9]+(\.[0-9]+)+[[:space:]]+[A-Z][a-z]' <篇>/fulltext.txt
# 双栏文本流（ARA&A/ApJ 等，标注的篇）→ PDF 目录确认：
pdftoppm -png -r 80 -f 1 -l 3 <篇>/*.pdf /tmp/p  # 视觉读目录页
# 或 pdftotext -layout -f 1 -l 2 <篇>/*.pdf -
```

- 分章与原文章节映射：对照该篇 `00_overview.md` 结构树 + 分章 frontmatter `sections:`
- **以原文 PDF 为准**，fulltext 仅辅助；双栏篇必须 PDF 确认

### 步骤 2：逐分章改造（格式 = 批 1 示例）

- 每个"原文有子节"的分章：`## N.n 原文二级标题` → `### N.n.n 原文三级标题`（逐字）→ 标题下 `> **译文**` → 原内容归位
- 原八段模板内容（`## 2.1 本节核心内容` / `### 2.2.x §2.x...`）按原文归属拆分归位；整章概述留 `## N.n` 下
- 每篇优先做"子节最丰富"的分章，平铺分章跳过

### 步骤 3：frontmatter

- `sections:` 更新为原文二级标题名单（逐字）；其余字段不动
