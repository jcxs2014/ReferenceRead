## ⚠️ 铁律（对照 §4 与示例）

1. **信息零丢失**：原分章所有 `[FACT]` / `[INTERPRETATION]` / `[CRITIQUE]`、公式（含 `$$` 显示公式）、参数、图表分析、数值必须**全部保留并归位**到对应子节下。改造前后 FACT 等块计数不减（§3 验证）。
2. **子节号 + 标题逐字沿用原文**：不翻译、不改写、不重排编号（§4.2 反例 ②）。
3. **每个子节标题下第一行**必须插中文翻译段：`> **译文**`（引用块，参照示例格式）。
4. **不新造原文没有的子节**：原文某二级下无三级子节 → 该二级直接用 `## N.n 原文标题`，内容平铺（路径 B 精神）；原文平铺的分章**维持现状不动**。
5. **反例禁止**（§4.2）：主题当子节（如 `### 1.4.1 上游 Alfvén 波的产生`）、翻译标题、凭空编号、模板内部号（`### 2.2.1 §2.1...`）冒充原文子节号——**全部要改**。
6. **只改分章文件**：不动 00_overview / 97 / 98 / 99；frontmatter 仅允许更新 `sections:` 为原文二级标题名单（若原文有子节），其他字段不动。
7. **公式保持 LaTeX**（不做任何数学符号转换）；不新增任何分析内容（重组只归位）。
8. 正文开头"本章属于/上一章/下一章"引用块保留。
