## 3. 精读规范

**路径选择**：
- **Caprioli 2014**（ApJL Letter，正文 4-5 页 + 附录，原文无长编号子节层级）→ **路径 B（八段模板）**，不镜像子节

**精读重点（本轮 6 篇的理论定位）**：
- caprioli-2014：粒子模拟（PIC）方法、加速效率数值（~10-20%）、与 Bell 1978 解析理论的对照、谱指数收敛
- kotera-olinto-2011：UHECR 源候选、Hillas 判据、传播与 GZK、多信使（接 alvesbatista-2019 开放问题）
- arnould-goriely-2003：p 过程反应网络、天体物理位点（O/Ne 燃烧层、超新星喷出）、核物理不确定性
- sneden-cowan-2008：太阳系外 r 过程观测（金属贫星）、r/s 过程区分、与 cowan-2021 的前后衔接
- nomoto-2013：核心坍缩 SN 核合成产额表、超新星/极贫星约束（EMP stars）、化学演化模型
- karakas-lattanzio-2014：AGB 核燃烧（第三 dredge-up、热脉冲）、s 过程与产额表、低中质量星银河增丰

**其余按标准接入 SOP**：00_overview 全套 frontmatter（category 按域）→ 路径 A 分章 / 路径 B 八段 → 97_quality_check → 98_vocabulary → 99_final_summary；公式 LaTeX 化（复用 `scripts/convert_supsub.py`，幂等）；对照原文 PDF 铁律。
